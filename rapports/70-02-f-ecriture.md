# 70-02-f : Les figures de l'eucharistie (fichier 70, lettre f) : rapport d'écriture

Livré : /home/claude/liturgie/redaction/70-02-f.html (parties dans redaction/parts/70-02-f/, plan.md à jour).
12 leçons, 72 exercices de leçon (6 par leçon) + bilan de 6 exercices ; 171 citations de la Chérubin ; environ 279 Ko.

Plan (la commande entière est traitée, dans l'ordre biblique) :
1. Lire les figures (typos, ombre, règles, trois degrés d'autorité, figures AT / signes du Christ, sacrifice-nourriture-présence, Thomas IIIa q. 73 a. 6, Lauda Sion, Canon romain, CEC 1333-1335).
2. Melchisédech (Gn 14:18-20 ; Ps 110 ; Hb 7 ; Cyprien, Augustin, Trente, Canon romain ; lien 73-l pour le sacerdoce).
3. Le sacrifice d'Isaac (Gn 22 ; Rm 8:32 ; Hb 11:17-19 ; « Dieu pourvoira à l'agneau » ; Origène ; lien s).
4. L'agneau pascal et la Pâque (Ex 12:1-28 ; mémorial ; Jn 19:36 ; 1 Co 5:7-8 ; Trente ; Sacramentum caritatis ; figure principale ; liens d et s).
5. La manne (Ex 16 ; Dt 8:3 ; Jos 5:12 ; Sg 16:20-21 ; Jn 6:49-51 ; Ambroise ; liens l, d, e).
6. Le sang de l'Alliance (Ex 24:3-11 ; Jr 31 ; Mc 14:24 ; Lc 22:20 ; Hb 9 ; interdit du sang).
7. Les pains de proposition (Lv 24:5-9 ; Ex 25:30 ; 1 S 21 ; Mt 12:3-6 ; Hb 9:2 ; 13:10 ; lecture du 3e degré ; liens c, e).
8. Le pain d'Élie et le banquet de la Sagesse (1 R 19:4-8 ; viatique, lien 72-v ; Evangelii gaudium 47 ; Pr 9:1-6, 13-18 ; Cyprien, Augustin ; deux tables).
9. L'oblation pure (Ml 1:6-11 ; interprétations ; Didachè, Justin, Irénée ; Trente ; PE III ; lien 67-o).
10. Cana (Jn 2:1-11 ; l'heure ; CEC 1335 ; Cyrille ; Ecclesia de Eucharistia 53-54 ; lien t).
11. La multiplication des pains (Mc 6:30-44 ; quatre gestes et Mc 14:22 ; Élisée ; CEC 1335 ; fragments ; liens d, p, u, r).
12. Emmaüs et les repas du Ressuscité (Lc 24:13-43 ; Jn 21 ; Ac 10:41 ; CEC 1347 ; Mane nobiscum Domine ; Léon le Grand ; lien 64-p, l, p).

Choix :
- Pour la typologie en général, renvoi au cours 12-interpreter-l-ecriture.html#ouverture-t ; ici seulement ce qui sert aux figures eucharistiques, avec une grille de trois degrés d'autorité réutilisée dans toutes les leçons.
- Le sacerdoce de Melchisédech n'est pas développé (73-l) ; la leçon porte sur le pain et le vin.
- Les paroles de l'institution, le discours de Capharnaüm et la question de la date de la Cène sont rappelés d'une phrase avec lien vers #ouverture-d ; la doctrine du sacrifice vers #ouverture-s.
- Les textes latins de la liturgie (Canon romain, PE III) sont cités en latin, avec une traduction sans guillemets, faute de pouvoir vérifier la traduction française officielle.
- Les citations patristiques sont paraphrasées (« en substance »), sans guillemets.

Contrôle : verifier.py ne signale plus que 10 faux « tutoiements » (fragments de versets ou de liturgie entre guillemets : « ton fils, ton unique », « tu as gardé le bon vin », « quoi à moi et à toi ? »…). liens.py : 0 lien à revoir. Assemblage d'essai réussi (1 cours, 12 leçons).
Humaniser : passe faite sur toutes les parties (contrastes « pas X, mais Y », chutes « On peut maintenant répondre à la question du départ » répétées, « véritable », « Un bon corrigé… », formules aphoristiques).

Incertitudes : voir doutes.md, section 70-02-f (Trente XXII ch. 1 paraphrasé, latin liturgique de mémoire, références patristiques, lectionnaire).
