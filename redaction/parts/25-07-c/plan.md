# Plan du cours 25-07-c : Cassiodore (lettre c)

Question centrale : comment un haut fonctionnaire des rois goths est-il devenu, par un monastère de copistes et quelques livres d'école, l'un des passeurs de la culture chrétienne et antique vers le Moyen Âge ? Obstacles : confondre Cassiodore et Boèce ; croire « Senator » un titre ; croire que Vivarium « sauva les classiques païens » (débat O'Donnell) ; croire Vivarium bénédictin ; ignorer la numérotation des psaumes ; prendre l'Histoire des Goths pour conservée.

Sources vérifiées : O'Donnell, Cassiodorus (1979, en ligne) ; latin des Variae (thelatinlibrary), des Institutions (asu.edu/jod, Mynors), Jordanes (thelatinlibrary), De orthographia (Keil, Wuppertal), préface Expositio (epub.oeaw) ; Benoît XVI 12 mars 2008 (vatican.va) ; Avvenire 2021 (cause).

1. Un Romain de Calabre au service des rois goths : naissance vers 485 à Squillace (Var. XII, 15), famille (Var. I, 4), nom (Senator), questeur primaevus (Var. IX, 24), consul 514, Chronique 519, maître des offices 523 (après Boèce), préfet du prétoire 533-537/538 sous Athalaric, Amalasonte, Théodat, Vitigès.
2. Les Variae : 12 livres, 468 lettres, publiées 537-538 ; plan ; titre (préf. 15) ; style ; Var. II, 27 (religionem imperare non possumus) ; Var. XII, 25 (soleil voilé) ; valeur et limites du témoin ; De anima, « treizième livre ».
3. L'Histoire des Goths : Var. préf. 11 ; Var. IX, 25 (Originem Gothicam...) ; perte ; Jordanes, Getica 551 (préface) ; débats ; projet de réconciliation ; Anecdoton Holderi (lien Boèce).
4. Le projet avec Agapet, puis la conversion : Inst. préf. 1 ; Alexandrie et Nisibe (Junillus) ; bibliothèque d'Agapet au Caelius ; échec par la guerre ; départ des charges 537/538 ; De anima ; Constantinople 540-554 (Vigile 550, Trois Chapitres).
5. Vivarium et sa bibliothèque : fondation (vers 554, débattue) ; Inst. I, 29 (Pellena, viviers, bains, Castellum, Cassien avec prudence) ; I, 32 (abbés Chalcedonius et Gerontius, règles des Pères) ; pas de mention de Benoît ; armoires, livres grecs (I, 8 ; I, 14), traducteurs, Bibles (neuf codices, pandecte, codex grandior), médecine (I, 31).
6. Les Institutions, livre I : date (vers 562, revu jusqu'à la fin) ; « ad vicem magistri » ; tirones et psaumes ; 33 chapitres ; neuf codices ; introducteurs (I, 10) ; quatre conciles ; divisions ; prudence (I, 15 idiomata) ; historiens ; Pères ; Pélage purgé (I, 8).
7. Les Institutions, livre II : sept arts ; préf. (nombre sept, versets) ; I, 27 (dépouilles), I, 28 (Moïse, Actes 7:22) ; contenu de chaque art ; subordination à l'Écriture ; circulation séparée.
8. La copie, œuvre spirituelle : Inst. I, 30 (antiquarii, manu praedicare, tot vulnera, tribus digitis) ; relieurs, lampes, horloges ; correction ; intention ; Benoît XVI.
9. L'Exposition des Psaumes : préface (Repulsis...) ; date et lieu ; méthode ; Augustin ; David prophète, le Christ ; Chalcédoine (Ex. Ps. 81) ; tirones ; psaumes de pénitence (numérotation) ; réception.
10. L'Histoire tripartite et le De l'orthographe : Inst. I, 17 ; Épiphane ; 12 livres ; jugement de Grégoire sur Sozomène ; De orth. préface (93e année, plainte des moines) ; grammairiens ; Complexions.
11. L'héritage : sort de Vivarium (lettres de Grégoire 598) ; bibliothèque (Latran ?) ; Codex grandior et Amiatinus ; Bède, Isidore, Alcuin, Raban ; débat historiographique ; réception ecclésiale (pas canonisé, cause 2020-2021, Benoît XVI 2008) ; éditions (PL 69-70, CCSL 96-98).
