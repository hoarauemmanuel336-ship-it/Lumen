# 07-07-q · Les quatre causes (lettre q, fichier 07)

Question centrale : de combien de manières une chose dépend-elle réellement d'une autre, et comment Dieu peut-il être cause de tout sans retirer aux créatures leur propre causalité ?
Obstacles du novice : « cause » réduit à la seule cause efficiente (sens moderne) ; confusion cause / condition / occasion / simple antécédent ; la finalité prise pour une projection humaine ; Dieu cause « à côté » des causes créées (partage du travail ou occasionnalisme) ; l'instrument tenu pour inerte.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. La cause, la condition et l'occasion : aitia/causa ; principe / cause (influx dans l'être, In V Metaph. lect. 1) ; Phédon 99b (la vraie cause et ce sans quoi elle ne serait pas cause) ; condition (sine qua non, retirer un obstacle) ; occasion (circonstance qui favorise l'agent libre) ; antécédent (post hoc, lien 06-s). Foi : occasion du péché ; Dieu cause, non simple condition.
2. Les quatre causes, vue d'ensemble : Phys. II, 3 (194b16-195a3) et Métaph. Δ 2 ; les quatre « pourquoi » ; la statue ; pourquoi quatre (intrinsèques : matière, forme ; extrinsèques : agent, fin ; De principiis naturae) ; prédécesseurs (Ioniens, Anaxagore, Phédon 97b-99c) ; causes les unes des autres (195a8-11) ; plusieurs causes d'une même chose.
3. Les causes intrinsèques : matérielle (ex quo, matière première/seconde, matière des accidents, prémisses matière de la conclusion 195a18) ; formelle (quo, eidos, logos de l'essence ; forme substantielle/accidentelle ; forme donne l'être ; vivant/cadavre ; âme forme du corps, lien 08-a) ; réductionnisme matérialiste ; foi : Genèse 2:7, création sans cause matérielle (lien 38-l).
4. La cause efficiente : « d'où vient le premier principe du changement » ; agent ; action dans le patient ; cause du devenir / cause de l'être (maçon, soleil et lumière, I q. 104 a. 1) ; cause physique / morale (le conseiller) ; tout agent agit en tant qu'il est en acte (lien 07-a) ; foi : Dieu cause efficiente qui conserve (lien 38-c).
5. La cause finale : hou heneka ; marche pour la santé ; fin dans la nature (Phys. II, 8 : hirondelle, araignée, racines ; l'art ne délibère pas) ; fin dans l'action intelligente ; la fin meut comme aimée (Λ 7, 1072b3) ; critiques (Bacon, Spinoza, Darwin) et réponse ; principe de finalité (lien 07-p) ; foi : la fin de l'homme.
6. La fin, cause des causes : première dans l'intention, dernière dans l'exécution (I-II q. 1 a. 1 ad 1) ; finis causa causarum (De principiis naturae 4) ; sans fin l'agent n'agirait pas plus ceci que cela ; ordre fin → agent → forme → matière ; Dieu agit pour sa bonté à communiquer (I q. 44 a. 4) ; Romains 11:36, Apocalypse 22:13 ; lien 38-f.
7. La cause exemplaire : modèle de l'artisan ; Exode 25:40 ; Platon (Timée 28a-29a) ; Sénèque, Lettre 65 (cinquième cause) ; forme extrinsèque ; Augustin (De div. qu. 83, q. 46) ; idées divines (I q. 15 ; I q. 44 a. 3) ; une essence, plusieurs idées ; le Verbe (Jean 1:3, Colossiens 1:15-16) ; question disputée de son rang (formelle extrinsèque / efficiente, Suárez).
8. La cause instrumentale : agent principal / instrument ; double action (propre et instrumentale) ; l'effet ressemble à l'agent principal ; vertu instrumentale passagère ; instrument conjoint et séparé ; Isaïe 10:15 ; l'écrivain sacré instrument (lien inspiration).
9. Cause univoque et cause équivoque : l'homme engendre l'homme ; le maçon et la maison ; l'effet ne dépasse pas la cause ; perfection contenue formellement ou éminemment ; équivoque n'est pas univoque inférieure : priorité de la cause équivoque (I q. 13 a. 5 ad 1) ; Dieu cause analogue (I q. 4 a. 3 ; lien 07-o, 09-d).
10. Causes essentiellement et accidentellement ordonnées : main-bâton-pierre ; père-grand-père ; simultanéité et dépendance actuelle ; régression à l'infini impossible per se, possible per accidens (I q. 46 a. 2 ad 7, forgeron et marteaux) ; lien 09-c (cinq voies).
11. La cause première et les causes secondes : tout l'effet de l'une et de l'autre (SCG III, 70) ; dignité de la causalité (I q. 22 a. 3 ; CEC 306-308) ; occasionnalisme (Ghazali, Malebranche) et SCG III, 69 ; I q. 105 a. 5 ; concours : prémotion (thomistes) / concours simultané (Molina), question libre (lien 52-d) ; 24e thèse ; 1 Corinthiens 3:6-7, Philippiens 2:13, Isaïe 26:12, Jean 5:17.
12. L'usage théologique : humanité du Christ instrument conjoint de la divinité (Jean Damascène, III q. 19 a. 1 ; III q. 13 a. 2) ; Luc 6:19, Marc 5:30, Jean 9:6 ; sacrements instruments séparés (III q. 62 a. 1, a. 5) ; ex opere operato (lien 67) ; les causes de la justification (Trente, session VI, ch. 7).
