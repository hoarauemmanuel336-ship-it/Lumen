# 66-04-s · Les sacramentaux (fichier 66-les-rites-les-sacramentaux-et-la-piete.html, lettre s)

Question centrale : que sont ces signes sacrés que l'Église a institués à côté des sept sacrements (bénédictions, consécrations, objets bénits, exorcismes), comment agissent-ils, que donnent-ils, et comment s'en servir sans tomber dans la superstition ?
Obstacles du novice : confondre sacramental et sacrement ; croire qu'une chose bénite agit d'elle-même (magie) ; croire que seuls les prêtres bénissent ; croire qu'une bénédiction approuve tout ce qui est béni (Fiducia supplicans) ; croire que la consécration des vierges ou la bénédiction abbatiale sont des ordinations ; confondre exorcisme et délivrance « maison », ou exorcisme et maladie ; mépriser les sacramentaux comme superstition.

Sources vérifiées : voir sources.md (SC 60, 61, 79, 80 ; CEC 1667-1673, 2111, 2117 ; CIC 1166-1172, 604, 573 ; Fiducia supplicans et communiqué 2024 ; Vatican News 2026 (Léon XIV) ; De benedictionibus 1984 (décret, structure, praenotanda) ; Livre des bénédictions 1988 ; Ordo virginum, ESI 2018 ; LG 45 ; dates des rituels 1970 ; De exorcismis 1999 ; Thomas III q.87 a.3 et II-II q.96 a.4).

Leçons (fichiers 01 à 12, puis 99-bilan) :
1. Ce qu'est un sacramental : SC 60, CIC 1166, CEC 1667-1668 ; le mot (sacramentalia, XIIe s.) ; éléments : prière + signe ; les grandes familles (bénédictions, consécrations/dédicaces, exorcismes ; choses bénites) ; pourquoi : logique de l'Incarnation, création bonne (1 Tm 4:4-5), sacerdoce baptismal (CEC 1669).
2. Sacramentaux et sacrements : institution (Christ / Église ; CIC 1167 ; Trente) ; efficacité (ex opere operato / prière de l'Église, « ex opere operantis Ecclesiae ») ; nombre fixe ou ouvert ; nécessité ; tableau ; « selon une certaine imitation » ; analogie.
3. Les effets des sacramentaux : disposer à la grâce (SC 60, CEC 1670), sanctifier les circonstances (SC 61) ; effets traditionnels selon les théologiens (grâces actuelles, péchés véniels par mouvement de révérence : Thomas III q.87 a.3 ; protection contre le Malin ; biens temporels s'ils servent le salut) ; conditions : foi, dispositions ; mystère pascal source.
4. La bénédiction, premier des sacramentaux : berakah/eulogia/benedictio ; Dieu béni et Dieu qui bénit (ascendante/descendante) ; Nombres 6 ; Christ qui bénit ; CEC 1671 ; signe de croix au nom de Jésus ; bénédictions constitutives (CEC 1672 ; personnes consacrées, objets réservés au culte, CIC 1171) et invocatives (demander la protection sans changer l'état) ; exemples.
5. Le livre des bénédictions et les ministres : Rituel 1614 → De benedictionibus 1984 (décret 31 mai 1984) → Livre des bénédictions 1988 ; cinq parties ; structure d'une célébration (Parole, louange-intercession, signes) ; jamais de signe sans Parole ni prière ; ministres : CEC 1669, CIC 1168-1169, SC 79, praenotanda 18 ; laïcs, parents ; CIC 1170 (non-catholiques).
6. Bénir les personnes, les familles et la table : bénédictions des familles, époux, enfants (parents), malades, personnes âgées, missionnaires, catéchistes, pèlerins, voyageurs ; bénédiction de la table (Dt 8:10 ; Jésus bénit le pain ; formules ; Ps 145:15-16).
7. Bénir les maisons, les lieux de travail et les objets : maisons (Luc 10:5, Ps 127:1, bénédiction annuelle des familles en temps pascal ; Épiphanie), écoles, hôpitaux, bureaux, ateliers, champs, véhicules, instruments de travail (Ps 90:17), animaux ; objets de piété (croix, images, chapelets, médailles, scapulaire) ; objets de piété personnels : usage, respect (CIC 1171), objets usés, indulgences.
8. La déclaration Fiducia supplicans (2023) : contexte (Responsum 2021, dubia 2023) ; structure ; bénédictions liturgiques et bénédictions pastorales spontanées ; couples irréguliers et de même sexe ; conditions (n. 31, 38-40) ; doctrine du mariage inchangée ; communiqué 2024 ; réception et Léon XIV (2026) ; degré d'autorité.
9. Les consécrations de personnes : consécration des vierges (histoire, rite 1970, CIC 604, ESI 2018) ; bénédiction d'un abbé ou d'une abbesse (1970 ; insignes) ; rite de la profession religieuse (1970 ; SC 80 ; LG 45) ; distinction avec l'ordination.
10. L'eau bénite et les cierges de la Présentation : eau bénite (signe baptismal, bénitier, aspersion dominicale, sel : 2 R 2:19-22, usage domestique, Thomas) ; cierges de la Chandeleur (Luc 2:32, procession, usage à la maison, malades, mourants) ; lien avec cierge pascal et baptême.
11. L'exorcisme : CEC 1673, CIC 1172 ; Christ exorciste (Mc 1:25-26), pouvoir donné (Mc 3:14-15 ; 16:17) ; exorcisme simple (baptême) / grand exorcisme ; rituel 1614 → De exorcismis 1999 (2004) ; discernement maladie/possession, signes ; formules déprécative et impérative ; supplications et prières privées ; Actes 19:13-16 ; ce qui est interdit aux laïcs.
12. Le bon usage des sacramentaux et la superstition : CEC 2111, 2117 ; Thomas II-II q.96 a.4 ; De Ben praenotanda 19 et 27 ; critères : foi, prière, Christ au centre, accord avec la liturgie ; erreurs : magie, quantité, chaînes, porte-bonheur, commerce ; Mt 23:16-22 ; réponse à « Pour commencer » de toute la matière.
