# 93-11-a La construction de la paix (lettre a) — plan

Question centrale : comment l'Église comprend-elle la paix et que fait-elle, et que demande-t-elle, pour la construire entre les peuples ?
Obstacles du novice : paix = absence de guerre ; non-violence = passivité ou pacifisme absolu ; pardon = oubli/impunité ; désarmement = utopie ou désarmement unilatéral ; souveraineté absolue ; Église = simple ONG.

Renvois : guerre juste → #sujet:vie.guerre ; légitime défense → #sujet:vie.homicide ; Pacem in terris et désarmement → 92-...#ouverture-j ; Paul VI ONU « jamais plus la guerre » → 92-...#ouverture-v ; diplomatie du Saint-Siège, ONU → #ouverture-n ; bien commun (paix 3e élément) → 91-...#ouverture-b ; solidarité, pardon SRS 40 → 91-...#ouverture-a ; valeurs (4 piliers PT) → 91-...#ouverture-v.
