# Plan du cours 93-04-i « Les idéologies face à la doctrine sociale » (lettre i)

Citations vérifiées : voir citations.md (dans ce dossier). Ne citer entre guillemets que ce qui y figure ; paraphraser le reste.
Voisins à ne pas redoubler (lien d'une phrase) : 91-01-l leçon 2 (SRS 41, pas une idéologie) ; 92-02-r (RN, Libertas) ; 92-03-q (QA, NAB, MbS, DR en détail) ; 92-07-t (CA, Libertatis nuntius) ; 92-09-f (paradigme technocratique, LS 101-118) ; 93-03-e (marché, CA 34) ; 93-05-p (démocratie CA 46, État de droit) ; 93-06-r (liberté religieuse) ; 93-10-o (écologie).

Fichiers : 00-ouverture.html (cours + introduction), 01..11.html, 99-bilan.html.

1. Ce qu'est une idéologie — histoire du mot (Destutt de Tracy 1796, Napoléon, Marx) ; traits (principe unique, explication totale, programme imposé, promesse d'un monde sans mal : CA 25 ; OA 27-28 idole totalitaire) ; regard de la foi (idolâtrie Rm 1:25 ; messianisme sécularisé CEC 676 ; Jn 18:36) ; pourquoi la DS n'en est pas une (rappel SRS 41 + lien 91-01-l ; CA 43, CA 46) ; méthode de jugement (conception de l'homme, Dieu, vérité, liberté, bien commun ; erreur/errant).
2. Le socialisme — courants du XIXe (Saint-Simon, Fourier, Proudhon 1840, Louis Blanc) ; Quod apostolici muneris (28 déc. 1878) ; RN (quatre griefs, classes ennemies-nées) ; QA quarante ans après (socialisme modéré, « bon catholique et vrai socialiste », lien 92-03-q) ; erreur anthropologique CA 13.
3. Le communisme marxiste — Marx-Engels, Manifeste 1848, matérialisme historique ; athéisme (opium ; DR 9-10 ; CA 13) ; lutte des classes (Manifeste ; CA 14 ; conflit légitime) ; suppression de la propriété (formule du Manifeste ; DR 11 ; Ex 20:15 ; Mi 4:4) ; « intrinsèquement pervers » (DR 58), décret 1949, persécutions, 1989 (CA 23-24), martyrs.
4. Le libéralisme philosophique — ce qu'il soutient (raison souveraine, Libertas) ; Mirari vos 1832 (Lamennais, L'Avenir, indifférentisme, deliramentum ; Newman) ; Quanta cura et Syllabus 1864 (prop. 80, contexte, Dupanloup) ; Libertas 1888 (lien 92-02-r) ; continuité avec Dignitatis humanae (DH 1-2 ; lien #ouverture-r).
5. Le libéralisme économique et le laisser-faire — Smith 1776, physiocrates, école de Manchester ; loi Le Chapelier 1791, contrat de travail ; RN (description, juste salaire) ; QA libre concurrence (lien 92-03-q) ; PP 26, OA 26 et 35 ; la part de vérité.
6. Le capitalisme : CA 42 — le mot (LE 7, LE 14) ; la question de 1991 ; le oui (économie d'entreprise, de marché, libre ; CA 34-35) ; le non (cadre juridique, axe éthique et religieux ; idéologie radicale de type capitaliste ; idolâtrie du marché CA 40) ; après 1991 (EG 53-56, CV) ; lecture juste.
7. Le totalitarisme (CA 44) — le mot (Amendola 1923, Mussolini 1925) et ses traits ; négation de la vérité objective ; dignité transcendante (image de Dieu, droits inviolables, même par la majorité) ; négation de l'Église (CA 45) ; démocratie sans valeurs (lien 93-05-p) ; Ap 13:4, Ps 146:3.
8. Le fascisme — Mussolini 1919-1922, doctrine de l'État (1932) ; Latran 1929, crise de 1931, NAB (statolatrie, serment, pas le parti comme tel ; lien 92-03-q) ; pourquoi contraire à la foi ; lois raciales 1938 ; l'Action française (1926-1939) : un nationalisme qui utilise l'Église.
9. Le nazisme et son idéologie raciale — doctrine (race, sang, Volk, Führer, espace vital ; Rosenberg) ; unité du genre humain (Ac 17:26 ; Gn 1:27 ; Summi pontificatus 1939 ; décret 1928 ; instruction 13 avril 1938) ; antisémitisme, Shoah, NA 4, « Nous nous souvenons » 1998 ; eugénisme et euthanasie (loi 1933, Casti connubii 1930, T4, Galen 3 août 1941) ; témoins (Lichtenberg, Stein, Kolbe, Jägerstätter).
10. Le paradigme technocratique — rappel LS (lien 92-09-f) ; pourquoi une idéologie (neutralité prétendue, vrai = faisable CV 70, croissance illimitée LS 106, tout résoudre LS 109, domination LS 108) ; racines (Guardini, Paul VI, CV 14) ; formes actuelles (LD 20-24, IA, homme sans limite) ; réponse (CV 69-70, Gn 2:15, lien #ouverture-o).
11. Discerner les mouvements historiques — PT 158-160 (erreur/errant, doctrine/mouvement, prudence) ; OA 30-35 (courants socialistes, niveaux du marxisme, « illusoire et dangereux », renouveau libéral) ; cohérence avec DR 58 ; critères ; application aujourd'hui.
Bilan : 6 exercices croisés.
