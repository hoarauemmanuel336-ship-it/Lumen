# Plan du cours 23-14-y : Cyprien de Carthage (lettre y)

Question centrale : comment un évêque de Carthage, converti tard et mort martyr dix ans après son élection, a-t-il donné à l'Église latine sa première pensée de l'unité, au milieu des persécutions, des chutes et des schismes ?
Obstacles du novice : confondre schisme et hérésie ; lire « hors de l'Église point de salut » au sens d'une condamnation de tous les non-catholiques ; croire que Cyprien est docteur de l'Église (il ne l'est pas officiellement) ; croire que la version « primatiale » du chapitre 4 est une falsification romaine ; croire que Cyprien avait raison sur le baptême des hérétiques parce qu'il est saint ; confondre lapsi, libellatiques, sacrifiés ; billets de paix = absolution.

Sources latines : CSEL 3 (Hartel), copie locale /tmp/cyp/txt (OpenGreekAndLatin csel-dev). Numérotation moderne des lettres (Hartel).

1. Le rhéteur de Carthage devenu évêque : Carthage au IIIe s., Thascius Caecilius Cyprianus, rhéteur ; conversion vers 246 (prêtre Caecilianus), À Donat 3-4 (seconde naissance) ; prêtre puis évêque 248-249 malgré cinq prêtres ; Pontius, Vie de Cyprien ; Tertullien « le maître » (Jérôme, Hommes illustres 53).
2. La persécution de Dèce et la question des lapsi : édit de 249-250, certificats (libelli, papyrus d'Égypte), sacrificati / thurificati / libellatici ; Cyprien se cache (Lettre 20, 1 ; Matthieu 10:23), gouverne par lettres (Lettre 14, 4) ; critique du clergé romain (Lettre 8) ; ruée au Capitole (Les Tombés 8) ; confesseurs et martyrs.
3. Les billets de paix et les conciles de Carthage : Lucianus, « communicet ille cum suis » (Lettre 15, 4 ; Lettre 23) ; principe de Cyprien (attendre la paix, concile, examen des cas) ; concile du printemps 251 (Lettre 55, 6 et 17) ; accord de Rome ; concile de 252 ou 253 (Lettre 57, 1).
4. Les Tombés (De lapsis) : date, plan ; accueil des confesseurs (2) ; causes de la chute (5-7) ; fausse paix (15-16) ; « l'homme ne peut être plus grand que Dieu » (17) ; récits (25) ; libellatiques coupables (27) ; pensée (28) ; pénitence (35-36) ; exomologèse.
5. Deux schismes : Félicissime (Lettres 41, 43, 52, 59 ; Fortunatus) ; Novatien (Corneille 251, 16 évêques, Lettre 55, 24 ; concile romain ; novatiens/cathares ; Nicée canon 8) ; Cyprien entre laxisme et rigorisme.
6. L'Unité de l'Église catholique : date 251, cible discutée ; plan ; ch. 3 (hérésies et schismes, ruse nouvelle) ; ch. 4 (version reçue) ; ch. 5 épiscopat un, in solidum, images ; ch. 7 tunique ; ch. 12 (deux ou trois) ; ch. 14 martyr hors de l'Église.
7. Les deux versions du chapitre 4 et la chaire de Pierre : texte reçu / texte de la primauté ; histoire (Manuce, polémique, Chapman, Bévenot) ; Lettres 43, 5 ; 48, 3 ; 55, 8 ; 59, 14 ; limites (71, 3 ; Sententiae) ; lecture catholique.
8. L'Église mère : De unitate 5-6 (mère, épouse, arche) ; CEC 181 ; Lettre 73, 21 ; sens chez Cyprien (séparés volontaires, schismatiques, martyr hors de l'Église ch. 14) ; développement : Latran IV, ignorance invincible, LG 14-16, CEC 846-848.
9. Le pasteur dans ses traités : L'Oraison dominicale (2-3, 8, 9 = CEC 2782, 13, 18, 23) ; La Tenue des vierges (3, 22) ; La Mortalité (8, 16, 20, 26) ; Les Œuvres et les aumônes (1-2) et le jugement de l'Église.
10. La correspondance et la Lettre 63 : 81 lettres (62 + 3 synodales + 16 d'autres), groupes, ce qu'elles montrent (Lettre 62 : rachat des captifs ; Lettre 67 : élection devant le peuple) ; Lettre 63 : aquariens, eau = peuple (63, 13), prêtre « au lieu du Christ » (63, 14), crainte de l'odeur du vin (63, 15) ; usage actuel.
11. La controverse baptismale avec Étienne : conciles 255, 256 (71), 1er septembre 256 (87) ; arguments (Lettres 69, 2 ; 70 ; 73, 21 ; 74, 9 ; 74, 11) ; Étienne « nihil innovetur » (74, 1) ; Firmilien ; fin (Sixte II, martyre) ; Arles 314 ; donatistes ; Augustin, Le Baptême I, 18, 28 et II, 4, 5 ; Trente.
12. Le martyre de 258 et la mémoire de l'Église : édits de Valérien ; Paternus 30 août 257, Curubis ; 14 septembre 258, Actes proconsulaires ; Pontius ; tombeau via Mappalienne ; Canon romain ; 16 septembre avec Corneille ; titre de « docteur de l'unité » (non officiel) ; Benoît XVI 2007.
