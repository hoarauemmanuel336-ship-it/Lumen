# Plan du cours 10-03-a : Aristote

Lettre a, fichier 10-les-philosophes-et-la-foi.html. Vouvoiement. 12 leçons + bilan (6 exercices).

Question centrale : qui est ce païen que le Moyen Âge chrétien appelle « le Philosophe », que dit-il de la nature, de l'âme, de Dieu et de la vie bonne, et pourquoi l'Église a-t-elle pu le recevoir après l'avoir tenu à distance ?

Obstacles du novice : croire qu'Aristote rejette tout Platon ; confondre forme et figure ; croire que « juste milieu » veut dire médiocrité ; croire que le premier moteur est le Dieu créateur ; croire qu'Aristote enseigne clairement l'immortalité personnelle (ou clairement la mortalité) ; croire que l'Église a toujours accueilli Aristote, ou toujours condamné ; croire que Thomas a « baptisé » Aristote sans rien changer.

Leçons :
1. La vie d'Aristote (384-322) : Stagire, Nicomaque médecin ; Académie 367-347 ; Assos (Hermias), Lesbos (Théophraste) ; précepteur d'Alexandre (343/342, Mieza) ; Lycée (335/334), péripatéticiens ; 323 accusation d'impiété, Chalcis, mort 322. « Le Philosophe », Dante Enfer IV, 131.
2. La critique de la théorie des Idées : rappel de Platon (lien #ouverture-p) ; objections (Métaph. A 9 : redoublement, métaphores poétiques 991a20-22, ni mouvement ni génération, troisième homme, séparation) ; la forme dans la chose (composé, l'universel dans les choses, abstraction) ; EN I 6, 1096a16-17 (vérité plus chère que les amis ; « Amicus Plato » formule tardive) ; ce que la foi en reçoit : réalisme modéré, idées en Dieu (Augustin, Thomas ST I q.15).
3. L'œuvre comme ensemble : écrits perdus (exotériques, Cicéron « fleuve d'or ») et traités d'école ; Strabon et Andronicos ; pagination Bekker ; division des sciences (Métaph. E 1) ; l'Organon (six traités, syllogisme An. Pr. I 1) ; physique, métaphysique, éthique, politique, rhétorique, poétique ; méthode (du plus connu pour nous, endoxa, apories) ; usage en théologie (science subalterne, ST I q.1 a.2).
4. La Physique : nature (II 1, 192b21-23 ; lit d'Antiphon) ; mouvement (I : sujet, forme, privation ; III 1, 201a10-11) ; quatre causes (II 3) et finalité (II 8 : pluie, « l'art ne délibère pas ») ; « tout ce qui est mû est mû par un autre » (VII-VIII) et premier moteur ; la foi : première voie, Sagesse 13:1-5.
5. Le traité De l'âme : l'âme principe des vivants ; définition (II 1 : entéléchie première d'un corps naturel organisé ; cire et empreinte ; œil ; hache) ; degrés (nutritive, sensitive, intellective ; figures) ; intellect (III 4 : sans mélange, sans organe, tablette ; III 5 : intellect agent, lumière ; III 8 : tous les êtres) ; foi : concile de Vienne 1312.
6. La Métaphysique et le premier moteur : titre, 14 livres ; A 1-2 (désir de savoir, étonnement, sagesse) ; Γ (être en tant qu'être, se dit en plusieurs sens) ; E 1 (théologique) ; Λ 6-7 (substance qui est acte, meut comme aimé, ciel et nature suspendus, vivant éternel) ; Λ 9 (pensée de la pensée) ; Λ 8 (pluralité de moteurs) ; Λ 10 (armée, Homère) ; foi : Sagesse 13:5, Romains 1:20, Exode 3:14, Deus caritas est 9 (paraphrase).
7. Le bonheur : EN I 1 (tout tend vers un bien) ; fin dernière ; eudaimonia, les trois vies ; fonction propre (I 7, 1098a16-18, hirondelle) ; biens extérieurs, Priam, « heureux en hommes » (1101a20-21) ; vie contemplative (X 7) ; foi : béatitude imparfaite et parfaite (ST I-II q.3 a.8 ; q.5 a.3), Augustin Confessions I, 1, 1 Jean 3:2.
8. La vertu, juste milieu, et la prudence : arêtê ; vertus intellectuelles et morales (II 1) ; hexis ; milieu relatif à nous (Milon) ; définition (II 6, 1106b36-1107a2) ; sommet (1107a6-8) ; actes sans milieu ; prudence (VI 5, 1140b4-6 ; Périclès ; tempérance qui sauve la prudence) ; habileté ; VI 13 (pas de vertu sans prudence) ; foi : Sagesse 8:7, CEC 1806 (auriga virtutum), théologales sans milieu (ST I-II q.64 a.4 ; Bernard).
9. L'amitié et la cité : EN VIII 1 (nécessaire, cités) ; trois amitiés (VIII 2-3) ; amitié de vertu, sel ; autre soi-même (IX 4) ; distance des dieux (VIII 7) → Jean 15:15, charité amitié (ST II-II q.23 a.1) ; Politique I 1-2 (vivre/bien vivre, animal politique, logos, bête ou dieu, tout et partie) ; régimes (III 6-7, bien commun) ; esclavage naturel jugé ; foi : De regno, doctrine sociale.
10. Le Dieu d'Aristote devant la foi : éternité du monde (Physique VIII 1 ; Du ciel I ; Topiques I 11) ; réponse : Genèse 1:1, Latran IV, Vatican I ; Thomas : création ≠ commencement, ST I q.46 a.2, De aeternitate mundi ; Bonaventure, Philopon (liens) ; premier moteur qui ne connaît pas le monde (Λ 9, 1074b32-35) ; réponse : providence (CEC 303, Matthieu 10:29-30), ST I q.14 a.5-6, q.22 a.2 ; lecture bienveillante de Thomas.
11. L'immortalité personnelle : textes (I 4, 408b18-29 ; II 1, 413a3-7 ; II 2, 413b24-27 ; III 5, 430a22-25) ; raisons de l'ambiguïté ; lectures : Alexandre d'Aphrodise, Thémistius, Avicenne, Averroès (lien #ouverture-m), Thomas (ST I q.76 a.1 ; De unitate intellectus, lien #ouverture-s), Pomponazzi 1516 ; Latran V 1513, Vienne 1312 ; distinctions d'autorité ; Matthieu 10:28.
12. D'Athènes à Paris : Boèce (logica vetus) ; Syriaques, Bagdad, al-Kindi, al-Farabi, Avicenne, Averroès le Commentateur ; traductions latines (Jacques de Venise, Tolède, Gérard de Crémone, Michel Scot, Grosseteste, Moerbeke) ; interdictions 1210, 1215 (Courçon), Toulouse 1229, Parens scientiarum 1231, statuts 1255 ; Albert (« faire comprendre aux Latins », « s'il est homme, il a pu se tromper ») et Thomas : ce qu'ils retiennent, ce qu'ils corrigent ; « Aristote baptisé » image.

Bilan : 6 exercices croisés.
