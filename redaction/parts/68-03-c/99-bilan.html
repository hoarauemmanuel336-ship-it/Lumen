Rangez dans l'ordre de la célébration du baptême d'un enfant les rites suivants, et indiquez pour chacun le temps auquel il appartient (accueil, Parole, sacrement, rites explicatifs, conclusion) : le cierge ; la renonciation ; le signe de croix sur le front ; le Notre Père ; la prière d'exorcisme ; la bénédiction de l'eau ; l'onction du saint chrême ; la prière universelle ; l'Effata ; la profession de foi ; l'onction avec l'huile des catéchumènes ; le bain ; le vêtement blanc ; la bénédiction finale.

Accueil : le signe de croix sur le front (leçon 4). Parole : la prière universelle (leçon 5), puis la prière d'exorcisme et l'onction avec l'huile des catéchumènes (leçon 6). Sacrement : la bénédiction de l'eau (leçon 7), la renonciation (leçon 8), la profession de foi et le bain (leçon 9). Rites explicatifs : l'onction du saint chrême (leçon 10), le vêtement blanc, le cierge (leçon 11), l'Effata (leçon 12). Conclusion : le Notre Père, puis la bénédiction finale (leçon 12). Les cinq temps décrits à la leçon 2 se retrouvent ainsi, et le bain occupe le centre : tout ce qui le précède y prépare, tout ce qui le suit en montre l'effet.
