# 65-08-e Le temps pascal (lettre e) — plan

ÉTAT : 11 leçons + bilan écrits, réunis dans redaction/65-08-e.html ; contrôle OK ; reste : humaniser, essai d assemblage, doutes, rapport.

Question centrale : pourquoi Pâques change-t-elle de date chaque année, et comment l'Église fait-elle des cinquante jours qui suivent une seule fête, jusqu'à la Pentecôte ?
Obstacles du novice : croire que Pâques est un seul dimanche ; ignorer pourquoi la date bouge ; croire que la différence avec les orthodoxes vient d'une querelle de doctrine ; croire que le temps pascal finit à l'Ascension ; confondre Pentecôte juive et chrétienne ; croire la Divine Miséricorde une fête nouvelle détachée de Pâques ; ignorer la mystagogie.

Leçons (fichiers 01..11) :
1. La Pâque et la querelle quartodécimane : Pâque juive (Exode 12, 14 nisan) ; mort du Christ à la Pâque (1 Co 5:7) ; usage d'Asie (14e jour) et usage du dimanche ; Polycarpe et Anicet (vers 155), Victor et Polycrate (vers 190), Irénée (Eusèbe, HE V 23-25).
2. Le concile de Nicée (325) : contexte (Constantin, diversité, dépendance du calcul juif, protopaschites) ; décision : une même date, un dimanche, sans suivre le calcul juif ; sources (lettre synodale aux Égyptiens, lettre de Constantin chez Eusèbe) ; pas de canon ; rôle d'Alexandrie ; canon 20 (prière debout).
3. Le comput : règle (dimanche après la première pleine lune qui suit l'équinoxe, fixé au 21 mars) ; lune ecclésiastique ; 22 mars-25 avril ; cycle de 19 ans ; Denys le Petit, Bède ; fêtes mobiles qui en dépendent.
4. Orient et Occident : calendrier julien, dérive ; réforme grégorienne (1582, Inter gravissimas, 10 jours) ; Orthodoxes gardent le julien pour Pâques ; dates qui coïncident ou non (2025, 2028) ; Vatican II (appendice SC) ; CEC 1170 ; recherche d'une date commune (Alep 1997, François, 1700e anniversaire de Nicée 2025).
5. Cinquante jours, un seul jour de fête : Normes universelles 22 ; Athanase « grand dimanche » (CEC 1169) ; Tertullien ; signes (alléluia, cierge pascal, debout, blanc, préfaces) ; les dimanches « de Pâques ».
6. L'octave de Pâques et le dimanche de la Divine Miséricorde : octave (Normes 24, solennités, Gloria, Credo non, renvoi double alléluia, Haec dies) ; dimanche in albis / Quasimodo ; Divine Miséricorde : Faustine, canonisation 30 avril 2000, décret 5 mai 2000, Jean 20:19-31, indulgence 2002 ; statut d'une révélation privée.
7. Les lectures du temps pascal : Actes en première lecture (Ordo lectionum 74, 100-102), dimanches et semaine ; deuxième lecture (1 Pierre, 1 Jean, Apocalypse) ; Évangile de Jean : apparitions, Bon Pasteur, discours après la Cène, prière sacerdotale ; semaine : Jean 3, 6, 10, 14-17.
8. La mystagogie : mot grec ; temps de la mystagogie dans le RICA ; Cyrille de Jérusalem, Ambroise ; discipline de l'arcane ; CEC 1075 ; sens pour tous les fidèles.
9. L'Ascension, quarantième jour, et la neuvaine : Actes 1:3, 1:9-11 ; jeudi, transfert au 7e dimanche ; histoire ; cierge ; neuvaine (Actes 1:14), Léon XIII (Divinum illud munus 1897) ; Normes 26 ; liens 50#ouverture-e.
10. La Pentecôte, achèvement du temps pascal : fête juive des Semaines ; Actes 2 ; cinquantième jour ; messe de la veille ; fin du temps pascal ; cierge au baptistère ; octave supprimée ; rouge ; liens 51#ouverture-p.
11. Deux chants du temps pascal : Veni, Sancte Spiritus (séquence obligatoire, PGMR 64 ; Langton ; texte et sens) ; Regina caeli (texte, origine, Benoît XIV 1742, remplace l'Angelus, antienne de Complies).
Bilan : 6 exercices croisés.
