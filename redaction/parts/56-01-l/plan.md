# 56-01-l « Les Douze et la succession apostolique » (fichier 56, lettre l) : plan

Question centrale : comment le Christ a-t-il institué les Apôtres, et comment leur charge se poursuit-elle aujourd'hui dans les évêques ?
Obstacles du novice : « hiérarchie » lu comme organigramme de pouvoir ; confondre Douze, apôtres, disciples ; croire que les évêques sont des « nouveaux apôtres » qui ajoutent à la Révélation ; croire que la succession est une simple liste historique ; croire que épiscope = évêque d'aujourd'hui dans le NT ; objection protestante (et de Jérôme) : évêque et presbytre sont un, l'épiscopat est une évolution humaine ; croire que service = absence d'autorité.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. Le mot hiérarchie : hieros + archè, Denys vers 500 (définition HC III,1, lien 24#ouverture-p) ; hiérarque/prêtres/ministres ; passage en latin (Hilduin, Érigène, IXe s.) ; Trente sess. XXIII can. 6 (1563) ; LG ch. III ; CEC 874-875 (le Christ source du ministère ; personne ne se confère la grâce ; Hébreux 5:4) ; ce que le mot ne dit pas (égale dignité, LG 32).
2. L'appel des Douze : Marc 3:13-19 lu pas à pas (montagne, ceux qu'il voulait, établit douze, être avec lui / envoyer, pouvoir) ; Luc 6:12-13 ; nombre douze et tribus (Genèse 49:28, Exode 24:4, Matthieu 19:28, Luc 22:30, Apocalypse 21:12-14) ; CEC 877 (germes du Nouvel Israël, origine de la hiérarchie sacrée) ; Douze / apôtres / disciples (Luc 10:1, Actes 14:14).
3. Les Douze, collège stable dont Pierre est le premier : « les Douze » comme nom (Marc 6:7, Jean 6:67-70, 1 Co 15:5), « les Onze » ; quatre listes, trois groupes de quatre, Pierre en tête, Judas en dernier ; Matthieu 10:2 « le premier » alors qu'André fut appelé avant (Jean 1:40-42) ; LG 19 « forme d'un collège, c'est-à-dire d'un groupe stable » ; collège qui agit ensemble (Actes 6:2, 15) ; sens de collège (lien #ouverture-c), primauté (lien #ouverture-p).
4. L'envoi en mission : apostolos (lien 55#ouverture-a), shaliah ; Matthieu 28:18-20 (pouvoir, trois verbes, promesse) ; Jean 20:21-23 (chaîne des envois, souffle, péchés ; lien 71#ouverture-l) ; Luc 10:16 ; la promesse jusqu'à la fin du monde exige des successeurs (LG 20, CEC 860).
5. Matthias : Actes 1:15-26 ; Psaumes 69:26 et 109:8, « charge » = episkopè ; conditions (témoin) ; prière et sort (Proverbes 16:33) ; « adjoint aux onze » ; premier signe de transmission ; Jacques non remplacé (Actes 12:2) : ce qui se transmet et ce qui ne se transmet pas déjà en germe.
6. Les ministères du NT : presbytres (Anciens) Actes 11:30, 14:23, 15, 20:17 ; épiscopes (Philippiens 1:1, Actes 20:28, Tite 1:5-9, 1 Timothée 3) ; interchangeabilité ; diacres (1 Timothée 3:8 ; Actes 6, lien #ouverture-d) ; Timothée et Tite, délégués apostoliques ; Jacques à Jérusalem ; Ignace vers 110 : trois degrés (lien 23#ouverture-i) ; ce qui est sûr et ce qui reste discuté.
7. La succession apostolique : définition ; imposition des mains (Nombres 27, Deutéronome 34:9, Actes 6:6, 13:3, 1 Tm 4:14, 2 Tm 1:6, 1 Tm 5:22) ; 2 Tm 2:2 ; Nicée can. 4, CIC 1012-1014 ; succession dans un siège (Irénée, lien 55#ouverture-a) et dans le collège ; Orthodoxes (UR 15), Anglicans (Apostolicae curae 1896), Protestants (UR 22, lien 55#ouverture-a).
8. Clément de Rome, Lettre aux Corinthiens 42-44 : contexte (vers 96) ; chaîne des envois ; établissement d'épiscopes et diacres ; règle de succession (44,1-2) ; ministres non destituables (44,3) ; offrir les dons (44,4) ; LG 20 le cite ; ce que le texte prouve et ne prouve pas ; lien 23#ouverture-c.
9. Ce qui ne se transmet pas : CEC 860 ; témoins choisis de la Résurrection (Actes 1:22, 10:41, 1 Co 9:1, 15:8) ; fondements (Éphésiens 2:20, Apocalypse 21:14) ; Révélation close (DV 4, Lamentabili 21) ; Écriture ; privilèges personnels (opinion commune) ; les évêques ne sont pas de nouveaux apôtres (Jude 17).
10. Ce qui se transmet : CEC 860 aspect permanent ; charge pastorale d'enseigner, sanctifier, gouverner (CEC 857, LG 21) ; racines dans les paroles du Christ ; transmise par le sacrement (CEC 875) ; personnelle et collégiale (CEC 877-879) ; avec prêtres et diacres (LG 20) ; détails des charges : lien #ouverture-t.
11. Les évêques successeurs des Apôtres par institution divine (LG 20) : lecture du paragraphe ; « institution divine » : ce que cela veut dire ; degré d'autorité (Trente can. 6-8, LG 20, CEC 862) ; Luc 10:16 ; collège succède au collège ; objection de Jérôme et protestante sous sa forme forte, réponse ; Orthodoxes d'accord.
12. L'autorité comme service : Marc 10:35-45 lu ; Luc 22:24-27 ; Jean 13 ; 1 Pierre 5:1-4 ; 2 Co 10:8 ; LG 18, 24 (diakonia) ; CEC 876 ; Augustin (LG 32) ; servus servorum Dei (lien #ouverture-j) ; service et autorité réelle (Hébreux 13:17) ; Bon Pasteur (lien #ouverture-t).
