# 63-11-v — Les vêtements liturgiques et les insignes (lettre v)

Question centrale : pourquoi les ministres changent-ils de vêtements pour célébrer, et que dit chaque pièce ?
Obstacles du novice : croire que ces habits copient ceux d'Aaron ou sont des marques d'honneur personnel ; confondre aube et surplis, chasuble et chape, étole du prêtre et du diacre ; ignorer que les insignes de l'évêque disent une charge.

Leçons (un fichier chacune : 00-ouverture, 01…10, 99-bilan) :
1. Revêtus du Christ : le sens des vêtements liturgiques — PGMR 335 (fonction, beauté, bénédiction) ; Galates 3:27, baptême ; ministre effacé (Jean 3:30, in persona Christi) ; vêtements d'Aaron comme figure (Exode 28:2, Ézéchiel 44:19, Zacharie 3:4-5) ; liturgie céleste (Apocalypse 7).
2. Du costume romain au vêtement sacré — clercs vêtus comme tous (Célestin Ier, 428) ; tunique, pénule, dalmatique, orarium ; la mode change, l'Église garde (VIe-IXe s.) ; lecture allégorique (Amalaire, Raban Maur), prières de vêture ; parallèles orientaux ; manipule.
3. L'amict, l'aube et le cordon — PGMR 336, 339 ; casque du salut ; aube baptismale ; surplis ; cordon (tenue de service, chasteté).
4. L'étole — orarium, nom de stola ; signe du ministère ordonné (RS 153) ; diacre / prêtre / évêque (PGMR 340) ; ancien croisement ; sens (immortalité, joug) ; parallèles byzantins.
5. La chasuble — PGMR 337, RS 123-124, 126 ; casula (Isidore) ; formes ; charité et joug.
6. La dalmatique — PGMR 338, RS 125 ; histoire (Rome, Sylvestre, Symmaque, clavi) ; service du diacre ; évêque (CE 56) ; tunique du sous-diacre.
7. La chape et le voile huméral — PGMR 341, CE 66 ; origine pluviale ; usages ; voile huméral (salut, procession, Jeudi saint) ; sens.
8. Les insignes de l'évêque et la mitre — CE 57 ; sens d'ensemble ; Pontificalia insignia ; mitre : histoire (Léon IX 1049), formes, fanons, CE 60, formule d'ordination.
9. La crosse et l'anneau — histoire (Isidore, Tolède) ; CE 58-59 ; formules ; férule papale ; querelle des Investitures (Worms 1122) ; anneau du Pêcheur.
10. La croix pectorale et le pallium — CE 61, 63 ; encolpion, panagia ; pallium : laine, agneaux de sainte Agnès, 29 juin, CIC 437, CE 62, histoire, usage 2015-2024 et 2025, sens (brebis sur les épaules, communion avec Pierre), omophorion.
