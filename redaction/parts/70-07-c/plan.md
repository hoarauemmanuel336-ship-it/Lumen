# 70-07-c · La communion eucharistique · plan

Question centrale : qui peut recevoir le Corps du Christ, avec quelles dispositions, combien de fois et sous quelle forme, et que fait la communion en celui qui la reçoit ?
Obstacles du novice : croire que communier va de soi pour toute personne présente à la messe ; confondre « digne » et « parfait » ; croire qu'un acte de contrition suffit après un péché grave ; ignorer la règle actuelle du jeûne (une heure) ; croire que la communion sous une seule espèce est une demi-communion ; croire que la communion efface les péchés mortels ; croire que la communion pascale est l'idéal ; croire que l'enfant doit tout savoir ; voir la communion spirituelle comme un pis-aller sans fruit ; réduire les fruits à un sentiment.

Leçons (12) :
1. L'état de grâce requis pour communier : invitation (CEC 1384) ; 1 Co 11:27-29 lu dans son contexte (indignement, s'examiner, discerner le corps) ; état de grâce (définition, péché mortel / véniel) ; jugement de conscience (EdE 37) et canon 915 ; dignité ≠ perfection (Mt 8:8, CEC 1386) ; vêtement de noce (Mt 22).
2. La confession préalable en cas de péché grave : CEC 1385, Trente XIII ch. 7 et canon 11 (foi seule insuffisante ; coutume de l'Église ; « quantumvis contritus ») ; canon 916 (motif grave + impossibilité → contrition parfaite avec résolution de se confesser au plus tôt) ; pourquoi la confession et pas seulement la contrition ; doute ; cas pratiques ; lien 71.
3. Le jeûne eucharistique et la tenue : sens (faim, primauté, préparation) ; Augustin lettre 54 ; Tertullien ; Code de 1917 (depuis minuit, jeûne naturel) ; Pie XII 1953 et 1957 ; Paul VI 1964 (une heure) ; canon 919 §1-3 ; Orient ; respect intérieur et extérieur (CEC 1387) ; geste de révérence (PGMR 160) ; parcelles (Cyrille) ; Augustin adorer avant de manger (SC 66) ; Redemptionis sacramentum 91-92 ; action de grâce.
4. Le précepte de la communion pascale : Latran IV 1215, canon 21 Omnis utriusque sexus (contenu, sanctions, propre prêtre) ; pourquoi un minimum ; Trente XIII canon 9 ; canon 920 ; CEC 1389 et 2042 ; « faire ses Pâques » ; un minimum, non un idéal.
5. La communion fréquente et Sacra Tridentina Synodus : Actes 2:46 et l'Église ancienne ; raréfaction médiévale ; Trente XXII ch. 6 ; jansénisme (Arnauld, 1643) ; décret du 20 décembre 1905 (état de grâce + intention droite ; remède et non récompense ; véniels) ; Mt 6:11 ; canon 917 et interprétation de 1984 ; CEC 1388 ; danger de l'habitude.
6. La première communion et l'âge de raison : âge de discrétion ; Quam singulari 8 août 1910 (normes I-III : vers sept ans, connaissance proportionnée, distinguer le pain eucharistique) ; rôle des parents et du curé ; confession avant (canon 914) ; canons 913-914 ; Orient : communion des nourrissons (lien 69) ; enfants handicapés (connaissance selon capacité) ; communion privée / solennelle.
7. La communion sous une seule espèce et sous les deux espèces : pratique ancienne ; recul médiéval et ses raisons ; Constance 1415 ; hussites et utraquistes ; Trente XXI (16 juillet 1562) ch. 1-4 et canons ; pouvoir de l'Église salva substantia (1 Co 4:1) ; concomitance (lien p) ; Jn 6:51 / 6:53 ; Vatican II (SC 55), CEC 1390 (signe plus plein) ; canon 925 ; lien 64 c pour les modalités.
8. Le fruit premier : l'union intime au Christ : CEC 1391 ; Jn 6:56-57 ; « demeurer » (Jn 15) ; Augustin, Confessions VII, 10 (tu seras changé en moi) ; Ga 2:20 ; union à la Trinité (Jn 14:23) ; ce que l'union n'est pas (sentiment) ; corps ecclésial (lien u).
9. Une nourriture pour la vie de grâce : CEC 1392-1395 ; analogie de la nourriture (Thomas : soutenir, accroître, réparer, réjouir) ; 1 R 19 ; charité ravivée (CEC 1394) ; rémission des péchés véniels (Ambroise, CEC 1393 ; Trente « antidote ») ; préservation des péchés mortels (CEC 1395) ; ce que la communion ne fait pas : remettre le péché mortel (Trente XIII canon 5 ; CEC 1395).
10. L'engagement envers les pauvres : CEC 1397 ; 1 Co 11:20-22 ; Mt 25:40 ; Chrysostome (hom. 27 sur 1 Co) ; Jc 2:15-16 ; 1 Jn 3:17 ; EdE 20 ; Sacramentum caritatis 88 (« pain rompu ») ; collecte et œuvres de miséricorde ; Mt 5:23-24.
11. La communion spirituelle : Trente XIII ch. 8 (trois manières de manger) ; désir et fruit (Thomas, de mémoire) ; Thérèse d'Avila (EdE 34) ; Alphonse de Liguori (de mémoire, paraphrase) ; quand on ne peut pas communier (SC 55) ; la foi agissant par la charité (Ga 5:6) ; ce qu'elle n'est pas.
12. Le gage de la gloire future et de la résurrection : Jn 6:54 ; CEC 1402-1405 ; O sacrum convivium ; « jusqu'à ce qu'il vienne » (1 Co 11:26) ; Ignace (remède d'immortalité, lien l) ; Irénée (lien p) ; Rm 8:11 ; viatique (lien 72) ; Ap 19:9 ; ce que veut dire « gage ».
