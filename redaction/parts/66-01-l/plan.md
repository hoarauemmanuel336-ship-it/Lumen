# 66-01-l — Unité de la foi et diversité des rites (lettre l, premier cours du fichier 66)

Question centrale : comment l'Église catholique peut-elle être une dans la foi tout en célébrant selon plusieurs rites ?
Obstacles : confondre rite et Église ; croire que « catholique » = « latin » ; voir les rites orientaux comme des concessions ou des catholiques de second rang ; croire que tout est variable (ou que tout est immuable) ; croire qu'on change d'Église en fréquentant une autre liturgie.

Leçons (10) :
1. Le mot « rite » : du geste réglé au patrimoine — ritus ; trois sens (cérémonie, ordre d'une liturgie, patrimoine) ; CCEO 28 §1 : liturgique, théologique, spirituel, disciplinaire, distinct par la culture et l'histoire ; exemples ; CEC 1200.
2. Rite et Église de droit propre — CCEO 27 ; sui iuris ; un rite / plusieurs Églises (byzantin) ; une Église / plusieurs rites (latine) ; OE 2 « Églises particulières ou rites » ; Église particulière (diocèse) ≠ Église de droit propre ; 24 Églises ; « uniate » ; orthodoxes même rite non catholiques.
3. Comment sont nées les traditions liturgiques — structure commune reçue (Actes 2:42 ; Justin, président qui prie « selon son pouvoir ») ; improvisation puis fixation ; métropoles et grands sièges : Nicée c.6 (Alexandrie, Rome, Antioche), Constantinople 381 c.3, Chalcédoine 451 (Jérusalem, c.28) ; LG 23 « sources de foi » ; facteurs : langue, culture, frontières, controverses.
4. La carte des grandes traditions — CCEO 28 §2 : alexandrine, antiochienne, arménienne, chaldéenne, constantinopolitaine + latine ; CEC 1203 ; tableau ; anaphores (Marc/Cyrille, Jacques, Addaï et Mari, Chrysostome/Basile, Canon romain).
5. La diversité, une richesse : SC 4 — texte ; CEC 1201-1202 ; Éphésiens 3:10 ; Pentecôte ; Irénée et Victor, Polycarpe et Anicet ; Grégoire à Augustin ; LG 13 ; CEC 1206 : tensions possibles ; CEC 1208 catholicité.
6. L'égale dignité des rites : OE 3 — latinisations, praestantia ritus latini (Benoît XIV), Léon XIII Orientalium dignitas 1894 ; OE 3 ; OE 1, 5, 6 ; CCEO 39 ; deux poumons ; conséquences.
7. Immuable et variable — SC 21 ; CEC 1205 ; Trente XXI c.2 « salva illorum substantia » ; Florence 1439 azyme/fermenté ; 1 Co 11:23 ; Actes 15:28 ; UR 4 ; variable ≠ arbitraire (SC 22, CCEO 40 progrès organique).
8. Une même foi, les mêmes sacrements — OE 2 ; CEC 1209 ; Éphésiens 4:4-6 ; exemples (baptême par immersion, chrismation par le prêtre, pain levé, absolution déprécative, ministre du mariage oriental) ; UR 17 complémentarité ; lex orandi ; CIC 923 ; primauté (LG 13).
9. L'appartenance à une Église de droit propre — ascription par le baptême (CIC 111, CCEO 29-30), 14 ans, parents ; CCEO 38 / CIC 112 §2 (pratique ≠ appartenance) ; OE 4 / CCEO 40 §3 garder son rite ; soin pastoral (CIC 383 §2) ; CCEO 35 non-catholiques venant à la pleine communion.
10. Le passage d'une Église à une autre — CIC 112 / CCEO 32-37 : consentement du Siège apostolique, présomption (CCEO 32 §2), mariage (CCEO 33, CIC 112 §1 2°), enfants (CCEO 34), déclaration devant témoins (CCEO 36, CIC 112 §3), registre (CCEO 37) ; CCEO 31 interdiction d'induire ; raisons ; De concordia inter Codices (2016).
