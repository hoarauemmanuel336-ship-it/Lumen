# 65-10-d · Les degrés des célébrations et le sanctoral (lettre d, fichier 65-le-temps-liturgique.html)

Question centrale : comment l'Église décide-t-elle, jour après jour, ce qu'elle célèbre, et pourquoi fait-elle mémoire des saints au milieu des mystères du Christ ?
Obstacles du novice : croire que les saints concurrencent le Christ ; croire que le saint est fêté à sa naissance ; confondre fête (sens courant) et fête (degré) ; ignorer qu'une mémoire facultative est un choix ; ne pas comprendre pourquoi une fête « saute » ou se déplace ; confondre calendrier et martyrologe ; croire que les fêtes de précepte sont les mêmes partout ; confondre Toussaint et jour des morts.

Leçons (12) :
1. Le temporal et le sanctoral : deux cycles (SC 102-104, 108) ; Propre du temps / Propre des saints / Communs dans le Missel ; préséance du temporal ; calendrier et martyrologe.
2. Le mystère pascal accompli dans les saints : SC 104 (texte vérifié), 111 ; Rm 8:17 ; trois buts (proclamer, proposer l'exemple, implorer) ; Marie SC 103 ; culte de dulie (lien) ; origine au tombeau des martyrs ; Hé 13:7.
3. Le dies natalis : mot latin, Martyre de Polycarpe 18 (genethlios hêmera), Tertullien De corona 3, Cyprien lettre 12, Depositio martyrum (354) ; Ps 116:15, Ph 1:21-23, Jn 12:24 ; exceptions : Christ, Marie, Jean-Baptiste (Augustin sermon 287) ; autres dates (translation, NUALC 56) ; Thomas d'Aquin 28 janvier, Thérèse 1er octobre ; Étienne 26 décembre.
4. Les Normes universelles de 1969 : Mysterii paschalis (14 février 1969), approbation des Normes et du calendrier, en vigueur 1er janvier 1970 ; plan des Normes (jour liturgique n. 3 ; dimanche 4-7 ; célébrations 8-15 ; féries 16 ; cycle ; calendrier 48-61 ; tableau) ; histoire des degrés : doubles/semi-doubles/simples (Pie V), Pie X (1911), Code des rubriques 1960 (classes), 1969 (solennité, fête, mémoire) ; usage de 1962 (lien 64 v).
5. La solennité et la fête : NUALC 10-13 ; premières vêpres, messe de la veille, Gloria et Credo, octaves de Noël et Pâques ; liste des solennités ; la fête : jour naturel, pas de 1res vêpres sauf fêtes du Seigneur un dimanche ; exemples.
6. Les mémoires et la férie : NUALC 14-16 ; mémoire obligatoire (unie à la férie) ; en Carême → facultative ; mémoire facultative : choix, une seule ; samedi de la Vierge ; communs ; férie : féries privilégiées, 17-24 décembre, Carême, ordinaires ; PGMR 355.
7. Le tableau des préséances et la règle des coïncidences : 13 rangs en trois groupes ; NUALC 59-61 ; solennité empêchée transférée ; dimanches Avent/Carême/Pâques → lundi ; fêtes et mémoires empêchées omises ; concurrence des vêpres ; exemples 2023-2027.
8. Le calendrier romain général et la réforme de 1969 : Calendarium Romanum (21 mars 1969) ; principes (SC 111, Mysterii paschalis) ; retraits (Christophe), déplacements, ajouts (Charles Lwanga) ; ajouts ultérieurs (2002, 2014, 2016, 2018, 2021) ; calendrier ≠ martyrologe.
9. Les calendriers propres : NUALC 48-55 ; pays, diocèses, familles religieuses, églises ; règles (rangs 4, 8, 11 du tableau) ; exemples (patrons de France, cathédrale, fondateur) ; approbation du Siège apostolique ; l'ordo.
10. Les fêtes de précepte : canon 1246-1248 ; dix fêtes ; transfert au dimanche (NUALC 7) ; France : quatre (indult Caprara 1802) ; principe permanent / discipline ; liens dimanche, préceptes de l'Église.
11. La Toussaint : Ap 7:9-10, Hé 12:1, 22-23 ; histoire (Édesse, Chrysostome, Panthéon 609/610, Grégoire III, Grégoire IV 835, Sixte IV, 1955) ; liturgie (lectures, préface) ; sens : appel universel à la sainteté (LG 40), Église en trois états (CEC 954).
12. La Commémoration de tous les fidèles défunts : 2 M 12:43-46 ; Tertullien, Augustin (Monique) ; Odilon de Cluny (998) ; Benoît XV 1915 trois messes ; rang n. 3, même un dimanche ; couleur ; préface « vita mutatur, non tollitur » ; indulgences 1-8 novembre ; 1 Th 4:13-14 ; purgatoire (lien).
Bilan : 6 exercices croisés.
