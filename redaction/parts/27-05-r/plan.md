# 27-05-r : Les martyrs (cours r du fichier 27-l-eglise-des-premiers-siecles.html)

Question centrale : qu'est-ce qu'un martyr, comment l'Église ancienne a-t-elle compris ce témoignage et comment l'a-t-elle honoré ?
Obstacles du novice : martyr = fanatique ou suicidaire (→ refus du martyre provoqué, fuite permise) ; récits = légendes (→ actes / passions, critères) ; catacombes = refuges (→ cimetières) ; culte des reliques = idolâtrie (→ « nous adorons le Christ, nous aimons les martyrs ») ; chiffres gonflés.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html

1. Le martyr, un témoin : grec martys, témoin au tribunal ; Actes 1:8, Luc 24:48 ; glissement vers le témoin du sang (Apoc 2:13 Antipas, Actes 22:20 Étienne) ; sens technique au IIe s. (Polycarpe, Lyon : martyrs / confesseurs) ; définition (mort, haine de la foi, acceptation) ; CEC 2473.
2. Le martyre dans le NT : le Christ témoin fidèle (Apoc 1:5 ; 1 Tim 6:13 ; Jean 18:37) ; annonces (Mt 10:17-22 ; Jean 15:20 ; Jean 16:2 ; Mt 10:39) ; Étienne (Actes 7:55-60) calqué sur la passion (Luc 23:34.46) ; Jacques (Actes 12:2) ; Pierre et Paul (Jean 21:18-19 ; 2 Tim 4:6-8) ; Apocalypse (6:9-11 ; 2:10 ; 12:11 ; 7:14) ; 2 Maccabées 7 en arrière-plan.
3. Ignace d'Antioche : vie, voyage, sept lettres (vers 107-110 ; datation discutée) ; Lettre aux Romains (froment de Dieu, disciple, imitateur de la passion, ne pas intervenir) ; martyre-eucharistie ; nuance : déjà condamné, pas provocateur.
4. Le Martyre de Polycarpe : lettre de Smyrne à Philomélium ; date (155/156, débat 167) ; récit (retrait à la campagne, arrestation, « 86 ans », bûcher, poignard) ; martyre « conforme à l'Évangile » ; Quintus (cité brièvement, lien l9) ; ch. 17 adorer / aimer ; ch. 18 os, jour natal ; premier récit.
5. Actes et passions : acta = procès-verbaux (Scillitains 180, Justin vers 165, Cyprien 258) ; passiones = récits amples (Perpétue ; passions épiques tardives, Agnès) ; valeur historique ; Ruinart, Bollandistes, Delehaye ; CEC 2474.
6. Lyon 177 : lettre des Églises de Vienne et Lyon (Eusèbe HE V,1-3) ; Pothin, Sanctus, Maturus, Attale, Blandine, Biblis, Ponticus, Alexandre ; Blandine en croix ; cendres au Rhône ; refus du titre de martyr ; réconciliation des tombés ; Irénée ; 48 noms (tradition).
7. Perpétue et Félicité (Carthage, 7 mars 203) : personnes, journal de Perpétue, vision de Saturus, rédacteur (Tertullien ? débat ; montanisme ? débat) ; père, cruche, baptême, visions (échelle, Dinocrate, Égyptien) ; Félicité « un autre en moi » ; mort ; Canon romain.
8. Laurent (10 août 258) : édits de Valérien, Sixte II et ses diacres (6 août), rôle du diacre (pauvres, biens) ; trésors de l'Église (Ambroise, De officiis II,28) ; gril (Ambroise I,41 ; Prudence) et doutes des historiens (décapitation probable) ; tombeau via Tiburtina, basilique, Depositio martyrum 354, Canon romain.
9. Confesseurs, martyre provoqué et fuite : confesseurs (Lyon ; Tradition apostolique 9 ; prestige et billets de paix, lien p) ; refus du martyre provoqué (Quintus ; Clément d'Alexandrie ; Elvire c. 60 ; Augustin « la cause ») ; fuite (Mt 10:23 ; Polycarpe ; Cyprien en 250 ; Tertullien rigoriste De fuga) ; discipline.
10. Baptême de sang et semence : Marc 10:38-39 ; Luc 12:50 ; Tertullien De baptismo 16 ; Cyprien ; Tradition apostolique 19 ; Saints Innocents ; CEC 1258 ; lien 68-le-bapteme#ouverture-n ; Tertullien Apologétique 50 (197) « semen est sanguis christianorum », sens ; Justin témoin converti ; débat des historiens sur la croissance.
11. Culte des martyrs : dies natalis (Polycarpe 18 ; Ignace « mon enfantement » ; Cyprien lettres 12 et 39 ; Depositio martyrum 354) ; tombeaux (memoria, trophées de Gaïus, martyrium), autel (Apoc 6:9 ; Ambroise 386 Gervais et Protase), reliques (Jérôme, Riparius ; abus ; Code théodosien 386 ; Carthage 401 ; Nicée II can. 7 ; CIC 1237) ; liens reliques / culte des saints.
12. Les catacombes : définition, nom (ad catacumbas), droit romain des sépultures, Calliste (lien o), crypte des papes ; ce qu'elles n'étaient pas (refuges) ; preuves ; origine du mythe (Fabiola, Quo vadis) ; Bosio, de Rossi ; Damase et ses inscriptions ; abandon et translations.
