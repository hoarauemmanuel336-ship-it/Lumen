# 64-03-p · La liturgie de la Parole (fichier 64-la-messe, lettre p)

Question centrale : pourquoi l'Église lit-elle l'Écriture à chaque messe, et comment cette première partie est-elle construite pour que le peuple entende le Christ et lui réponde ?
Obstacles du novice : croire que les lectures sont une « instruction » avant la messe proprement dite ; ne pas voir la logique du Lectionnaire (cycles, choix) ; confondre homélie et sermon / témoignage ; ne pas voir que Credo et prière universelle sont des réponses à la Parole.

Leçons (12) :
1. Le Christ qui parle quand on lit l'Écriture — SC 7, SC 33, PGMR 29, DV 21, VD 56 ; Néhémie 8 ; Luc 4 ; dialogue Dieu/peuple ; structure PGMR 55 ; lien 63-u (modes de présence).
2. La table de la Parole ouverte plus largement — SC 51, SC 35 ; Lectionnaire (Ordo lectionum missae 25 mai 1969 ; 2e éd. 21 janv. 1981) ; principe : lire au peuple les parties les plus importantes ; harmonie et lecture semi-continue (OLM 66-67) ; un seul ordre pour tout le rite romain ; PGMR 57 (pas de textes non bibliques) ; Jérôme (CEC 133).
3. Le cycle des dimanches sur trois ans — trois lectures (Prophète, Apôtre, Évangile, PGMR 357) ; A Matthieu, B Marc (+ Jean 6, OLM 105), C Luc ; Jean aux temps forts ; calcul de l'année ; même texte tous les quatre ans.
4. Le cycle de semaine sur deux ans — deux lectures ; temps ordinaire : 1re lecture sur 2 ans (année I impaire, II paire), Évangile annuel (Marc, Matthieu, Luc) ; temps forts : cycle annuel ; sanctoral et choix (PGMR 358-361).
5. La première lecture et son lien avec l'Évangile — AT ; harmonie (OLM 67) ; exemples 2 R 4/Jn 6 ; Is 35/Mc 7 ; temps pascal : Actes ; unité des deux Testaments (DV 16) ; lecteur, « Parole du Seigneur ».
6. Le psaume responsorial et la deuxième lecture — psaume : réponse, psalmiste, chanté, partie intégrante (PGMR 61), graduel ; deuxième lecture : Apôtre, lettres, semi-continue, indépendante, temps pascal 1 P / 1 Jn / Ap.
7. L'acclamation de l'Évangile — Alléluia (hébreu hallelou-Yah), Ps 146-150, Ap 19 ; debout, chanté ; verset ; Carême : verset avant l'Évangile ; trait ; séquence (PGMR 64) ; peut être omis s'il n'est pas chanté.
8. La proclamation de l'Évangile et ses honneurs — sommet (PGMR 60) ; diacre ou prêtre (PGMR 59) ; bénédiction du diacre / Munda cor meum (Is 6) ; procession, cierges, encens, Évangéliaire, signes de croix, acclamations, baiser (« Per evangelica dicta… »), bénédiction par l'évêque (PGMR 175).
9. L'homélie — mot grec homilia ; SC 52, PGMR 65-66 ; réservée au ministre ordonné (can. 767) ; but et contenu ; Luc 4, Luc 24 ; EG 135-138 ; VD 59 ; obligatoire dimanche.
10. Le silence après les lectures et l'homélie — PGMR 56 ; OLM 28 ; VD 66 ; SC 30 ; nature du silence ; Luc 2:19 ; 1 S 3:10.
11. La profession de foi — PGMR 67-68, 137 ; Nicée-Constantinople ou Symbole des Apôtres (Carême, temps pascal) ; dimanches et solennités ; inclinaison ; histoire (Constantinople VIe s., Tolède 589, Gaule carolingienne, Rome sous Benoît VIII) ; « consubstantiel » 2021 ; Rm 10:9-10.
12. La prière universelle — SC 53, PGMR 69-71 ; 1 Tm 2:1-4 ; ordre des intentions ; sacerdoce baptismal ; Justin ; Vendredi saint ; forme : invitation, intentions, réponse, oraison.
Bilan : 6 exercices croisés.
