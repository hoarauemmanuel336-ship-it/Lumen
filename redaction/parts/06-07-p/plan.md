# 06-07-p · Les prédicables et la définition (lettre p)

Question centrale : comment dire exactement ce qu'est une chose, et de quelles manières un mot peut-il se dire d'une autre chose ?
Obstacles du novice : confondre espèce logique et espèce biologique ; prendre le propre pour l'essence ; confondre accident prédicable et accident prédicamental (catégories) ; croire qu'une définition est une description quelconque ; croire que tout se définit (Dieu, l'individu) ; divisions qui se recoupent.

Leçons (10) :
1. Les cinq manières de dire une chose d'une autre : prédication, universel, Porphyre et l'Isagogè (Chrysaorius, Boèce), les cinq prédicables comme ensemble, leur déduction (essence entière / partie commune / partie propre ; hors essence nécessaire / contingent), Aristote et ses quatre prédicables (Topiques I), prédicables ≠ catégories (lien 07 d), ce que la foi en reçoit.
2. Le genre et l'espèce : définitions de Porphyre (« qu'est-ce ? »), genre suprême, genres subalternes, espèce spécialissime, notions relatives ; espèce logique ≠ espèce biologique ; Genèse 1 « selon leur espèce » ; individu sous l'espèce ; Dieu hors de tout genre (rappel lien 07 d).
3. La différence spécifique : « quel ? » ; trois sens de Porphyre (commune, propre, très propre) ; divisive et constitutive ; raisonnable ; différences essentielles souvent inconnues, signes accidentels (Thomas I q.29 a.1 ad 3) ; anges, chacun son espèce (I q.50 a.4).
4. Le propre et l'accident : quatre sens du propre (médecin, bipède, blanchir, risible) ; propre au sens strict, convertible, découle de l'essence ; accident prédicable : présent ou absent sans corruption du sujet ; séparable / inséparable ; prédicable ≠ prédicamental (lien 07 s) ; communication des idiomes ; en Dieu ni propre ni accident réels.
5. L'arbre de Porphyre : texte de Porphyre (substance → corps → corps animé → animal → animal raisonnable → homme → Socrate, Platon) ; figure (zone libre) ; lecture de haut en bas / de bas en haut ; ce que l'arbre montre et ses limites ; anges et Dieu.
6. Définir et la définition nominale : définition = discours qui dit ce qu'est une chose (Aristote, Topiques I, 5) ; de-finire, borner ; nominale / réelle ; définition nominale par étymologie, synonyme, usage ; son rôle (I q.2 a.2 ad 2, « ce que signifie le nom ») ; Adam nomme les animaux (Genèse 2:19-20) ; l'individu ne se définit pas ; « définir » un dogme.
7. Les définitions réelles : essentielle (genre prochain + différence ; pourquoi prochain), métaphysique et physique ; descriptive (propriétés, accidents) ; causale (efficiente, finale ; éclipse, scie) ; hiérarchie et usage.
8. Les quatre règles de la définition : plus claire ; convertible (Platon et le bipède sans plumes, Diogène Laërce VI, 40) ; défini hors de la définition (le soleil astre du jour, Topiques VI, 4) ; positive quand possible (point d'Euclide, aveugle, Dieu : voie négative, lien 09 t) ; tester une définition.
9. La division : diviser un tout ; tout universel, essentiel, intégral, potestatif ; division par soi et par accident ; Platon (Phèdre 265e, le mauvais boucher) ; dichotomie et critique d'Aristote ; quatre règles (complète, un seul principe, parties qui s'excluent, ordonnée) ; divisions théologiques (lois I-II q.91 ; grâce I-II q.111 a.1).
10. Les définitions au service de la théologie : personne (Boèce ; analyse ; I q.29 a.1 et a.3 ad 4 ; lien 07 n) ; sacrement (Augustin, Cité de Dieu X, 5 ; Thomas III q.60 a.1-2 ; Catéchisme 1131 ; lien 67 l) ; vertu (Aristote EN II, 5-6 ; définition de Pierre Lombard tirée d'Augustin analysée par les quatre causes, I-II q.55 a.4 ; Catéchisme 1803 ; lien #sujet:mor.vertus).
