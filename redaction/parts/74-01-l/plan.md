# Plan du cours 74-01-l : Le mariage dans le dessein du Créateur

Cours l du fichier 74-le-mariage.html (premier cours : introduction avec construction commune + présentation des cours m, c, u, i, f, e).
Vouvoiement. Versets de la Chérubin (Tobie suit la Vulgate : trois nuits de prière, « ce n'est pas pour satisfaire ma passion »).
Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html

Question centrale : pourquoi l'Église dit-elle que le mariage vient de Dieu et qu'il existait avant d'être un sacrement, et que dit l'Ancien Testament du mariage tel que Dieu l'a voulu, blessé, puis éduqué ?

Vérifié en ligne (vatican.va) : CEC 1602-1611 (extraits), 369, 372 ; GS 12, 47, 48, 50 ; FC 11, 13 ; MD 6, 7, 10 ; DCE 6, 11 ; AL 10-13 ; Arcanum 19 (anglais) ; DV 15 ; Thomas Suppl. q.42 a.2 ; Ia q.92 a.1 et a.3 (newadvent).

1. Le mariage, réalité de la création avant d'être sacrement — question de l'ancienneté ; « au commencement » (Mt 19:4.8 cité, lien m) ; CEC 1602-1603 (Écriture s'ouvre et s'achève sur des noces ; Dieu auteur ; vocation inscrite dans la nature ; pas institution purement humaine) ; GS 48 ; mariage naturel / mariage sacrement ; Thomas, quatre institutions (Suppl. q.42 a.2) ; les quatre étapes du Catéchisme (création, péché, pédagogie de la Loi, dans le Seigneur) ; bénédiction nuptiale (« sola quae nec per originalis peccati poenam… ») ; Arcanum 19 ; plan du cours.
2. L'homme et la femme créés à l'image de Dieu — Gn 1:26-28 lu de près (tselem, demut, 'adam, zakar u-neqebah) ; singulier/pluriel ; égalité (CEC 369, MD 6) ; Dieu ni homme ni femme ; communion des personnes (GS 12, MD 7, CEC 372) ; FC 11 vocation à l'amour ; AL 10 ; deux lectures de l'image (âme raisonnable, communion) : doctrine et développement ; Gn 1:31 ; Gn 5:1-2.
3. « Il n'est pas bon que l'homme soit seul » : la création de la femme — Gn 2:18-22 ; second récit, autre style ; solitude originelle ; nommer les animaux ; 'ezer kenegdo (secours de Dieu : Ps 121:1-2, Ps 33:20) ; sommeil (tardémah, Gn 15:12) ; côte/côté (tsela') ; Thomas Ia q.92 a.3 (ni tête ni pieds ; côté du Christ, Jn 19:34) ; Dieu amène la femme ; Thomas « aide pour la génération » et lecture élargie (MD 7, CEC 371-372).
4. « Une seule chair » — Gn 2:23-25 ; premier cri de l'homme ; os et chair (Gn 29:14, 2 S 5:1) ; 'ish/'ishshah ; « c'est pourquoi » : de l'origine à la norme ; quitter (priorité du lien conjugal) ; s'attacher (dabaq : Dt 10:20, Ruth 1:14) ; une seule chair (union des corps et des vies) ; nudité sans honte ; reprise par le Christ et Paul (Mt 19:5-6 ou Ep 5:31-32, lien m) ; AL 13.
5. La bénédiction de la fécondité — Gn 1:22 et 1:28 (bénédiction avant précepte) ; Gn 4:1 (« avec l'aide du Seigneur »), Gn 5:3 ; Gn 9:1 ; promesse à Abraham (Gn 12:2, 15:5) ; Ex 1:7 ; Ps 127:3-5, 128:3 ; stérilité (Gn 25:21, 30:1-2, 30:22-23 ; 1 S 1 ; Ps 113:9) ; GS 50 (don le plus excellent ; coopérateurs) ; CEC 372 ; précepte donné à l'espèce (Thomas IIa-IIae q.152 a.2) ; fécondité plus large que la génération ; lien f.
6. Le mariage blessé par le péché — Gn 3:7-13 (honte, peur, accusation) ; Gn 3:16 (peines, teshuqah, mashal) : conséquence et non commandement (MD 10) ; Gn 4:7 ; CEC 1606-1607 ; convoitise (Mt 5:28, 1 Jn 2:16) ; Lamek (Gn 4:19-24) ; ce qui demeure : CEC 1608, Gn 3:20-21, bénédiction nuptiale ; CEC 1609 (repliement) ; liens péché originel, concupiscence ; remède : lien f.
7. La polygamie des patriarches et des rois, et la pédagogie de Dieu — monogamie des origines (Adam et Ève, Noé Gn 7:13) ; Lamek ; Abraham et Agar (Gn 16:1-6), Jacob (Gn 29:30-31 ; 30:1 ; 30:15), Elqana (1 S 1:6), Gédéon (Jg 8:30), David (2 S 5:13 ; 12:7-9), Salomon (1 R 11:1-4) ; Loi qui encadre (Ex 21:10 ; Dt 21:15 ; Dt 17:17) ; idéal monogame dans les sages (Pr 5:18-19 ; Pr 31:10-12 ; Si 26:1-3 ; Qo 9:9 ; Gn 24:67) ; CEC 1610 (« pas encore explicitement critiquée ») ; DV 15 ; Augustin et Thomas (opinions) ; lien u.
8. La répudiation permise par la Loi et la parole de Malachie — Dt 24:1-4 lu de près ('erwat dabar ; acte de répudiation ; interdiction du retour) ; ce que la loi fait (protéger : CEC 1610) ; Hillel et Shammai (Mishna Gittin 9:10) ; usage prophétique (Jr 3:1, 3:8 ; Is 50:1) ; Si 7:26 ; Malachie 2:10-16 (contexte, femme de ta jeunesse, femme de ton alliance, témoin, un seul être, « je hais la répudiation ») ; Esdras 10:3 (autre cas) ; Pr 2:17 ; Mt 19:8 (lien m, i).
9. L'Alliance comme un mariage chez les prophètes — Osée 1:2 ; 1:6.9 ; 3:1 ; 2:16-25 lu de près ('ishi/ba'li ; fiançailles ; cinq dons comme dot : justice, droit, amour, tendresse, fidélité) ; Jr 2:2 ; 31:31-32 ; Is 54:5-8 ; 62:4-5 ; Ez 16:8, 16:60 ; CEC 1611 ; lecture à double sens (le mariage éclaire l'Alliance, l'Alliance réforme le mariage) ; Nouveau Testament (Mc 2:19, Jn 3:29, Ap 19:7-9 ; lien m).
10. Le Cantique des cantiques et l'amour humain — titre, forme, Salomon, Sulamite (7:1) ; Dieu presque absent (8:6 « flamme du Seigneur ») ; canonicité (Aqiba, Yadayim 3:5) ; lectures : allégorique (Origène, Bernard), littérale ; CEC 1611 (« expression unique de l'amour humain en tant qu'il est reflet de l'amour de Dieu ») ; textes : 2:10-16, 4:9-12, 6:3, 7:11 (renversement de Gn 3:16), 2:7, 8:6-7 ; DCE 6 (dodim/ahabah) ; Jean-Paul II, catéchèses de 1984 ; lien chastete.theologie-corps.
11. Le livre de Tobie et la prière des époux — livre deutérocanonique, deux familles, deux détresses (Tobie 3:7-17) ; Raphaël ; Tobie 6:10-18 (mariage selon Dieu, contre la passion sans Dieu) ; 7:9-16 (demande, main droite, bénédiction, acte écrit) ; 8:1-10 (prière : bénédiction, mémoire de la création, droiture d'intention, pitié, vieillir ensemble) ; 8:15-19 ; 10:13 ; texte grec et texte latin ; « nuits de Tobie » (usage médiéval, doute) ; Ruth (CEC 1611 ; Ruth 1:16-17, 4:13) ; Tobie dans le lectionnaire du mariage (doute) ; lien 15 #ouverture-t.
12. Le mariage, institution naturelle commune à tous les peuples — Gn 12:18-19 ; 20:3 ; 26:10-11 ; 39:9 ; Rm 2:14-15 ; CEC 1603 (variations, traits communs, « un certain sens pour la grandeur de l'union matrimoniale ») ; GS 47 (« ne brille pourtant pas partout du même éclat ») ; Arcanum 19 (Innocent III et Honorius III) ; loi naturelle ; droit romain (Modestin) ; Code de 1983 canon 1055 (communauté de toute la vie, lien f/m) ; mariage entre non-baptisés vrai mariage ; devient sacrement au baptême des deux (lien m) ; l'État reconnaît sans créer (lien 93 #ouverture-l) ; Déclaration universelle des droits de l'homme, art. 16.3 ; réponse à la question du cours.
Bilan : 6 exercices croisés.
