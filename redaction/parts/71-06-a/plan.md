# Plan du cours 71-06-a « L'absolution et le ministre » (fichier 71, lettre a)

Question centrale : qui peut dire « Je t'absous », avec quelles paroles, à quelles conditions, et comment ce pouvoir s'exerce (juge, médecin, père ; refus ; absolution collective).
Obstacles du novice : croire que la prière qui précède est la « vraie » absolution ou que seule la formule latine vaut ; croire qu'une formule en forme de prière (Orient) est moins efficace ; croire que tout prêtre peut toujours absoudre (faculté) ; confondre péché réservé et censure réservée ; voir le refus d'absolution comme une condamnation ; prendre l'absolution collective pour une option ordinaire.

Leçons (une par fichier, 01.html à 12.html ; 00-ouverture.html ; 99-bilan.html) :
1. La formule d'absolution du rite latin : texte complet (CEC 1449, Ordo paenitentiae 1973, Rituel français 1978), structure trinitaire, pascale, ecclésiale ; gestes (mains étendues, signe de croix, Amen) ; place dans le rite ; formules du Rituel romain ancien (Misereatur, Indulgentiam, Passio Domini).
2. Les paroles essentielles : « Je te pardonne tous tes péchés, au nom du Père… » ; forme du sacrement (Trente XIV ch. 3) ; le « je » in persona Christi (2 Co 2:10) ; le « te » personnel ; « tous » ; « au nom du Père » (Mt 28:19) ; latin absolvere « délier » ; validité (sens, voix, présence) ; forme brève en danger de mort.
3. Les formules orientales déprécatives : CEC 1481, formule byzantine (Nathan/David, Pierre, pécheresse…) ; « par moi, pécheur » ; formule slave (Pierre Moghila) ; épitrachilion ; efficacité d'une prière de l'Église ; Trente n'exige pas l'indicatif hors du rite latin ; lien vers 71-02 pour l'histoire occidentale.
4. Le ministre : évêque et prêtres. Jn 20:21-23 rappelé (lien l) ; Trente XIV ch. 6 et canon 10 ; can. 965 ; CEC 1461-1462 (évêque modérateur) ; pourquoi ni diacre ni laïc ; prêtre pécheur absout validement ; obligation de disponibilité (can. 986, CEC 1464).
5. La faculté d'entendre les confessions : pouvoir d'ordre et faculté (can. 966) ; raison (acte judiciaire, juridiction, Trente ch. 7) ; de droit (967 §1 : pape, cardinaux, évêques), par office (968 : Ordinaire du lieu, chanoine pénitencier, curé), par concession (969-970) ; validité partout (967 §2) ; révocation (974) ; suppléance (can. 144).
6. Le danger de mort : can. 976 ; Trente ch. 7 (« nulla sit reservatio in articulo mortis ») ; ce qu'est le danger de mort ; même prêtre sans faculté, même en présence d'un prêtre approuvé ; complice (977) ; obligation de recours après (1357 §3) ; can. 986 §2 ; absolution sous condition au mourant inconscient ; contrition parfaite sans prêtre (lien c) ; viatique (lien 72-v).
7. Péchés et censures réservés : notion de réservation (Trente ch. 7, can. 11) ; péchés réservés d'hier (Code 1917) et d'aujourd'hui en Orient (CCEO 728) ; droit latin : censures ; censure = peine médicinale ; latae sententiae ; les six excommunications réservées au Siège apostolique (1370 §1, 1379 §3, 1382 §1, 1384, 1386 §1, 1387) ; non réservées (avortement, Misericordia et misera 2016) ; can. 1357 (cas urgent, recours d'un mois).
8. La Pénitencerie apostolique : for interne / externe, sacramentel / non sacramentel ; histoire (fin XIIe s., Honorius III, Pie V 1569, Benoît XIV 1744, Pie X, Benoît XV indulgences) ; Praedicate Evangelium art. 190-193 ; pénitenciers des basiliques ; recours du confesseur sous noms d'emprunt ; rappel du sceau en une phrase (lien p).
9. Le confesseur juge, médecin et père : can. 978 §1 ; Trente (ad instar actus iudicialis) ; RP 31 « tribunal de miséricorde » ; Augustin « soigner et non accuser » ; CEC 1465-1466 ; saint Alphonse (père, médecin, docteur, juge) ; can. 979 ; Ga 6:1 ; Hé 5:1-2 ; EG 44.
10. Refus ou report de l'absolution : Jn 20:23 (retenir) ; can. 980 ; raisons (absence de contrition ou de propos, refus de restituer, de quitter l'occasion prochaine, de pardonner ; censure réservée sans cas urgent ; MD 7c) ; report médicinal ; le doute favorable ; bénédiction et accompagnement ; ce que le refus n'est pas.
11. L'absolution collective : can. 960-963 ; CEC 1483-1484 ; RP 32-33 ; troisième forme du Rituel (lien h) ; deux cas (danger de mort ; grave nécessité aux deux conditions inséparables) ; jugement de l'évêque ; dispositions du fidèle (propos de confession individuelle, can. 962-963) ; exhortation à la contrition ; mars 2020 (Pénitencerie, pandémie).
12. Le motu proprio Misericordia Dei (7 avril 2002) : contexte (crise, recours abusif à l'absolution générale ; Novo millennio ineunte) ; normes 1 à 9 ; précisions sur la grave nécessité (moins d'un mois n'est pas « longtemps ») ; norme 7 c ; confessionnal à grille fixe ; vaut aussi pour les Églises orientales catholiques.
