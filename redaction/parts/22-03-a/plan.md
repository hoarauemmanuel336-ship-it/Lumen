# 22-03-a — L’autorité du consensus des Pères (lettre a, fichier 22-la-patristique.html)

Question centrale : pourquoi l’accord des Pères sur un point de foi engage-t-il l’Église, alors qu’un Père seul, même saint, peut se tromper ?
Obstacles du novice : tout recevoir d’un Père / ne rien recevoir des Pères ; « unanime » pris au sens arithmétique ; consensus = majorité ; science des Pères confondue avec leur foi ; croire que Trente interdit de lire la Bible.

Leçons (fichiers 01.html à 11.html) :
1. Un Père seul, les Pères ensemble — opinion isolée / consensus unanime ; mots consensus, unanimis ; Vincent de Lérins, Commonitorium 28 (434) ; Thomas I, q.1, a.8 ad 2 (probable) ; deux erreurs opposées.
2. Témoins, non auteurs — fondement : Tradition apostolique ; Augustin, Contre Julien II, 10, 34 ; Tertullien, Prescription 28 ; Origène, Des principes, préf. 2 ; Basile, Esprit Saint 7, 16 et 29, 71 ; pourquoi la convergence prouve.
3. Le décret de Trente (8 avril 1546) — contexte, texte traduit, analyse, règle négative, foi et mœurs, pourquoi les Pères à côté de l’Église.
4. De Pie IV à Vatican I — profession de foi tridentine (Iniunctum nobis, 13 nov. 1564), formule positive ; Dei Filius ch. 2 (24 avril 1870) ; Léon XIII, Providentissimus Deus (DH 3284) ; Pie XII, Divino afflante Spiritu (peu de textes).
5. Première condition : l’unanimité morale — définition, mesure (tous ou la plupart, Orient et Occident, époques, pas d’opposition sérieuse) ; exemple du baptême des petits enfants (Irénée II,22,4 ; Origène ; Cyprien Ep. 64 ; Tertullien Baptême 18) ; consensus ≠ majorité.
6. Deuxième et troisième conditions — matière de foi ou de mœurs ; cas Galilée (Bellarmin 1615, paraphrase) ; enseigné comme de foi (signes) ; opinion d’école ; Genèse 6:2 (anges / fils de Seth).
7. Les opinions personnelles des Pères (theologoumena) — définition ; Origène préf. 3 ; Augustin sur l’origine de l’âme ; Jérôme et Augustin sur Galates 2 ; Augustin Lettre 82, 1, 3 ; saint et docteur sans infaillibilité ; erreurs écartées (Origène 543/553 ; Augustin sur la grâce, Orange 529).
8. La science et l’histoire des Pères — Providentissimus Deus (DH 3289) ; phénix (1 Clément 25) ; Augustin, Genèse au sens littéral I, 19, 39 ; légende des Septante (Irénée, Augustin / Jérôme) ; Pseudo-Denys.
9. Les florilèges des conciles anciens — Athanase, Décrets de Nicée 27 ; Basile 29 ; Éphèse 431 (liste de Vincent, faux apollinaristes) ; Chalcédoine 451 (« Suivant les saints Pères ») ; limites et critique.
10. Dei Verbum 8 et le ressourcement — DV 8 traduit, DV 23, Optatam totius 16 ; ressourcement (Newman, Möhler, de Lubac 1938, Sources chrétiennes 1942, Daniélou 1946) ; ce qu’il change à l’usage des Pères.
11. Un consensus et une opinion — virginité perpétuelle (Origène, Jérôme Contre Helvidius 19, Augustin, 553, 649 ; Tertullien et Helvidius) ; millénarisme (Papias, Justin Dial. 80, Irénée, Eusèbe, Augustin CD XX,7 ; 1944, CEC 676) ; tableau des trois conditions.
Bilan : 6 exercices croisés.
