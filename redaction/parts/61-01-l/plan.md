# Plan 61-01-l « Marie, nouvelle Ève » (lettre l, premier cours du fichier 61)

Question centrale : pourquoi les Pères ont-ils pensé Marie à partir d'Ève, et pourquoi ce parallèle porte-t-il toute la réflexion de l'Église sur elle (jusqu'aux dogmes de 1854 et 1950) ?
Obstacles du novice : croire que le parallèle est une image pieuse tardive ; croire qu'il met Marie à égalité avec le Christ ; ignorer qu'il vient de Paul (Adam/Christ) ; confondre « cause du salut » chez Irénée avec la Rédemption ; lire « Femme » comme mépris ; croire que l'argument « démontre » les dogmes.

Sources vérifiées : LG 55, 56, 58, 61, 62, 63 (vatican.va fr) ; Justin Dial. 100, Irénée AH III 18, 1 et 7 ; III 21, 10 ; III 22, 3-4 ; V 19, 1 ; V 21, 1 ; Tertullien De carne Christi 17 ; Jérôme Lettre 22, 21 (newadvent) ; Ineffabilis Deus (papalencyclicals, anglais) ; Munificentissimus Deus 39-40 (vatican.va anglais) ; CEC 411 (résumé) ; RM 19, 24 (fragments).

Leçons :
0. Ouverture : intro (cours, enchaînement, construction commune + code-l, autres cours i h s a d).
1. Adam et le Christ chez saint Paul : Rm 5:12-21 (figure, combien plus, désobéissance/obéissance), 1 Co 15:21-22, 45-49 ; typologie ; Ève chez Paul (2 Co 11:3, 1 Tm 2:13-14) ; Ga 4:4 ; le pas que franchiront les Pères.
2. Saint Justin, Dialogue avec Tryphon 100 : Justin, l'œuvre, le texte (traduction d'après l'anglais), « par la même voie », concevoir la parole, foi et joie ; première attestation (vers 155-160) ; ce qu'elle laisse supposer.
3. Saint Irénée, le nœud : Irénée, gnostiques ; AH III 22, 4 (vierge fiancée, cause de mort / cause du salut, nœud, incrédulité / foi) ; LG 56 ; sens de « cause du salut » ; V 19, 1 avocate d'Ève.
4. La récapitulation : anakephalaiôsis (Ep 1:10), III 18, 1 et 7 ; terre vierge / Vierge (III 21, 10) ; généalogie de Luc (III 22, 3) ; arbre (V 19, 1) ; Gn 3:15 (V 21, 1) ; Démonstration 33 (Ève récapitulée en Marie) ; Marie avec lui.
5. Tertullien, De carne Christi 17 : contexte, terre vierge, l'oreille, parole du diable semence, Caïn / Sauveur, « croire » des deux côtés, opération rivale ; limites de Tertullien.
6. Les éléments du parallèle : deux vierges, un ange, une parole, désobéissance / obéissance (et incrédulité / foi), tableau ; inversion ; ce que le parallèle ne dit pas (égalité, épouse) ; coopération libre (LG 56).
7. « La mort par Ève, la vie par Marie » : Jérôme, Lettre 22, 21 ; Cyrille de Jérusalem, Épiphane ; LG 56 ; Ave / Eva (Ave maris stella) ; la vie = le Christ.
8. Le titre de « Femme » : Jn 2:4 et 19:26 ; usage (Jn 4:21, 20:15, Mt 15:28) ; étrangeté pour une mère ; l'heure ; Gn 2:23, 3:15, Jn 16:21, Ap 12 ; RM 24 ; degré : lecture théologique ; objections.
9. Mère des vivants dans l'ordre de la grâce : Gn 3:20 (Hawwah) ; Épiphane ; LG 56, 61, 62, 63 ; Jn 19:27 ; Ap 12:17 ; nature / grâce ; renvoi à 62 (mère de l'Église, médiation).
10. Argument des définitions : nature d'un argument de convenance tiré de la Tradition ; Ineffabilis Deus (Ève avant la chute, Marie au-dessus d'Ève, Gn 3:15 inimitié totale) ; Newman (1866) ; Munificentissimus Deus 39-40 ; degré d'autorité (la définition, non les raisons) ; liens #ouverture-i, #ouverture-a.
