# 10-04-n Plotin et le néoplatonisme (lettre n) : plan

Sous-titre : La philosophie de l'Un, ce qu'elle a donné à la pensée chrétienne et ce que la foi a dû y corriger
Question centrale : qu'a pensé Plotin (tout vient de l'Un et y retourne), pourquoi les chrétiens y ont trouvé une langue, et où la foi s'en sépare (création libre, Trinité égale) ?
Obstacles : néoplatonisme = école qui se disait nouvelle ; Un = Dieu chrétien ; émanation = création ; hypostases = Personnes ; extase = mystique chrétienne ; matière mauvaise = corps méprisé.
12 leçons + bilan (6 exercices). Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. Le néoplatonisme et la vie de Plotin : nom moderne (les intéressés se disent platoniciens ; V, 1, 8 exégètes de Platon) ; IIIe-IVe s., prolongé jusqu'au VIe ; Vita Plotini : naissance vers 205 (Lycopolis selon Eunape), 28 ans, Ammonius Saccas, 11 ans ; Gordien III (242-244) ; Rome 244 ; pacte Érennius-Origène ; écrit à partir de 254 ; enseignement (séminaire, lectures de commentaires, Vita 14) ; disciples (Amélius, Porphyre 263, Eustochius, Rogatianus) ; tuteur d'orphelins ; Platonopolis ; honte d'être dans un corps (Vita 1) ; mort 270 (dernières paroles, Vita 2, leçon discutée). Mots : Néoplatonisme, Ammonius Saccas, Hypostase (réservé L3?) non ; Vita Plotini.
2. Les Ennéades : 54 traités, écrits 254-270 (21/24/9) ; Porphyre éditeur vers 300-301 (Vita 24-26) ; six groupes de neuf, ordre des matières, nombres parfaits, découpages ; titres ; ordre chronologique et numéros entre crochets ; manière de citer ; style (Vita 8) ; plan : I morale, II-III monde, IV âme, V Intellect, VI être, nombre, Un ; transmission (Théologie d'Aristote, Ficin 1492, Bouillet, Bréhier, Henry-Schwyzer). Mots : Ennéade, Traité, Ordre chronologique, Théologie d'Aristote.
3. L'Un : par l'un tout être est être (VI, 9, 1) ; le multiple suppose l'un ; au-delà de l'être (République 509b) et de la pensée (dualité) ; on dit ce qu'il n'est pas (V, 3, 14), Apollon (V, 5, 6) ; Bien, Premier, puissance de toutes choses (III, 8, 10 source) ; « tout et rien » (V, 2, 1) ; liberté (VI, 8) ; jugement : Exode 3:14, l'Être même, Dieu qui se connaît ; théologie négative reprise (lien 09 t). Mots : L'Un, Au-delà de l'être, Théologie négative, Puissance de toutes choses.
4. L'Intellect : naissance (V, 2, 1 ; V, 1, 7) ; regard tourné vers l'Un ; Intellect = être (Parménide) ; Idées dans l'Intellect (V, 5) ; unité-multiplicité (« tout est en tout ») ; éternité (III, 7 ; Boèce) ; le dieu d'Aristote mis au second rang ; jugement : Idées dans l'intelligence divine (Augustin, lien p), mais Intellect inférieur à l'Un → question du Verbe. Mots : Intellect (noûs), Intelligible, Éternité, Seconde hypostase.
5. L'Âme : troisième hypostase ; Âme du monde, âmes particulières, nature ; temps vie de l'âme (III, 7, 11) ; corps dans l'âme (IV, 3, 22) ; descente (IV, 8), audace (V, 1, 1), part non descendue (IV, 8, 8) ; contemplation (III, 8) ; jugement : âme créée, non parcelle d'une âme du monde, forme du corps (Vienne, lien 08 a), part non descendue écartée. Mots : Âme du monde, Nature (physis), Descente de l'âme, Audace (tolma).
6. Procession et conversion : images (soleil, feu, neige, parfum, source V, 1, 6 ; III, 8, 10) ; débordement (V, 2, 1) ; l'Un demeure ; le produit inférieur ; conversion (epistrophê) qui constitue chaque degré ; contemplation et production (III, 8) ; retour moral ; nécessité (V, 4, 1) et sa nuance ; mot « émanation » ; jugement : Romains 11:36, plan de la Somme (lien s). Mots : Procession, Conversion, Émanation, Demeure.
7. Le mal et la matière : matière dernier degré, indéterminée, non-être (II, 4 ; I, 8) ; mal premier (I, 8, 3), privation ; mal de l'âme ; débat sur l'origine de la matière ; contre les gnostiques (II, 9) : beauté du monde ; jugement : Augustin privation (Conf. VII, 12, 18), mais matière créée et bonne (Genèse 1:31), Denys DN IV, Thomas I q. 48-49 ; liens 42 p. Mots : Matière, Privation, Mal premier, Gnostiques.
8. L'union à l'Un et l'extase : purification et vertus (I, 2) ; ascension du beau (I, 6) : patrie (I, 6, 8), statue (I, 6, 9) ; « retranche tout » (V, 3, 17) ; union VI, 9, 9-11, extase, fuite du seul vers le Seul ; Porphyre : quatre fois (Vita 23) ; jugement : union par grâce, vision béatifique (1 Jean 3:2 ; Benoît XII ; Vienne contre les béghards), distinction mystique naturelle/surnaturelle ; Ostie (lien 26). Mots : Purification, Union, Extase, Simplification.
9. Porphyre et Proclus : Porphyre (vers 234-vers 305), Tyr, Malchus ; œuvres (Isagoge, Vie, Lettre à Marcella, Abstinence, Philosophie des oracles) ; Contre les chrétiens (15 livres, Daniel, Antioche, fragments, Constantin et 448) ; Jamblique et théurgie ; Proclus (412-485), Éléments de théologie (prop. 1, 7, 35), triades, hénades ; Contre les chrétiens sur l'éternité du monde ; Liber de causis (Thomas 1272) ; Damascius et 529 (lien c). Mots : Isagoge, Contre les chrétiens, Théurgie, Éléments de théologie, Livre des causes.
10. Augustin et les livres des platoniciens : Milan 386, Victorinus traducteur (VIII, 2, 3), Plotin et/ou Porphyre (débat ; Vie heureuse 1, 4) ; ce qu'ils lui ont ouvert : Dieu esprit, retour intérieur (VII, 10, 16), mal privation, Verbe (VII, 9, 13 ; Jean 1:1-3) ; ce qui manquait : Verbe fait chair (Jean 1:14), humilité (Philippiens 2:7-8), présomption et confession (VII, 20, 26) ; Cité de Dieu IX, 17 ; X, 29 (lettres d'or) ; Révisions I, 1, 4 ; liens 26 c, 26 p. Mots : Livres des platoniciens, Présomption, Confession, Médiateur.
11. Le Pseudo-Denys et la mystique chrétienne : Denys lecteur de Proclus (lien 24 p) ; vocabulaire (hyperousios, proodos, epistrophê, henôsis, ekstasis) ; Théologie mystique I, 1 (rayon de ténèbre) ; Moïse dans la nuée (Exode 20:21) ; transformations (Trinité, création, Christ, Église) ; passage : Ambroise, Grégoire de Nysse (avant), Érigène (vers 862), Victorins, Thomas, Bonaventure, Nuage d'inconnaissance, Jean de la Croix ; Ficin. Mots : Suressentiel, Ténèbre divine, Théologie mystique, Corpus dionysien.
12. Les deux différences décisives : création libre contre émanation nécessaire (V, 4, 1 ; VI, 8 nuance ; Vatican I canons 4-5 ; CEC 285, 295-296 ; Apocalypse 4:11 ; Thomas I q. 19, a. 3 ; q. 45 a. 1) ; Trinité égale contre hypostases hiérarchisées (Porphyre chez Augustin X, 23 et 29 ; Arius « porphyriens » ; Nicée homoousios, lumière née de la lumière ; Quicumque ; Jean 10:30 ; hypostase changée de sens ; Thomas I q. 32 a. 1 ad 1 ; Victorinus) ; bilan : langue reçue, sens corrigé. Mots : Création libre, Émanation nécessaire, Consubstantiel, Subordinatianisme.
Bilan : 6 exercices croisés.
