# 59-03-i · L'intercession des saints (fichier 59, lettre i)

Question centrale : pourquoi et comment les saints du ciel prient-ils pour nous, et que fait le fidèle qui leur demande de prier pour lui ?
Obstacles du novice : croire qu'intercéder = accorder soi-même une grâce ; croire que « un seul médiateur » interdit toute intercession ; croire que les morts ne savent rien de nous ; prêter aux saints l'omniscience ; confondre invocation et adoration ; voir dans les patrons des « dieux spécialisés » ; imaginer le ciel comme un repos où l'on oublie la terre.

Recherche web épuisée : vérifications faites sur vatican.va (Lumen gentium 49, 50, 51, 60, 62 ; CEC 956, 2634-2636, 2156) ; le reste paraphrasé sans guillemets, doutes dans doutes.md.

Leçons (un fichier chacune) :
1. Intercéder : se tenir entre (intercedere, enteuxis/entynchanô ; CEC 2634-2635 ; Abraham Gn 18, Moïse Ex 32 et Ps 106:23, Samuel 1 S 12:23 ; le Christ Hé 7:25, Rm 8:34 ; l'Esprit Rm 8:26-27 ; intercession / invocation / médiation).
2. Prier les uns pour les autres sur la terre (Jc 5:16-18, 1 Tm 2:1-4, Paul qui demande et offre des prières, Épaphras, Actes 12:5 ; Mc 2:3-5 ; pourquoi Dieu le veut : Thomas II-II q.83 a.2, Pascal ; la prière du juste ; CEC 2635-2636).
3. Un seul médiateur et la participation des créatures (1 Tm 2:5-6 ; mesitès ; Christ médiateur en tant qu'homme ; LG 60, 62 ; Thomas III q.26 a.1 ; 1 Co 3:9, Jn 15:5 ; médiation de rédemption / médiation d'intercession ; degrés d'autorité ; liens Marie et objections).
4. Les prières des saints devant le trône (Ap 5:8, 8:3-4, Ps 141:2 ; les Anciens ; Tb 12:12, Za 1:12 ; Ap 6:9-11 ; Hé 12:1, 22-23 ; Lc 15:7,10 ; lire l'Apocalypse).
5. Jérémie, l'ami de ses frères (2 M 15:11-16 ; Onias III ; Jérémie intercesseur de son vivant Jr 18:20, 42:2-4, interdit Jr 7:16 ; Jr 15:1 ; canon deutérocanonique ; valeur de témoin).
6. Le témoignage des catacombes et de la liturgie ancienne (inscriptions « pete / roga pro nobis » ; graffiti de la Memoria apostolorum ; Origène ; Cyrille de Jérusalem Cat. myst. V, 9 ; Augustin Sermon 159 et Traité sur Jean 84 ; Communicantes ; Sub tuum praesidium : rappel + lien).
7. Comment les saints connaissent nos prières (Is 63:16, Jb 14:21 ; Augustin De cura pro mortuis ; Thomas Suppl. q.72 a.1 et II-II q.83 a.11 ; voir dans le Verbe ce qui les concerne ; pas d'omniscience ; degré d'autorité).
8. Le décret de Trente (session XXV, 3-4 décembre 1563) : invocation (via LG 50), condamnations, reliques, images, abus ; Profession de foi de Pie IV ; LG 51 ; « bon et utile ».
9. Demander une prière, ce n'est pas adorer (Thomas II-II q.83 a.4 ; litanies ; oraisons ; sacrifice réservé à Dieu : Augustin, Cité de Dieu VIII, 27 ; Ap 19:10 ; superstition ; rappel latrie/dulie + lien).
10. Les saints patrons (patronus ; nom de baptême CEC 2156, can. 855 ; titulaire d'église ; patrons de lieux : Église universelle 1870, missions 1927, Europe 1964-1980-1999, France 1922-1944 ; métiers : Joseph artisan 1955, Luc, Vianney 1929, Thomas d'Aquin 1880 ; pas des dieux spécialisés ; usages populaires).
11. La charité des saints qui s'achève au ciel (Thérèse de Lisieux, Derniers entretiens 17 juillet 1897 ; CEC 956 ; Dominique ; 1 Co 13:8 ; Ph 1:23-24 ; Lc 19:17 ; Ap 14:13 et 22:3 ; Thomas q.83 a.11).
