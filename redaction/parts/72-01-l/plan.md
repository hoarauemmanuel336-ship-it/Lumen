# 72-01-l : Le fondement et l'histoire de l'onction des malades

Question centrale : d'où vient le sacrement des malades (Écriture, Christ, Apôtres) et pourquoi il a changé de visage et de nom au cours des siècles (onction des malades → extrême-onction → onction des malades).
Obstacles du novice : croire que c'est « le sacrement des mourants » ; croire que Marc 6:13 est déjà le sacrement ; confondre « presbytres » et « anciens » ; croire que Vatican II a inventé un nouveau sacrement ; croire que la maladie est punition d'une faute personnelle.

Lettres : l ; liens internes du fichier : #ouverture-s (sujet, ministre, rite ; Paul VI 1972 ; messe chrismale), #ouverture-e (effets), #ouverture-v (viatique).

Leçons (fichiers 01 à 10) :
1. La maladie devant Dieu dans l'Ancien Testament (CEC 1500-1502 ; Ps 6, 38, 41, 88 ; Ex 15:26 ; Job ; Sagesse 1:13 ; 2 Rois 20 Ézékias ; Siracide 38 ; Asa ; Raphaël ; Is 33:24, 35:5-6, 53:4-5).
2. Le Christ médecin des corps et des âmes (CEC 1503-1504 ; Mt 4:23-24 ; Lc 4:18 ; Mt 11:2-5 ; gestes Mc 1:41, 7:33-35, 8:23-25, Jn 9:6-7, Lc 6:19 ; foi Mc 5:34, 9:23, 6:5-6 ; paralysé Mc 2 ; Jn 9:2-3 ; Jn 5:14 ; Pères : Ignace, Augustin).
3. La compassion du Christ et sa victoire sur la souffrance par la Croix (CEC 1505 ; splanchnizomai ; Hé 4:15 ; pas toutes les guérisons, Trophime, 2 Co 12:9 ; Mt 8:16-17 ; 1 P 2:24 ; Gethsémani ; Col 1:24 ; Salvifici doloris 19 ; Ap 21:4).
4. Les Douze envoyés : l'onction de Marc 6:13 (Mc 6:7-13 ; Lc 9:1-6 ; Mt 10:8 ; l'huile Is 1:6, Lc 10:34 ; Christ = Oint ; « insinuatum » de Trente ; Mc 16:17-18 ; Actes ; charismes 1 Co 12:9 ; CEC 1506-1509 ; Mt 25:36).
5. Le texte de l'épître de Jacques (Jc 5:13-16 ; mots grecs ; presbytres ; sauver / relever ; pardon ; CEC 1510 ; Luther, Calvin ; canons II et IV de Trente).
6. La lettre d'Innocent Ier à Decentius (416 ; Gubbio ; chap. 8 ; huile du chrême faite par l'évêque ; prêtres et tous les chrétiens ; l'évêque peut oindre ; pénitents exclus : genus sacramenti).
7. L'onction dans l'Église ancienne (Tradition apostolique ; Sérapion ; Emitte ; huile bue et appliquée ; Origène, Chrysostome, Césaire, Bède ; CEC 1512 ; onction par les fidèles et par les prêtres).
8. De l'onction des malades à l'extrême-onction (réforme carolingienne ; lien avec la pénitence au lit de mort ; raisons du retard ; onction des sens et formule ; nom au XIIe s. ; sacramentum exeuntium ; scolastique ; l'euchélaion oriental).
9. Les conciles de Florence et de Trente (Exsultate Deo, 22 nov. 1439 ; Luther, Calvin ; session XIV, 25 nov. 1551, préambule, chap. 1-3, canons 1-4 ; « praesertim »).
10. Le retour au nom d'onction des malades (Code 1917 c. 940 ; SC 73-75 ; Paul VI 1972 en une phrase + lien #ouverture-s ; CEC 1512-1514 ; continuité).
