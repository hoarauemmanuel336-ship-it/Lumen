# Plan du cours 31-04-r : La Réforme radicale

Lettre r. 10 leçons. Fichiers : 00-ouverture.html, 01.html à 10.html, 99-bilan.html.

Question centrale : qui sont ceux qui, dans les années 1520-1600, ont voulu aller plus loin que Luther et Zwingli (rebaptiser, se séparer du monde, faire venir le Royaume par l'épée, ou repenser la Trinité), et que sont-ils devenus ?
Obstacles du novice : confondre anabaptistes pacifiques et Münster ; croire que Müntzer était anabaptiste au sens strict ; croire que les anabaptistes se disaient « rebaptiseurs » ; ignorer que catholiques ET protestants les ont mis à mort ; confondre mennonites, amish, huttérites, baptistes ; croire que les antitrinitaires étaient de simples « libres penseurs » ; confondre sociniens et unitariens modernes.

1. Le mot anabaptiste et la Réforme radicale. Grec ana + baptizein ; le nom donné par les adversaires (Täufer, frères) ; refus du mot par les intéressés ; loi du Code de Justinien contre les rebaptiseurs (Code théodosien 16.6), diète de Spire 1529 ; l'expression « Réforme radicale » (G. H. Williams, 1962) et les trois familles (anabaptistes, spiritualistes, rationalistes antitrinitaires) ; monogenèse / polygenèse (Stayer, Packull, Deppermann 1975) ; jugement catholique : un seul baptême, Trente session VII, canon 13 sur le baptême ; lien 68-le-bapteme v et b.
2. Conrad Grebel et les premiers baptêmes d'adultes à Zurich (1525). Grebel, Manz ; cercle de Zwingli ; seconde dispute (octobre 1523) ; lettre à Müntzer (septembre 1524) ; dispute du 17 janvier 1525 ; mandat du Conseil ; 21 janvier 1525 chez Manz, Blaurock ; Zollikon ; Hubmaier à Waldshut ; mandat de mars 1526 ; Manz noyé (5 janvier 1527) ; Grebel mort (1526) ; Blaurock brûlé (1529).
3. La Confession de Schleitheim (1527) et la séparation d'avec le monde. Michael Sattler ; réunion du 24 février 1527 ; sept articles ; deux royaumes ; procès et mort de Sattler à Rottenburg (mai 1527) ; Martyrs ; réponse de Zwingli et Calvin ; jugement catholique.
4. Thomas Müntzer : le prophète et le théologien. Vie (Stolberg, vers 1489), études, Zwickau (1520-1521), prophètes de Zwickau, manifeste de Prague (1521) ; Allstedt (1523) et liturgie allemande ; mystique de la croix et de l'Esprit.
5. Thomas Müntzer : le sermon aux princes et la guerre des Paysans. Sermon sur Daniel 2 (13 juillet 1524), Mühlhausen ; ligue ; Frankenhausen (15 mai 1525), exécution (27 mai 1525) ; Luther contre les « prophètes célestes » ; historiographie (Engels, RDA, recherche récente) ; lien avec les anabaptistes (lettre de Grebel, Hans Hut).
6. Le royaume anabaptiste de Münster (1534-1535). Melchior Hoffman ; Rothmann ; Jan Matthijs ; prise de la ville ; siège par l'évêque Franz von Waldeck ; Jan de Leyde roi, polygamie, communauté des biens ; chute (25 juin 1535) ; exécutions (22 janvier 1536), cages de Saint-Lambert ; conséquences ; lien 77 millénarisme.
7. Menno Simons. Witmarsum (1496), prêtre (1524), doutes ; Oldeklooster (1535) ; départ (janvier 1536), baptême par Obbe Philips ; Fondement de la doctrine chrétienne (1539-1540) ; christologie de la « chair céleste » ; mort (1561).
8. Les mennonites et la famille anabaptiste. Nom ; martyrs (chiffres, Miroir des martyrs 1660) ; Confession de Dordrecht (1632) ; huttérites (Jakob Hutter), amish (Jakob Ammann, 1693) ; tolérance aux Provinces-Unies, Prusse, Russie, Amérique ; aujourd'hui ; dialogue catholique-mennonite (« Appelés ensemble à être artisans de paix », 2003) ; jugement catholique.
9. Les antitrinitaires du XVIe siècle. Retour aux textes et refus des formules ; Servet (rappel, lien Calvin) ; Italiens : Lelio Sozzini, Gribaldi, Biandrata, Gentile (Berne 1566), Ochino ; Pologne : Église mineure (1565) ; Transylvanie : Ferenc Dávid, diète de Torda (1568), Jean-Sigismond ; non-adorantisme et mort de Dávid (1579) ; réponse catholique : Paul IV, Cum quorundam (1555) ; liens Nicée, erreurs trinitaires.
10. Fauste Socin et les sociniens. Sienne (1539), oncle Lelio ; Bâle, De Jesu Christo Servatore ; Transylvanie (1578-1579) ; Pologne (1579), Raków ; doctrine (Christ homme, rejet de la satisfaction, raison et Écriture) ; Catéchisme de Raków (1605) ; Académie de Raków ; expulsion de 1658 ; Bibliotheca Fratrum Polonorum ; postérité (unitariens, Lumières) ; jugement catholique.
Bilan : 6 exercices croisés.
