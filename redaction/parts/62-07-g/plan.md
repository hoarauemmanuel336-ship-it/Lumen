# Plan du cours 62-07-g « Les grandes prières mariales » (lettre g)

Question centrale : d'où viennent les prières que l'Église adresse à Marie, que disent-elles exactement, et comment chacune garde-t-elle Marie tournée vers le Christ ?
Obstacles du novice : croire que le Je vous salue Marie est tout entier dans la Bible ou tout entier inventé ; croire que prier Marie, c'est l'adorer ; ignorer l'ordre liturgique (vêpres, complies, temps de l'année) ; croire que le Souvenez-vous est de saint Bernard ; voir les litanies comme une répétition vide ; confondre hymne, antienne, séquence ; ignorer l'Orient.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. La salutation de l'ange et d'Élisabeth : Luc 1:28 et 1:42 ; Ave = grec chaire ; gratia plena / comblée de grâce (lien 60 #ouverture-a) ; ajout des noms Marie et Jésus ; antienne grégorienne ; formule autour de 1050 ; Eudes de Sully vers 1196 ; « Jésus » attribué sans preuve à Urbain IV ; CEC 2676.
2. « Sainte Marie, Mère de Dieu » : la demande ; XVe siècle (Calendrier des bergers 1493, Savonarole 1495, bréviaire des Mercédaires vers 1514) ; Bréviaire romain de saint Pie V (1568) ; Catéchisme de Trente ; sens des mots (Mère de Dieu, pécheurs, maintenant, heure de notre mort) ; CEC 2677 ; « pauvres pécheurs » français ; objection des vaines redites (Matthieu 6:7) ; 1 Timothée 2:5.
3. Le Sub tuum praesidium : textes grec, latin, français ; eusplanchnia ; papyrus Rylands 470 et sa datation débattue ; Theotokos ; usages copte, byzantin, ambrosien, romain ; LG 66 note ; Marialis cultus 13 ; Psaume 91.
4. Le Magnificat aux vêpres : Marialis cultus 18 ; vêpres (PGLH 39, 50, 138, 261, 263, 266) ; Psaume 141:2 ; trois cantiques évangéliques ; doxologie ; Règle de saint Benoît ; Orient (orthros, « Plus vénérable que les chérubins ») ; exégèse renvoyée à 60 #ouverture-l.
5. L'Angélus : texte ; structure ; histoire (soir : chapitre franciscain 1263 ou 1269, Jean XXII 1318/1327 ; matin Parme 1318 ; midi Prague 1386, Calixte III 1456) ; texte 1560/1612 ; oraison (collecte du 4e dimanche de l'Avent) ; Marialis cultus 41 ; Psaume 55:18, Daniel 6:11, Jean 1:14 ; Regina caeli au temps pascal.
6. Les antiennes de la fin du jour, Alma et Ave Regina : complies ; PGLH 92 ; répartition traditionnelle ; Alma (Hermann Contract, porte du ciel, étoile de la mer, nature émerveillée, vierge avant et après) ; Ave Regina caelorum (XIIe siècle, du 2 février à la Semaine sainte).
7. Regina caeli et Salve Regina : Regina caeli (XIIe s., légende de Grégoire, franciscains, du samedi saint à la Pentecôte, debout, remplace l'Angélus) ; Salve Regina (XIe s., Hermann ou Adhémar du Puy, Cluny vers 1135, Cîteaux 1218, Dominicains vers 1221, légende du « O clemens », Léon XIII 1884, vallée des larmes Psaume 84:7).
8. Le Souvenez-vous : texte latin et français ; jeu Verbi/verba ; prière du XVe s. « Ad sanctitatis tuae pedes » ; Claude Bernard, le « pauvre prêtre » (mort en 1641), 200 000 feuillets ; confusion avec saint Bernard ; idée bernardine (sermon sur l'Assomption) ; Pie IX 1846 ; François de Sales ; Hébreux 4:16.
9. Les litanies de Lorette : litanie (grec litaneia) ; Lorette ; Dillingen 1558 ; Sixte V, Reddituri (1587) ; Clément VIII (1601) ; cinq groupes d'invocations ; titres symboliques (Cantique 4:4, 7:5 ; Genèse 28:17) ; ajouts (1883, 1903, guerre 14-18, 1950, 1980, 1995, 2020) ; Auxilium christianorum avant Lépante.
10. L'Ave maris stella : hymne (définition) ; sept strophes ; manuscrit de Saint-Gall (IXe s.) ; attributions sans fondement ; stella maris (Jérôme, stilla maris) ; Eva/Ave (Genèse 3:20) ; « Monstra te esse matrem » ; vêpres des fêtes de la Vierge.
11. Le Stabat Mater : séquence (définition) ; XIIIe s. ; Jacopone da Todi, Innocent III ; vingt tercets ; Trente ; Benoît XIII 1727 ; 15 septembre, séquence facultative ; chemin de croix ; Jean 19:25, Luc 2:35, Lamentations 1:12 ; compassion (lien #ouverture-c).
12. L'hymne acathiste : akathistos ; vingt-quatre strophes alphabétiques, kontakia et oikoi, chairetismoi (« Réjouis-toi, Épouse inépousée ») ; datation (entre Éphèse et Chalcédoine selon beaucoup) ; auteurs proposés ; prooimion et siège de 626 ; vendredis de Carême, samedi de l'Acathiste ; CEC 2678 ; LG 69.
Bilan : 6 exercices croisés.
