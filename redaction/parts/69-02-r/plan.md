# 69-02-r Le rite de la confirmation et le saint chrême (lettre r) : plan

Question centrale : avec quoi, par quels gestes et par quelles paroles l'Église confirme-t-elle, et que dit chacun de ces signes ?
Obstacles du novice : croire que l'huile est un décor (alors que l'onction est la matière) ; confondre les trois huiles ; confondre l'imposition des mains sur tous (non essentielle) et l'imposition de la main dans l'onction (essentielle) ; croire que « Sois marqué » est une formule moderne ; ignorer le lien évêque / chrême ; croire que le geste de paix est une simple politesse ; croire que le rite a toujours été le même.

Rappels (une phrase + lien) : institution, Tertullien, Cyrille (#ouverture-l) ; effets, caractère, LG 11, mission des laïcs (#ouverture-e) ; ministre, prêtre, parrain, âge (#ouverture-m) ; Orient/Occident (#ouverture-i) ; messe chrismale entière (65-le-temps-liturgique.html#ouverture-s) ; onction après le baptême (68-le-bapteme.html#ouverture-c) ; matière et forme en général (67-les-sacrements-en-general.html#ouverture-m) ; caractère (67-...#ouverture-c) ; symboles de l'Esprit (51-l-esprit-saint.html#ouverture-s) ; sept dons (51-l-esprit-saint.html#ouverture-d).

Leçons :
1. Le saint chrême, huile mêlée de parfum : huile d'olive ou autre huile végétale (rituel des huiles 1970), parfum (baume), sens de l'huile (CEC 1293), sens du parfum (Exode 30, Florence : huile = netteté de conscience, baume = bonne réputation), les trois huiles, myron.
2. La consécration du chrême à la messe chrismale : CEC 1297 (en fait partie), quand et où, préparation, insufflation, prière (deux formules), mains des prêtres, pourquoi l'évêque, Orient (prière antiochienne CEC 1297), distribution, conservation, renouvellement annuel.
3. Christ, chrême et chrétien : mashiah / christos / chriô / chrisma ; le Christ oint (Ac 10:38, Ps 45:8 / He 1:9) ; Ac 11:26, 26:28, 1 P 4:16 ; Théophile d'Antioche ; CEC 1289 ; 1 Jn 2:20.27.
4. Le sceau de l'Esprit Saint : sphragis / signaculum ; CEC 1295-1296 ; Jn 6:27 ; 2 Co 1:21-22 ; Ep 1:13-14 ; 4:30 ; Ez 9:4 ; Ap 7:2-3 ; le front ; caractère (lien).
5. La bonne odeur du Christ et la consécration pour la mission : 2 Co 2:14-16 ; Ep 5:2 ; Mc 14 ; Ignace ; CEC 1294 ; consécration = mise à part et envoi ; Jn 20:21-22 ; Ac 1:8 ; LG 11 (lien e).
6. La constitution Divinae consortium naturae (15 août 1971) : SC 71 ; titre (2 P 1:4) ; naissance-croissance-nourriture ; Ac 8, 19, He 6:2 ; Innocent III ; Florence ; Trente ; Orient ; décision ; imposition préalable ; formule byzantine ; 1er janvier 1973.
7. Le Rituel de la confirmation (1971) : décret 22 août 1971 ; Pontifical romain de 1596 ; praenotanda ; chapitres ; plan de la célébration ; changements (formule, soufflet, promesses, messe) ; traductions.
8. La présentation des confirmands et la rénovation des promesses du baptême : SC 71, CEC 1298 ; présentation, homélie, renonciation, profession (quatrième question sur l'Esprit), assentiment de l'évêque ; Josué 24 ; 1 Tm 6:12.
9. L'imposition des mains sur l'ensemble des confirmands : geste biblique ; CEC 1299 (prière, Isaïe 11:2) ; prêtres associés ; Tradition apostolique ; DCN (non essentielle, mais intégrité) ; distinction.
10. L'onction sur le front : matière et forme : DCN, CEC 1300 ; pouce, croix, front ; imposition de la main incluse ; Accipe signaculum doni Spiritus Sancti ; formule byzantine (sphragis dôreas) ; Ac 2:38 ; ancienne formule latine ; nom ; réponse Amen ; validité.
11. Le geste de paix et la confirmation au cours de la messe : Pax tecum ; Tradition apostolique (baiser) ; CEC 1301 ; soufflet (alapa) supprimé ; Ep 4:3 ; prière universelle ; liturgie eucharistique ; communion ; bénédiction ; Rituel (de more intra Missam) ; hors de la messe.
