# Plan du cours 56-06-r « Les prêtres » (lettre r)

Angle : la place des prêtres dans la constitution hiérarchique de l'Église (rapport à l'évêque, presbyterium, attaches, offices du diocèse et de la paroisse, deux grands documents). Le sacrement lui-même (caractère, pouvoirs, fraternité, obéissance, spiritualité, curé d'Ars) est le sujet du cours « Le presbytérat » (73-l-ordre.html#ouverture-p) : on y renvoie, sans reprendre ses exemples (Nombres 11, lampe, cithare d'Ignace aux Éphésiens, « ceci est mon corps »).

Question centrale : qui sont les prêtres dans l'Église, à qui ils sont rattachés, et par quels offices ils servent concrètement le peuple de Dieu ?

1. Le mot « prêtre » et les Anciens de l'Église — presbuteros ; les Anciens de Jérusalem (Actes 11:30 ; 15) ; 1 Timothée 5:17 ; 1 Pierre 5:1-4 (Pierre « l'Ancien comme eux ») ; pourquoi « ancien » ; LG 28 : le ministère exercé en divers ordres, évêques, prêtres, diacres.
2. Coopérateurs de l'ordre épiscopal — LG 28 « coopérateurs avisés… aide et instrument » ; 1 Corinthiens 3:9 ; Philippiens 2:20-22 ; unis dans la dignité, dépendants dans l'exercice (missio, facultés) ; « fils et amis », « père » ; erreurs : Aérius, l'opinion de saint Jérôme, le presbytérianisme ; PO 7, canons 273-274.
3. En la personne du Christ Tête — 2 Corinthiens 2:10 ; saint Thomas ; Pie XII (CEC 1548) ; « Tête » ajouté par Vatican II (PO 2) ; Éphésiens 1:22 ; 4:15-16 ; au nom de l'Église (CEC 1552-1553) ; Christ Tête et Pasteur dans les trois charges (PO 6, PDV 15) ; canon 1009 §3 (2009) ; ce que la formule ne dit pas.
4. Le presbyterium — le mot (1 Timothée 4:14) ; Ignace (Tralliens 3, Magnésiens 6) ; LG 28, CD 28, CEC 1567 ; ce qu'il est et n'est pas ; ses signes ; PDV 74.
5. Prêtres diocésains et prêtres religieux — séculier et régulier ; le diocésain (CD 28) ; le religieux (canon 266 §2, exemption, canon 678, CD 34) ; sociétés de vie apostolique, instituts séculiers ; un seul presbyterium (PO 8, canon 498).
6. L'incardination — canon 265 ; acéphales ; Chalcédoine canon 6 ; Tite 1:5 ; canon 266 ; excardination (267-270) ; canon 271, PO 10, prêtres Fidei donum (1957).
7. Le conseil presbytéral — PO 7 ; canon 495 ; sénat ; composition (497-499) ; voix consultative (500) ; durée (501) ; collège des consulteurs (502) ; sens.
8. Le curé — canon 515, 519 ; pasteur propre (canon 131) ; nomination, stabilité (522-523) ; un curé par paroisse (520, 526), 517 ; devoirs (528-529) ; fonctions spécialement confiées (530) ; résidence, messe pro populo, registres, conseils (533-537) ; 75 ans (538).
9. Le vicaire paroissial et l'aumônier — canons 545-552 ; canons 564-572 (le Code français dit « chapelain ») ; Matthieu 25:36 ; aumôneries militaires (1986).
10. Le vicaire général — canon 475-481 ; pouvoir ordinaire vicarial ; CD 27 ; vicaires épiscopaux ; Exode 18.
11. Le décret Presbyterorum ordinis — 7 décembre 1965 ; histoire du texte ; plan ; idées maîtresses (PO 2, 4, 6, 7, 9, 10, 14, 20-21).
12. L'exhortation Pastores dabo vobis — synode de 1990 ; 25 mars 1992 ; Jérémie 3:15 ; six chapitres et leurs titres bibliques ; charité pastorale (23) ; quatre dimensions ; séminaire (61) ; évêque (65) ; formation permanente (70, 74).
Bilan : 6 exercices croisés.
