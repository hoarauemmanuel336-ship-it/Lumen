# 56-03-j « Le pape et sa juridiction » (fichier 56, lettre j) : plan

Question centrale : qu'est-ce que le pape, quel pouvoir a-t-il sur l'Église, d'où lui vient-il, comment se transmet-il, et quelles doctrines l'Église a-t-elle écartées en le définissant ?
Obstacles du novice : croire que le pape est un « super-évêque » au-dessus du sacrement (alors qu'il est évêque de Rome) ; confondre pouvoir suprême et pouvoir arbitraire ; croire que les évêques sont ses délégués ; confondre infaillibilité et juridiction ; croire que les cardinaux sont un ordre sacré ; croire qu'un concile peut juger le pape ; croire que la renonciation doit être acceptée.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. Le nom de pape et l'évêque de Rome : pappas, usages anciens (Orient, Alexandrie, Occident), réservation (Grégoire VII) ; objection Matthieu 23:9 et réponse (1 Corinthiens 4:15) ; successeur de Pierre parce qu'évêque de Rome (can. 331, Pastor aeternus ch. 2, Latran, élection) ; degré : dogme (successeur), débat sur le lien primauté-Rome.
2. Les titres : vicaire du Christ (Gélase, Innocent III, Florence 1439, LG 27 pour les évêques, Luc 10:16) ; pasteur de l'Église universelle (can. 331, Jean 21:17, Jean 10:16) ; serviteur des serviteurs de Dieu (Grégoire le Grand, Jean le Jeûneur, Matthieu 20:26-28) ; Annuaire pontifical (2020 titres historiques, 2006/2024 patriarche d'Occident).
3. Pastor aeternus (18 juillet 1870) : structure (prologue, 4 chapitres) ; prologue (unité de l'épiscopat) ; ch. 1 institution ; ch. 2 perpétuité ; ch. 3 nature ; ch. 4 infaillibilité (lien) ; degré : foi définie, LG 18 ; primauté d'honneur / de juridiction.
4. Les qualités du pouvoir (can. 331) : pourquoi une série ; plénier (canon du ch. 3, « potiores partes ») ; suprême (can. 333 § 3, can. 1404, pas d'appel au concile) ; limites (droit divin, 2 Corinthiens 10:8).
5. Universel, immédiat, ordinaire et épiscopal : universel (tous rites, Églises orientales) ; immédiat (recours direct, can. 1417) ; ordinaire (can. 131) ; vraiment épiscopal ; l'évêque n'est pas vicaire du pape (LG 27, can. 333 § 1).
6. Les cardinaux : cardo, clergé de Rome (titres, diaconies, suburbicaires) ; 1059 ; trois ordres (can. 350) ; can. 349, 351 ; consistoire ; institution ecclésiastique.
7. L'élection en conclave : histoire brève (1059, 1179, 1274) ; UDG 1996 et retouches 2007/2013 ; siège vacant (can. 335, UDG 1) ; électeurs (80 ans, 120) ; déroulement ; acceptation (can. 332 § 1, UDG 88) ; 2025.
8. La renonciation : can. 332 § 2 ; pourquoi nul n'accepte ; Célestin V, Boniface VIII, Grégoire XII ; Benoît XVI 11 février 2013 ; pape émérite ; théories d'invalidité et réponse.
9. La Curie romaine : can. 360 ; Sixte V 1588 … Pastor bonus 1988 ; Praedicate Evangelium (19 mars 2022, 5 juin 2022) ; structure (Secrétairerie d'État, 16 dicastères, organismes) ; pouvoir vicarial ; « tout fidèle peut présider » (Brambilla 2025) et la question discutée de l'origine du pouvoir de gouvernement ; service des évêques.
10. Le conciliarisme : la thèse, ses arguments (Matthieu 18:17, Actes 15, Constance), Haec sancta (6 avril 1415) ; réponse (Execrabilis 1460, Latran V 1516, Pastor aeternus, LG 22) ; question discutée du pape hérétique.
11. Gallicanisme et fébronianisme : Déclaration 1682 (quatre articles), Inter multiplices (1690) ; Febronius (1763), primauté d'inspection, condamnation 1764, rétractation 1778 ; réponse de Vatican I ; ce qui est juste et ce qui est rejeté.
12. Ut unum sint 95 : contexte (n. 88, 94-96) ; objection orthodoxe et protestante sous leur forme forte ; essentiel et forme d'exercice ; premier millénaire ; Evangelii gaudium 32 ; document « L'Évêque de Rome » (2024) ; patriarche d'Occident.
