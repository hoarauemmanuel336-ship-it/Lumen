# 22-02-p — Pères, docteurs et écrivains ecclésiastiques (lettre p)

Question centrale : trois titres voisins (Père, docteur, écrivain ecclésiastique) ; qu'est-ce qui les distingue, qui les donne, et à quoi servent-ils ?
Obstacles du novice : croire que « docteur » = « Père » ; croire que le docteur est infaillible ; croire que ne pas être docteur est un blâme ; croire qu'écrivain ecclésiastique = hérétique ; ignorer les deux sens d'« écrivain ecclésiastique ».

Leçons (9) :
1. Le titre de docteur de l'Église — mot latin doctor ; racines bibliques (Éph 4:11, Ac 13:1, 1 Co 12:28) ; objection Mt 23:8-10 et Augustin (In Ep. Ioh. 3, 13, le Maître intérieur) ; un titre conféré (acte) et non lié à une époque (Thomas, Thérèse, Newman 2025) ; distinction avec le Père, le docteur de la Loi, le doctorat universitaire ; surnoms.
2. Les trois conditions du doctorat — eminens doctrina, insignis vitae sanctitas, Ecclesiae declaratio (Benoît XIV, De servorum Dei beatificatione) ; procédure (Dicastère des causes des saints + votum du Dicastère pour la doctrine de la foi, Praedicate evangelium 2022) ; Newman (31 juillet / 1er novembre 2025) ; effets : honneur liturgique (commun des docteurs, O doctor optime), pas d'infaillibilité des écrits.
3. Les quatre grands docteurs de l'Occident — décrétale Gloriosus Deus de Boniface VIII, Sexte 1298 (décret daté parfois de 1295) ; fêtes en rite double ; Ambroise, Jérôme (ignorer les Écritures…), Augustin, Grégoire ; pourquoi ces quatre.
4. Les quatre grands docteurs de l'Orient — Pie V, Bréviaire 1568 (après Thomas 1567) ; les trois saints hiérarques de l'Orient (30 janvier) ; Athanase ajouté ; profils ; Athanase De incarnatione 54 ; chaire de saint Pierre du Bernin.
5. Les Pères devenus docteurs plus tard — Isidore 1722 … Irénée 2022 ; tableau ; Éphrem 1920 (Principi Apostolorum Petro, trois patriarches) ; Irénée Doctor unitatis ; reconnaissance progressive ; 18 des 38 docteurs sont des Pères.
6. Les Pères qui ne sont pas docteurs — Grégoire de Nysse, Ignace d'Antioche, etc. ; pourquoi les listes ne coïncident pas ; absence de titre ≠ blâme ; tableau des quatre cas.
7. L'écrivain ecclésiastique — sens strict et sens large (Jérôme, De viris illustribus) ; Tertullien, Origène, Eusèbe ; Vincent de Lérins, Commonitorium 17-18 (« grande épreuve »).
8. L'usage des écrivains ecclésiastiques — Decretum Gelasianum ; apports (Tertullien : Trinité, Apol. 50, CEC 1015 ; Origène ; Eusèbe historien) ; règles de discernement ; Benoît XVI 2007.
9. Le Père dans la liturgie : l'office des lectures — Règle de saint Benoît 9 ; matines ; SC 89 c et 92 b ; Liturgia Horarum (1970-1971) ; PGLH 159-165 ; exemple du 17 octobre (Ignace) ; lectionnaire facultatif jamais promulgué.
Bilan : 6 exercices croisés.
