# 08-01-l · L’âme et les degrés de vie (lettre l, premier cours du fichier 08)

Question centrale : qu’est-ce qui distingue un vivant d’un non-vivant, qu’est-ce qu’une âme, et comment la vie s’étage-t-elle de la plante à l’homme ?
Obstacles : « âme » = fantôme réservé à l’homme ; plantes et bêtes sans âme ; âme = organe ou chose logée quelque part ; facultés = âme ; l’homme aurait trois âmes ; la vie = chimie seule (mécanisme) ou force en plus (vitalisme).

Fichiers : 00-ouverture.html (balise cours + introduction), 01.html … 11.html, 99-bilan.html (+ </cours>).

1. Ce qu’est vivre : vivants évidents (ST I q.18 a.1), se mouvoir soi-même (thèse XIII), action immanente / transitive (q.18 a.3 ad 1), « vivre, pour les vivants, c’est être » (q.18 a.2, De anima II,4). Foi : Dieu vivant, Jean 5:26.
2. Le mot âme dans trois langues : souffle ; hébreu nefesh (Gn 2:7, Lv 17:11, Ps 42:2-3) ; grec psychê (Homère, philosophes ; Mt 16:25-26, Mt 10:28, Ac 2:41, 1 Co 15:44) ; latin anima / animus ; CEC 363 ; sens philosophique retenu.
3. L’âme, premier principe de vie : principe / cause ; premier vs seconds principes ; argument ST I q.75 a.1 (chaleur) ; tout vivant a une âme (thèses XIII-XIV) ; l’âme n’est pas un lieu ni un organe ; principe intrinsèque vs Dieu cause de la vie (Ac 17:25.28).
4. La définition d’Aristote : De anima II,1 (412a19-28, 412b1-22) ; acte premier (science / contemplation, sommeil) ; corps naturel (hache) ; organisé (feuille, racines) ; cire et empreinte ; œil et vue ; renvoi au cours a pour l’âme humaine.
5. Les trois degrés de vie : cinq genres de puissances, trois âmes, quatre modes de vivre (q.78 a.1) ; critère : dépassement de la nature corporelle ; étendue de l’objet ; inclusion (triangle dans le quadrilatère) ; degrés d’immanence (ScG IV,11) ; continuité de la nature (Denys) ; Gn 1.
6. La vie végétative : nutrition (assimilation, limite de croissance), croissance, génération (q.78 a.2 : la plus parfaite, participer au divin) ; ordre des trois ; le végétatif en l’homme ; foi : grain de blé (Jn 12:24, 1 Co 15:36-38), nourriture eucharistique (Augustin, paraphrase).
7. La vie sensitive : connaître (forme sans matière, toucher), appétit sensible, mouvement local ; immanence qui commence dehors et finit dedans (ScG IV,11) ; âme animale non subsistante (thèse XIV ; Qo 3:19-21, 12:7) ; ce que l’homme doit aux bêtes (Pr 12:10, Mt 10:29).
8. La vie rationnelle : opération sans organe ; intelligence et volonté ; objet : tout l’être ; l’homme horizon et frontière ; au-dessus : anges, Dieu (q.18 a.3) ; vie de la grâce (2 P 1:4).
9. Les facultés de l’âme : potentiae ; l’homme connaît par elles (De ver. q.2 a.6 ad 3) ; distinction par actes et objets (q.77 a.3), objet formel ; distinction réelle (q.77 a.1) ; propriétés qui émanent (thèse XVII) ; écoles (thomistes, Scot, Ockham ; Augustin) ; critique de Locke.
10. Une seule âme en l’homme : Platon (trois âmes), 1 Th 5:23 et CEC 367 ; trois raisons de q.76 a.3 ; l’âme rationnelle contient les autres (thèse XVI) ; ce que l’Église enseigne (renvoi cours a) et ce qui se discute (pluralité des formes, animation de l’embryon).
11. Le vivant n’est pas une machine : Descartes (Discours V, paraphrase), La Mettrie (renvoi), biologie réductrice ; ce que le mécanisme voit juste ; ce qui manque à la machine (Kant § 65, § 75 en paraphrase ; Monod, téléonomie) ; ni mécanisme ni vitalisme ; foi.
