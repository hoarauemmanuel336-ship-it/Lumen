# Plan du cours 62-05-r « Le Rosaire » (lettre r)

Question centrale : d'où vient le Rosaire, comment se prie-t-il, et pourquoi l'Église en fait-elle une prière de l'Évangile centrée sur le Christ ?
Obstacles du novice : croire que le Rosaire est une prière « à Marie » sans le Christ ; croire que la répétition est une « vaine redite » (Matthieu 6:7) ; prendre la tradition dominicaine pour un fait historique établi ou, à l'inverse, pour une fraude sans valeur ; confondre Rosaire et chapelet ; croire que Lépante prouve une efficacité magique ; croire que la forme du chapelet est intangible ou d'institution divine ; croire que les mystères lumineux sont obligatoires.

Fichiers : 00-ouverture.html, 01.html … 11.html, 99-bilan.html.

1. Le Rosaire et le chapelet : les mots. Latin rosarium (roseraie, couronne de roses, recueil) ; allemand Rosenkranz ; chapelet (ancien français chapel, couronne) ; couronne ; Psautier de Marie ; rose, symbole marial (Siracide 24:14) ; Rosaire / chapelet / dizaine / grain ; l'objet et la prière.
2. Les psautiers des laïcs. Les 150 psaumes et l'office (Psaumes 119:164) ; trois cinquantaines ; frères convers et laïcs : 150 Pater ; patenôtres, patenôtriers de Paris (1268) ; essor de l'Ave au XIIe siècle (Aybert, m. 1140) ; psautiers de Marie ; Henri de Kalkar (dizaines) ; Dominique de Prusse (clausules, vers 1410) ; Ave alors limité à sa partie biblique (lien g).
3. La tradition dominicaine. Le récit (Marie remet le psautier à Dominique contre les albigeois) ; qui le répand (Alain, fin XVe) ; les papes (Léon X 1520 « prout in historiis legitur », Pie V, Léon XIII) ; la critique (Thurston, Bollandistes : silence des sources 1220-1450) ; degré d'autorité (question historique, non définie) ; ce qui reste vrai (rôle dominicain, MC 43).
4. Alain de La Roche et les confréries. Vie (vers 1428, Dinan ; Paris, Lille, Douai, Gand, Rostock ; m. Zwolle 8 sept. 1475) ; « bienheureux » par la voix populaire ; confrérie du Psautier, Douai 1470 ; Sprenger, Cologne 1475 ; nature d'une confrérie (communion de prière, gratuité) ; diffusion par l'imprimerie ; visions et jugement critique ; écrits posthumes (1498).
5. Saint Pie V et Consueverunt Romani Pontifices. Pie V (Ghislieri, dominicain, pape 1566-1572) ; après Trente (lien 31) ; la bulle du 17 septembre 1569 : description (150 Ave, Pater à chaque dizaine, méditations), prière vocale et mentale, indulgences ; forme fixée pour quatre siècles.
6. Lépante et Notre-Dame du Rosaire. Menace ottomane, Chypre, Sainte Ligue ; 7 octobre 1571, un dimanche ; prières et processions ; Notre-Dame de la Victoire ; Grégoire XIII (1573) ; Clément XI (1716) ; Pie X (1913) ; 1969, mémoire ; lire la victoire (Exode 17:11-12 ; Jacques 5:16 ; ni magie ni hasard).
7. Léon XIII, pape du Rosaire. Supremi apostolatus officio (1er sept. 1883) : octobre, cinq dizaines, litanies, messe ou exposition ; encycliques suivantes (1883-1898) ; « Reine du très saint Rosaire » ; Laetitiae sanctae (1893) : trois maux, trois séries ; Bartolo Longo et Pompéi (canonisé le 19 octobre 2025) ; octobre aujourd'hui (lien m).
8. La structure du chapelet. L'objet ; ouverture (signe de croix, Credo ou Psaumes 70:2, Pater, trois Ave, Gloria) ; la dizaine (annonce, Pater, dix Ave, Gloria, prière de Fatima facultative) ; conclusion (Salve Regina, litanies, intentions du pape) ; sens de chaque élément (RVM 32-37 ; MC 49-50) ; textes du Gloria et du Credo ; Rosaire entier.
9. La méditation des mystères, âme du Rosaire. MC 47 « corps sans âme » ; Matthieu 6:7 ; prière vocale et mentale ; répétition et amour (RVM 26 ; Jean 21:17 ; Matthieu 26:44 ; Psaumes 136) ; méthode (RVM 29-31 : annonce, Parole, silence ; clausule ; nom de Jésus, RVM 33) ; rythme calme ; objection protestante la plus forte et réponse.
10. Rosarium Virginis Mariae. 16 octobre 2002 ; contexte (25e année, Novo millennio ineunte, Année du Rosaire) ; plan ; « prière préférée » (29 oct. 1978) ; mystères lumineux facultatifs (RVM 19, lien y) ; répartition (RVM 38) : avant et après ; liberté.
11. Abrégé de l'Évangile, prière christologique. Pie XII (Philippinas Insulas, 1946) ; MC 42-46 (« résumé de tout l'Évangile », Incarnation rédemptrice, Philippiens 2:6-11) ; RVM 1, 3, 18 ; Marie modèle de contemplation (Luc 2:19, 2:51 ; RVM 10-11) ; cinq verbes (RVM 13-17) ; réponse finale.
