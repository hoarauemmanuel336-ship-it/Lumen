# 06-08-j · Le jugement et la proposition (lettre j)

Question centrale : que fait l'intelligence quand elle dit « est » ou « n'est pas », et comment savoir exactement ce qu'une phrase affirme, pour savoir exactement ce qui la contredit ?
Obstacles : confondre contraire et contradictoire ; croire que « quelque » veut dire « quelques-uns mais pas tous » ; convertir simplement une universelle affirmative ; confondre possible et contingent ; sens composé / divisé ; croire qu'une conditionnelle affirme ses parties ; nier une hérésie par l'erreur contraire.

1. Le jugement, acte qui affirme ou nie : concevoir / juger ; composer et diviser (De int. 1, ST I q16 a2) ; seul lieu du vrai et du faux (Métaph. E 4) ; jugement et assentiment (Mt 5:37) ; la foi : assentiment, objet complexe du côté du croyant, atteint la chose (ST II-II q1 a2 ad 2).
2. La proposition et ses trois éléments : énonciation (De int. 4, la prière ; Boèce) ; sujet et prédicat ; la copule, réduction des verbes ; « est » troisième ou second (De int. 10) ; « Dieu est », Ex 3:14, Ps 14:1 ; Mt 16:16.
3. Qualité et quantité : affirmative / négative (la négation porte sur la copule ; terme infini) ; universelle, particulière, singulière ; indéfinies, collectif/distributif ; pièges (« tous ne… pas »).
4. Les quatre propositions A, E, I, O : tableau ; noms (affirmo, nego ; vers mnémotechnique) ; mise en forme ; extension des termes (distribution).
5. Le carré logique et les contradictoires : opposition comme ensemble (figure libre ; Apulée, Boèce) ; contradictoires (De int. 7) ; conditions (De int. 6 ; Jn 10:30 / Jn 14:28 ; Quicumque) ; usage : un contre-exemple suffit.
6. Contraires, subcontraires, subalternes : règles ; matière nécessaire/contingente ; portée existentielle ; tableau des inférences.
7. La conversion : règle de l'extension ; E et I simple ; A par accident (et termes convertibles) ; O non ; contraposition ; Mt 12:30 et Mc 9:40.
8. Les modales : mode et dictum ; nécessaire / impossible (He 6:18, 2 Tm 2:13, Lc 1:37) ; possible / contingent ; carré des modales ; sens composé / divisé (Réf. soph. 4 ; ST I q14 a13 ad 3 ; De int. 9 bataille navale).
9. Les propositions composées : catégorique / hypothétique ; conditionnelle (1 Co 15:14-17) ; disjonctive (stricte/large) ; conjonctive (copulative ; négative Mt 6:24) ; exponibles (exclusive Mc 10:18, exceptive, réduplicative).
10. Nier exactement une hérésie : ce que fait une condamnation (censures, lien 03) ; contradictoire non contraire (Trente VI can. 7, 25 ; Baïus 25) ; analyser avant de nier (Trente VI can. 9 « foi seule », Jc 2:24, Rm 3:28 ; 5e proposition de Jansénius) ; entre deux erreurs contraires (Chalcédoine, Quicumque) ; méthode.
