# Plan du cours 32-06-r : La Révolution française

Lettre r. 12 leçons. Fichiers : 00-ouverture, 01 à 12, 99-bilan. Vouvoiement. Apostrophes droites.

Question centrale : comment l'Église de France est-elle passée, en dix ans, d'ordre privilégié du royaume à Église persécutée, puis à Église concordataire, et que faut-il en juger (faits, débats d'historiens, jugement de l'Église : béatifications, canonisation de 2024, Dignitatis humanae) ?
Obstacles : croire que la Révolution fut antireligieuse dès 1789 (le bas clergé l'a d'abord soutenue) ; confondre Constitution civile (réforme gallicane d'une Église d'État) et déchristianisation (1793) ; confondre culte de la Raison et Être suprême ; mythes chiffrés sur la Vendée (« génocide » discuté) ; croire que le Concordat rendait les biens ou que les Articles organiques en faisaient partie.

1. L'Église de France en 1789 et le clergé aux États généraux : premier ordre, effectifs, richesse, haut/bas clergé, portion congrue ; règlement du 24 janvier 1789 ; cahiers ; députés (≈ 300, dont > 200 curés) ; 4-5 mai ; curés du Poitou 13 juin ; vote du 19 juin (149) ; 22 juin Saint-Louis ; 27 juin ; Grégoire, Sieyès, Talleyrand, La Fare.
2. Les dîmes, les biens du clergé et les vœux monastiques (1789-1790) : 4 et 11 août (dîme, Sieyès) ; Talleyrand 10 octobre ; décret du 2 novembre ; assignats ; ventes ; 28 octobre 1789 suspension des vœux ; 13 février 1790 ; commission des réguliers ; départs ; dom Gerle (13 avril 1790).
3. La Constitution civile du clergé (12 juillet 1790) : comité ecclésiastique ; contenu (83 diocèses, 10 métropoles, élection, institution par le métropolitain, lettre au pape, traitements, résidence) ; sources (gallicanisme, jansénisme, richérisme) ; sanction 22 juillet / 24 août ; Exposition des principes (30 octobre 1790).
4. Le serment et la condamnation par Pie VI (1790-1791) : décret 27 novembre, sanction 26 décembre ; Grégoire ; 4 janvier 1791 ; jureurs/réfractaires (Tackett) ; carte ; motifs ; sacres du 24 février 1791 ; Quod aliquantum (10 mars 1791) ; Charitas (13 avril 1791) ; rétractations ; schisme ; Avignon ; jugement.
5. Les massacres de septembre 1792 et les martyrs des Carmes : lois de 1791-1792 (29 nov 1791, 27 mai 1792, 26 août 1792), exil ; 10 août ; 2-6 septembre ; Carmes (du Lau, La Rochefoucauld) ; bilan ; béatification 17 octobre 1926 (191) ; martyre.
6. La déchristianisation (1793-1794) et le calendrier républicain : calendrier (5 octobre / 24 novembre 1793) ; décadi ; représentants en mission, Fouché ; abdications (Gobel 7 nov.) ; Grégoire ; fermeture des églises ; vandalisme ; pontons de Rochefort (béatifiés 1995).
7. Le culte de la Raison (1793) et le culte de l'Être suprême (1794) : 10 novembre 1793 ; temples ; Robespierre contre l'athéisme (21 nov.) ; décret 6 décembre ; 7 mai 1794 ; fête du 8 juin ; Thermidor ; analyse (religion civile, Rousseau).
8. La guerre de Vendée : causes ; mars 1793 ; chefs ; Armée catholique et royale ; Sacré-Cœur ; Savenay ; colonnes infernales ; noyades ; bilans (Hussenet) ; débat « génocide » ; martyrs d'Angers (1984) ; La Jaunaye.
9. Les carmélites de Compiègne (1794) : carmel ; expulsion 1792 ; acte d'offrande ; arrestation 22 juin ; procès 17 juillet ; échafaud ; Picpus ; béatification 1906 ; canonisation équipollente 18 décembre 2024 ; postérité littéraire.
10. Pie VI mort captif à Valence (1799) : après Thermidor (3 ventôse an III, 11 prairial) ; Directoire ; fructidor ; Guyane ; théophilanthropie ; campagne d'Italie ; Tolentino ; Duphot ; République romaine ; exil ; Valence ; mort ; conclave de Venise.
11. Le Concordat de 1801 et les Articles organiques (1802) : Bonaparte ; Marengo ; négociations ; contenu ; Tam multa, Qui Christi Domini ; Petite Église ; Articles organiques (placet, 1682, mariage civil, catéchisme) ; protestation ; bilan jusqu'en 1905.
12. Le sacre de Napoléon (1804) et la captivité de Pie VII (1809-1814) : sacre ; catéchisme impérial ; Saint-Napoléon ; rupture ; Rome occupée ; annexion ; Quum memoranda ; arrestation 6 juillet 1809 ; Savone ; institution canonique refusée ; cardinaux noirs ; concile de 1811 ; Fontainebleau ; concordat de 1813 et rétractation ; retour 24 mai 1814 ; bilan.
Bilan : 6 exercices croisés.
