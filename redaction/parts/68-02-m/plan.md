# 68-02-m · Matière, forme et ministre du baptême (fichier 68-le-bapteme, lettre m)

Question centrale : que faut-il, au minimum et à coup sûr, pour qu'un baptême soit vraiment donné, et que demande l'Église au-delà de ce minimum ?
Obstacles du novice : croire que seule l'eau bénite baptise ; croire que l'infusion est un « demi-baptême » ou que seule l'immersion vaut ; confondre l'aspersion dominicale et le baptême ; croire que la formule peut se reformuler librement ; ignorer la forme orientale ou la croire douteuse ; croire que seul un prêtre peut baptiser, ou au contraire que n'importe qui peut baptiser n'importe quand ; croire que le parrain est nécessaire à la validité ; croire que le nom doit être celui d'un saint du calendrier.

Liens : 67#ouverture-m (matière et forme), 67#ouverture-i (ministre et intention), #ouverture-l, #ouverture-c, #ouverture-v, #ouverture-s, #ouverture-b, 66#ouverture-e.

1. L'eau naturelle, matière du baptême : Ép 5:26, can. 849, Florence 1439 (aqua vera et naturalis, froide ou chaude) ; pourquoi l'eau (institution Mt 28:19, Jn 3:5 ; convenance, Thomas III q.66 a.3) ; Trente VII baptême can. 2 (paraphrase) ; quelle eau (Thomas a.4 ; tableau certaine / douteuse / exclue ; bière, Grégoire IX 1241) ; eau bénite (can. 853), eau propre (Rituel), nécessité.
2. L'immersion, signe le plus expressif : Jn 3:23, Mc 1:10, Ac 8:38-39, 2 R 5:14 ; Rm 6:3-4, Col 2:12 ; baptistères (Doura-Europos, Latran, octogone) ; Tertullien, Grégoire à Léandre (via Thomas a.8), Tolède IV 633 ; CEC 1239 ; can. 854 ; Orient, 1755.
3. L'infusion : Didachè 7 ; Novatien (Eusèbe) ; extension en Occident ; Mc 7:4, Lc 11:38 (baptizein = laver) ; Thomas a.7 ; conditions (tête, eau qui coule sur la peau, trois fois, en même temps que la formule, un seul ministre).
4. L'aspersion et les conditions de validité : définitions (immersion, infusion, aspersion) ; Cyprien, lettre 69 à Magnus (malades, Ez 36:25, Nb 19) ; conditions (eau qui touche et coule, chaque personne, « je vous baptise » en nécessité, Thomas q.67 a.6) ; can. 854 ; doute → sous condition (#ouverture-v) ; rite d'aspersion de la messe.
5. La forme latine : Mt 28:19, Florence, CEC 1240 ; mot par mot ; CEC 233 « au nom » ; essentiel (acte exprimé, Thomas a.5 ad 2 ; « Ego » non essentiel) ; langue, fautes (Zacharie 746) ; changements substantiels (2008, 2020 → #ouverture-v) ; « au nom de Jésus » (Ac 2:38, 19:5 ; Thomas a.6) ; unité matière-forme.
6. La forme orientale : CEC 1240 ; grec, amen, triple immersion ; Florence (baptizetur… / baptizatur manibus meis) ; principe (acte + Trinité) ; Chrysostome (passif) ; Jn 1:33 ; deux formules, une foi ; Églises orientales catholiques (66#ouverture-e).
7. Le ministre ordinaire : Jn 4:1-2, 1 Co 1:14-17, Jn 1:33 ; définition ; évêque (Ignace, Tertullien, can. 863) ; prêtre (can. 530, 857-858, 862) ; diacre (Ac 6:5, 8:38 ; LG 29 ; Gélase via Thomas ; can. 861 ; CEC 1256 ; CCEO 677) ; ministre député (can. 861 §2).
8. Le ministre en cas de nécessité : CEC 1256, can. 861 §2, Florence ; raisons (1 Tm 2:4, Mc 16:16) ; histoire (Tertullien, Augustin, Gélase, Urbain II, Nicolas Ier via Thomas q.67 a.3-5) ; intention (67#ouverture-i) ; limites (un seul ministre, pas soi-même : Innocent III 1206) ; pratique (comment baptiser, prévenir le curé, rites complétés → #ouverture-s).
