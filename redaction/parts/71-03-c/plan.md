# 71-03-c — La contrition (cours c du fichier 71-la-penitence.html)

Question centrale : que faut-il éprouver et vouloir, devant Dieu, pour que le péché soit pardonné, et suffit-il de regretter par crainte ?
Obstacles du novice : croire que la contrition est un sentiment (larmes) ; croire qu'il faut être sûr de ne plus jamais retomber ; croire que la crainte de l'enfer est un motif indigne ; croire que la contrition parfaite dispense de se confesser ; confondre remords (Judas) et repentir (Pierre) ; examen de conscience = introspection angoissée.

Leçons (11) :
1. Les trois actes du pénitent — contrition, confession, satisfaction ; CEC 1450 ; Trente XIV ch. 3 « quasi-matière » (lien 67 #ouverture-m) ; canon 4 contre les deux parties (terreurs + foi) ; contrition première et âme des autres.
2. La conversion intérieure, cœur de la pénitence — Joël 2:12-13 (shuv), Psaume 51 (David, Natan), CEC 1430-1432, metanoia, conversion œuvre de la grâce (Lm 5:21), Ez 36:26.
3. Le cœur brisé : le mot « contrition » — conterere, Vulgate Ps 50:19 cor contritum, hébreu nishbar / nidkeh, attritio (atterere), compunctio (Actes 2:37), animi cruciatus ; cœur de pierre.
4. La définition du concile de Trente — 25 nov. 1551, ch. 4 ; douleur, détestation, résolution ; douleur de la volonté, pas forcément sensible ; qualités : intérieure, surnaturelle, souveraine, universelle ; nécessaire en tout temps ; espérance (Pierre / Judas, 2 Co 7:10).
5. La contrition parfaite et son effet — motif : Dieu aimé par-dessus tout ; remet les véniels ; remet les mortels avec la résolution de se confesser (CEC 1452) ; canon 916 ; pécheresse Lc 7:47 ; danger de mort.
6. L'attrition — laideur du péché, crainte de l'enfer ; don de Dieu, impulsion de l'Esprit (grâce actuelle) ; doit exclure la volonté de pécher et espérer le pardon ; Ninivites ; Mt 10:28 ; Luther, Exsurge Domine prop. 6, Trente canon 5 ; crainte servile et filiale ; fils prodigue.
7. La querelle des contritionnistes et des attritionnistes — Abélard, Pierre Lombard ; saint Thomas (ex attrito fit contritus), Scot ; Trente laisse ouvert l'« amour initial » (session VI ch. 6) ; jansénistes (Arnauld 1643, Pascal 1656) ; laxisme condamné (Innocent XI, 1679) ; Alexandre VII 1667 ; Alexandre VIII 1690 ; Unigenitus 1713.
8. La suffisance de l'attrition dans le sacrement — CEC 1453, Trente ; pourquoi : ex opere operato (lien 67 #ouverture-o), le sacrement achève ; condition : attrition vraie et surnaturelle ; comparaison hors sacrement ; tendre vers la contrition.
9. Le ferme propos et ses conditions — propositum ; ferme, efficace (occasions prochaines, Mt 5:29-30, restitution Lc 19:8), universel ; canon 987 ; propos ≠ certitude (Rm 7:19, Pr 24:16) ; rechutes ; Jn 8:11.
10. L'examen de conscience, préparation à la contrition — CEC 1454, Reconciliatio et paenitentia 31 ; Ps 139:23-24, Lm 3:40, Ps 19:13 ; méthode (Décalogue, Béatitudes, Rm 12-15…) ; examen quotidien d'Ignace ; écueils : scrupule, examen superficiel ; canon 988.
11. L'acte de contrition, prière du pénitent — formule française traditionnelle, analyse ; latin Actus contritionis ; place dans le rite (Ordo paenitentiae 1973) ; modèles bibliques (Lc 15:18, Lc 18:13, Ps 51) ; prière du soir, danger de mort.
