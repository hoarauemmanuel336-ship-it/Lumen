# 65-01-l · Le dimanche (premier cours du fichier 65, lettre l)

Question centrale : pourquoi le dimanche, et non le sabbat ni une fête annuelle, est-il le fondement de toute l'année liturgique ?
Obstacles du novice : dimanche = simple jour de repos civil / « sabbat chrétien » décrété par Constantin ou le pape ; obligation vue comme règle extérieure ; messe du samedi soir vue comme passe-droit ; ADAP confondue avec la messe.

Leçons (12) :
1. L'année liturgique, déploiement du mystère du Christ (SC 102) : commémoration à jours fixes ; semaine, Pâques annuelle, cycle ; mystères rendus présents ; « aujourd'hui » ; temporal/sanctoral (lien #ouverture-d) ; vue d'ensemble des temps (liens vers cours du fichier).
2. Le dimanche, fête primordiale et noyau (SC 106) : Pâque hebdomadaire ; dimanche plus ancien que l'année ; Pâques = grand dimanche annuel ; fondement et noyau ; jour de joie et de cessation du travail.
3. Le premier jour de la semaine : Jean 20:1-29 (v.1, 19, 26), Luc 24 (Emmaüs, fraction du pain), Marc 16, Matthieu 28 ; Pentecôte ; le dimanche naît d'un événement.
4. Du sabbat au dimanche dans l'Église apostolique : le sabbat (Gn 2, Ex 20, Dt 5) ; Jésus maître du sabbat ; premiers chrétiens au Temple ; Ac 20:7, 1 Co 16:2 ; Col 2:16-17 ; Ignace (Magn 9, via CEC 2175) ; accomplissement, pas transfert ; erreur « Constantin/le pape a changé le sabbat ».
5. Le nom de jour du Seigneur : kyriakê hêmera (Ap 1:10), kyriakon deipnon (1 Co 11:20), Didachè 14, latin dies dominica → dimanche ; dies solis, Justin, Christ soleil (Ml 3:20, Jn 8:12) ; autres langues.
6. Le huitième jour, jour de la création nouvelle : premier jour de la création (Gn 1:3-5), 2 Co 5:17 ; huitième jour : Barnabé, Justin (huit personnes de l'arche 1 P 3:20-21, circoncision Col 2:11-12), baptistères octogonaux, Augustin Cité de Dieu XXII,30, Basile via DD 26 ; CEC 2174.
7. Le jour de l'assemblée eucharistique : Ac 20:7, He 10:25, Didachè 14, Pline (stato die ante lucem), Justin Apol. I, 67 ; SC 106 ; paroisse (CEC 2179, SC 42), DD 35-36 ; le précepte (can. 1247, lien troisième commandement).
8. Les martyrs d'Abitène : persécution de Dioclétien (304), 49 martyrs, Saturnin, Émérite, proconsul Anulinus, « sine dominico non possumus » ; sens de dominicum ; DD 46 ; Benoît XVI à Bari (2005).
9. La loi de Constantin (321) : texte (CJ 3,12,2), exception des campagnes, loi de juillet 321 (affranchissements) ; ce qu'elle change et ne change pas ; DD 64 ; sens chrétien du repos (CEC 2184-2188, DD 65-68).
10. La primauté du dimanche dans le calendrier : SC 106 ; Normes universelles 4-7 (paraphrasées) ; ne cède qu'aux solennités et fêtes du Seigneur ; dimanches de l'Avent, Carême, Pâques ; exemples ; dimanches attribués (Sainte Famille, Baptême, Trinité, Christ Roi) ; transferts (Épiphanie, Fête-Dieu) ; lien #ouverture-d.
11. La lettre Dies Domini (31 mai 1998) : contexte (week-end), plan en cinq chapitres + intro + conclusion, idées maîtresses, « N'ayez pas peur de donner votre temps au Christ ! ».
12. La messe anticipée du samedi soir et les assemblées dominicales en l'absence de prêtre : jour liturgique depuis le soir (Gn 1:5), premières vêpres, histoire (Pie XII 1953/1957, Eucharisticum mysterium 1967), can. 1248 §1, DD 49 ; ADAP : SC 35,4, can. 1248 §2 (CEC 2183), Directoire 1988, DD 53, éléments, précautions.
