# 69-01-l : L'institution de la confirmation (lettre l, premier cours du fichier 69)

État : TERMINÉ (12 leçons, 70 exercices + bilan de 6 ; contrôle, humaniser et essai d’assemblage faits).

Question centrale : sur quoi repose la confirmation, puisque les évangiles ne montrent jamais Jésus confirmer ?
Obstacles du novice : croire que « confirmation » veut dire « je confirme mon baptême » ; croire que le baptisé n'a pas encore l'Esprit ; ignorer le lien onction / Christ / chrétien ; lire Samarie comme un « baptême dans l'Esprit » d'expérience ; croire que l'institution par le Christ exige un rite fixé par Jésus ; croire que les protestants n'ont pas de confirmation.

Sources vérifiées en ligne (vatican.va, mot à mot sur les passages cités) : Catéchisme 1285 (citation de LG 11), 1287, 1288, 1289. Le reste : voir doutes.md.

Liens : 51-l-esprit-saint.html#ouverture-a/-v/-l/-p/-d ; 68-le-bapteme.html#ouverture-l ; 67-les-sacrements-en-general.html#ouverture-l/-e/-c ; 49-la-redemption.html#ouverture-t ; même fichier #ouverture-r/-e/-m/-i.

Leçons (12) :
1. Confirmation et chrismation : les noms du sacrement (confirmatio, deux sens CEC 1289 ; histoire du mot en Gaule au Ve s., consignatio, signaculum ; chrismation, myron, chrisma ; deux noms, un sacrement de l'initiation).
2. L'onction dans l'Ancien Testament : prêtres, rois, prophètes (huile ; Ex 30 ; Aaron ; Saül, David 1 S 16:13, Salomon ; oint du Seigneur ; Élisée ; mashiah/christos ; triple office).
3. L'Esprit promis au Messie et à tout le peuple (Is 11:1-2 ; Is 61:1-3 ; Joël 3:1-2 ; Nb 11:29 ; Ez 36:26-27 ; CEC 1286-1287).
4. Le Christ oint de l'Esprit au Jourdain (Mt 3:16-17 ; Jn 1:32-33 ; Lc 4:16-21 ; Ac 10:38 ; Jn 3:34 ; oint dès l'Incarnation, manifesté au Jourdain ; Ps 133 ; chrétien = oint, CEC 1289).
5. La promesse de l'Esprit aux disciples (Jn 14:16-17 ; Jn 16:7 ; Jn 7:39 ; Jn 15:26-27 ; Lc 24:49 ; Ac 1:4-5, 1:8 ; témoins ; LG 11 par CEC 1285).
6. La Pentecôte, source de la confirmation (Ac 2:1-4 ; assurance Ac 4:13, 4:31 ; Jn 20:22 et Pentecôte, CEC 1287 ; Ac 2:38-39 ; CEC 1288 Paul VI ; Florence paraphrasé ; ce que la confirmation reprend et ne reprend pas).
7. Samarie : Pierre et Jean imposent les mains (Ac 8:4-25 ; lectures ; Simon ; Philippe et les apôtres).
8. Éphèse et la « doctrine de l'imposition des mains » (Ac 19:1-7 ; comparaison avec Samarie ; Hb 6:1-2 ; sens biblique du geste ; Corneille Ac 10:44-48 ; sceau et onction 2 Co 1:21-22, Ep 1:13, 1 Jn 2:20).
9. Le Christ a-t-il institué la confirmation ? (Trente, fait défini ; opinions médiévales ; Thomas « non exhibendo, sed promittendo » ; institution dans la substance ; tableau des manières).
10. Tertullien, la Tradition apostolique et saint Cyprien (De baptismo 7-8 ; De resurrectione 8 ; rites de la Tradition apostolique ; Cyprien, lettre 73 ; ce que montrent ces témoins).
11. Saint Cyrille de Jérusalem et l'onction du chrême (Cat. myst. III : devenus christs ; pas une simple huile ; sens oints ; figures d'Aaron et de Salomon ; 1 Jn 2).
12. Les réformateurs et le concile de Trente (Luther, Calvin, Melanchthon ; session VII, trois canons ; raisons ; Vatican II SC 71, LG 11, Paul VI).
