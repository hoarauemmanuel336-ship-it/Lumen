# 56-02-p « La primauté de Pierre » (fichier 56, lettre p) : plan

Question centrale : quelle place unique le Christ a-t-il donnée à Pierre parmi les Apôtres, comment l'Écriture la montre-t-elle, et comment l'Église ancienne l'a-t-elle reconnue dans l'Église de Rome ?
Obstacles du novice : croire que la primauté est une invention romaine tardive ; opposer Pierre et le Christ comme fondement ; croire que les clés et le pouvoir de lier sont la même chose que le pardon des péchés seul ; confondre primauté et impeccabilité (reniement, Antioche) ; croire que la venue de Pierre à Rome est une légende ; lire « petros / petra » comme petit caillou / roc ; projeter la papauté moderne sur le Ier siècle.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. Simon devient Pierre : Jean 1:42, Kèpha / Petros, « rocher » ; sens d'un nom donné par Dieu (Abraham, Israël) ; Céphas chez Paul (1 Co 15:5, Ga 1:18) ; un nom qui n'était pas un prénom ; Pierre = fonction.
2. La promesse de Césarée de Philippe : Mt 16:13-19 ; la confession ; « chair et sang », révélation du Père ; « sur cette pierre je bâtirai » (futur, ekklèsia) ; les portes du séjour des morts ; jeu de mots en araméen ; Mt 16:23 « Satan ».
3. Les clés du Royaume : Is 22:15-25 (Shebna, Éliakim, maître du palais) ; clés = autorité de gouverner la maison ; une charge qui se transmet ; Ap 3:7 (le Christ a la clé de David) ; CEC 553.
4. Lier et délier : sens juif (interdire / permettre, exclure / réintégrer) ; Mt 16:19 à Pierre seul ; Mt 18:18 aux disciples ; LG 22 (collège uni à sa tête) ; CEC 553 (absoudre, juger la doctrine, décider la discipline) ; distinction avec Jn 20:23 (lien sacrements).
5. Affermir ses frères : Lc 22:31-34 ; « vous » / « toi » ; prière du Christ pour la foi de Pierre ; reniement annoncé ; Pastor aeternus ch. 4 (lien vers infaillibilité) ; la primauté ne repose pas sur la vertu de Pierre.
6. « Pais mes brebis » : Jn 21:15-19 ; triple question après le triple reniement ; agneaux / brebis, paître / garder ; le troupeau du Christ (Jn 10) ; annonce du martyre ; 1 P 5:1-4 ; Pastor aeternus ch. 1.
7. Pierre premier à Jérusalem (Actes 1-15) : rappel des listes (lien ouverture-l) ; Ac 1:15 ; Pentecôte Ac 2:14 ; Ac 3-5 ; Samarie Ac 8:14 ; Ac 9:32 ; Corneille Ac 10-11 ; Ac 12 ; Ac 15:7 ; Jacques ; Ga 1:18 ; Antioche Ga 2:11.
8. Pierre à Rome : 1 P 5:13 « Babylone » ; Jn 21:18-19 ; Clément 1 Co 5 ; Ignace Rom 4,3 ; Gaïus (Eusèbe HE II, 25) ; Tertullien ; Néron ; fouilles 1939-1949 ; Pie XII 1950 ; Paul VI 1968 ; degré de certitude.
9. Ignace d'Antioche : lettre aux Romains (vers 107-110), adresse « qui préside dans le pays des Romains… qui préside à la charité » ; sens d'agapè ; Clément de Rome et Corinthe (lien ouverture-l) ; Rom 4, 3 ; ce que le texte dit et ne dit pas.
10. Irénée : Contre les hérésies III, 3, 2-3 ; contexte gnostique ; latin potentior principalitas, convenire ; débats d'interprétation ; liste des évêques de Rome ; Victor et la querelle pascale.
11. Léon le Grand : pape 440-461 ; sermons d'anniversaire (Pierre vit et préside dans son siège ; héritier indigne) ; Tome à Flavien et Chalcédoine 451 « Pierre a parlé par Léon » ; Éphèse 431 (rappel) ; ce que Léon ajoute (héritier, droit romain).
12. Le rocher : lectures « la foi de Pierre » et « le Christ seul » (1 Co 3:11, 1 Co 10:4 ; Augustin, Retract. I, 21 ; Chrysostome ; Luther, Calvin) ; petros/petra ; réponse catholique (Kèpha, Cullmann, CEC 424 et 881, Pastor aeternus ch. 1) ; lecture orthodoxe (Cyprien, primauté d'honneur) ; degrés d'autorité.
