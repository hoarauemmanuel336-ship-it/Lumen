# 73-06-s — Le sujet de l'ordination (lettre s)

Question centrale : qui peut être ordonné, et comment l'Église discerne-t-elle qu'un homme est appelé ?
Obstacles du novice : croire que la vocation est un sentiment intérieur qui suffit, ou une « envie » qui donne droit ; confondre validité et licéité ; prendre les qualités requises pour une exigence de perfection ; voir dans les irrégularités des punitions ; ignorer ce qu'est un séminaire et pourquoi il existe ; ne pas savoir par quelles étapes on arrive à l'ordination.

Leçons (12) :
1. Un homme baptisé : le sujet valide — validité / licéité ; can. 1024, CEC 1577 ; baptême porte des sacrements (lien 68 v) ; cas d'un baptême invalide (2020) ; homme : une phrase + lien #ouverture-o ; intention de recevoir (Augustin 391) ; confirmation pour la licéité (can. 1033, lien 69 m) ; Ambroise 374.
2. La vocation : appel intérieur et appel de l'Église — He 5:4, Mc 3:13-14, Jn 15:16, Is 6:8, Jr 1:5-7, 1 S 3:8-10 (Éli), Ac 13:2-3 ; PO 11 (voix non extraordinaire, signes) ; controverse Lahitton (1909-1912) ; appel de l'évêque (« Me voici » du rite, lien #ouverture-r) ; signes.
3. L'absence de droit à l'ordination — CEC 1578 ; can. 1025 §2, 1026, 1029, 1030, 1052 ; OT 6 ; 1 Tm 5:22 ; Ac 8:18-21 ; don immérité ; refus n'est pas un jugement de sainteté.
4. La foi intègre — can. 1029 ; Tt 1:9, 2 Tm 1:13-14, 1 Tm 3:9 ; profession de foi et serment de fidélité (can. 833) ; irrégularité apostasie/hérésie/schisme (lien s9) ; foi vécue et non seulement sue.
5. L'intention droite — Trente XXIII réforme ch. 4 (ne pas fuir la juridiction séculière) ; OT 6 ; Mc 10:37-44, 1 P 5:2-3, Ac 8 ; mauvais motifs ; liberté (can. 1026, 1036) ; purification (Léon XIV, Une fidélité qui génère l'avenir 12).
6. Les vertus et la bonne réputation — 1 Tm 3:1-7, Tt 1:7-8, Ac 6:3, Ac 16:1-2, 1 Tm 3:10 ; can. 1029, 1043, 1051 ; publication des noms (Trente ch. 5) ; passé pardonné.
7. La maturité humaine et affective — OT 11 ; Lc 2:52 ; PDV 43-44 (paraphrase) ; capacité au célibat (lien #ouverture-c) ; Léon XIV n. 10 et 12 ; instruction de 2005 et Ratio 199-201 ; protection des mineurs.
8. La santé physique et psychique — OT 6 ; Lv 21:17-18 ; can. 1029, 1041 1°, 1051 ; maladie cœliaque et alcoolisme (CDF 2003) ; orientations de 2008 sur la psychologie ; can. 220.
9. Les irrégularités et les empêchements — can. 1040-1049 ; liste ; dispenses ; cas occultes ; obligation de révéler ; néophyte (Ambroise) ; homme marié → diaconat permanent.
10. Le séminaire : Trente et Optatam totius — avant Trente ; Trente XXIII ch. 18 (15 juillet 1563) ; seminarium ; Charles Borromée ; Optatam totius (28 octobre 1965) ; famille « premier séminaire » ; Mc 3:14 ; Léon XIV 2025.
11. Les quatre dimensions et la Ratio fundamentalis (2016) — PDV (1992) ; humaine, spirituelle, intellectuelle, pastorale ; Ratio 1970/1985/2016 ; étapes propédeutique, disciples, configuration, pastorale ; formation unique, intégrale, communautaire, missionnaire.
12. Les étapes vers l'ordination et l'âge requis — admission (can. 1034) ; lecteur et acolyte (can. 1035, lien #ouverture-l) ; déclaration (1036) ; célibat (1037) ; retraite (1039) ; documents et scrutins (1050-1052) ; âges (1031, 378) ; Trente 22/23/25 ; Nb 8:24, Lc 3:23, 1 Tm 4:12.
