# 08-03-i · L'intelligence (fichier 08, lettre i) · plan

Question centrale : qu'est-ce que cette faculté qui connaît ce que sont les choses, que peut-elle atteindre, comment opère-t-elle, à qui appartient-elle, jusqu'où va-t-elle (Dieu), et en quoi diffère-t-elle d'une machine ?
Ne pas refaire : abstraction, intellect agent/possible, espèce, verbe, retour à l'image (06-04-i : lien ouverture-i) ; preuve complète de la spiritualité de l'âme, chiliogone, lunettes vertes, langue amère, chien/lévrier (08-08-s) ; Pomponazzi (08-08-s).

1. « Lire au-dedans » : le mot (intellectus, intus legere ; étymologie philologique inter-legere), faculté de l'âme, connaître l'être et l'essence vs les sens ; intelligence naturelle et don d'intelligence (II-II q.8 a.1). Siracide 17:6-7.
2. L'objet propre : la quiddité des choses sensibles (I q.84 a.7) ; proportion connaissant/connu (sens, homme, ange) ; conséquences : l'invisible connu par le visible ; foi : paraboles, sacrements (III q.61 a.1), Incarnation (préface de Noël).
3. L'objet commun : l'être (I q.79 a.7 ; q.5 a.2 ; De ver. q.1 a.1) ; « l'âme est en quelque manière toutes choses » (De l'âme III, 8, 431b21) ; désir de savoir (Métaph. A, 1, 980a21 ; I q.12 a.1) ; débat Scot ; capacité de Dieu, désir naturel de voir Dieu (question débattue, Humani generis 26).
4. L'immatérialité de l'opération : sans organe (De l'âme III, 4) ; l'universel (exemples neufs) ; argument de l'excès du sensible (429a29-b5) ; se savoir connaître ; dépendance extrinsèque ; lien 08-08-s pour la conclusion sur l'âme.
5. Intellect et raison : intuition et discours (I q.79 a.8) ; une seule faculté ; homme rationnel, ange intellectuel, Dieu ; Boèce ; Antiqua et nova 14 ; foi : théologie discursive, contemplation simple regard (II-II q.180 a.3 ad 1), vision.
6. Raison spéculative et raison pratique (I q.79 a.11 ; De l'âme III, 10) ; vérité pratique (EN VI, 2, 1139a29-31) ; vertus intellectuelles ; syndérèse (q.79 a.12), premier principe pratique (I-II q.94 a.2), conscience acte (q.79 a.13) → liens morale.
7. La connaissance de soi par la réflexion (I q.87 a.1-3) ; perception d'existence / connaissance de nature ; Augustin (Conf. X, 16, 25) ; contre le cogito cartésien ; foi : examen de conscience.
8. Le monopsychisme d'Averroès : Alexandre, Avicenne, Averroès ; raisons ; conséquences ; averroïstes latins, condamnation de 1270.
9. La réponse de saint Thomas : De unitate intellectus (1270) ; « hic homo intelligit », le mur ; intellect agent en chacun (q.79 a.4-5), Ps 4:7 ; défi final ; Latran V (1513).
10. La connaissance humaine de Dieu : par les créatures, jamais vision directe ici-bas (I q.12 a.11-12) ; ontologisme ; foi « dans un miroir » ; lumière de gloire (Vienne, Benoît XII).
11. Intelligence humaine et intelligence artificielle : ce que fait l'IA (Dartmouth, Turing, inférence statistique), chambre chinoise (Searle 1980), Antiqua et nova (28 janvier 2025) n. 10, 12, 30-35.
Bilan : 6 exercices.
