# Plan du cours 68-05-v : La validité du baptême et la question du rebaptême

Question centrale : pourquoi l'Église ne baptise-t-elle jamais deux fois, et comment juge-t-elle qu'un baptême a vraiment eu lieu ?
Obstacles du novice : croire que l'Église « rebaptise » les protestants ; confondre hérésie du ministre et défaut de forme ; croire que la foi du ministre décide ; ne pas voir que le baptême sous condition n'est pas un second baptême ; croire que « Nous te baptisons » est un détail ; croire que la formule trinitaire suffit toujours (cas mormon).

Fichiers : 00-ouverture.html, 01.html … 11.html, 99-bilan.html.

1. « Un seul baptême » : Éph 4:4-6 ; Credo de Nicée-Constantinople (grec homologoumen hen baptisma) ; raisons : une seule mort du Christ (Rom 6:9-10), naissance unique (Jean 3:5), caractère (lien 67 #ouverture-c) ; vocabulaire réitérer / rebaptiser ; Actes 19:1-6 (disciples d'Éphèse : le baptême de Jean n'était pas le sacrement) ; Hébreux 6:4-6 chez les Pères.
2. Cyprien et Étienne Ier (255-257) : contexte (schisme de Novatien, Agrippinus vers 220, conciles d'Asie, Firmilien) ; arguments de Cyprien (lettres 69-75, conciles de 255 et 256, Sententiae episcoporum) ; menace de rupture ; fin de la querelle (Sixte II, martyre de Cyprien 258).
3. La règle romaine : « nihil innovetur nisi quod traditum est » (lettre 74, 1) ; la Tradition comme critère ; imposition des mains en pénitence ; Vincent de Lérins (Commonitorium 6) ; Augustin : coutume apostolique.
4. Le concile d'Arles (314) : contexte donatiste, canon sur les Africains qui rebaptisent ; interroger sur le Symbole ; Nicée (325) canons 8 et 19 ; un critère objectif : la forme trinitaire.
5. Augustin contre les donatistes : De baptismo ; « c'est le Christ qui baptise » (Jean 1:33 ; Tract. in Ioh. 6) ; sacrement / fruit ; marque du soldat ; Augustin et Cyprien (lien 67 #ouverture-i pour la crise donatiste en général).
6. Le baptême donné hors de l'Église catholique : Trente VII, can. 4 sur le baptême ; matière, forme, intention ; CIC 869 § 2 ; Directoire œcuménique 1993 ; UR 3 et 22 ; Églises orthodoxes (et leur pratique parfois de rebaptiser les latins, Oros de 1755) ; communautés sans baptême d'eau.
7. Les formules non trinitaires : « au nom de Jésus » (Actes 2:38 et sa lecture), pentecôtistes unitaires ; « Créateur, Rédempteur, Sanctificateur » (CDF 2008) ; erreurs de langue (Zacharie et Boniface) vs changement voulu.
8. « Nous te baptisons » (CDF, 2020) : responsum et note doctrinale ; SC 22 § 3 ; le ministre agit au nom du Christ ; cas Detroit (2020), Phoenix (2022) ; Gestis verbisque (2024).
9. Le baptême des mormons (CDF, 2001) : mots semblables, sens différent ; Ladaria ; doctrine de Dieu, origine du baptême, baptême pour les morts (1 Cor 15:29) ; intention.
10. Le baptême sous condition : doute réel ; CIC 869 ; formule ; histoire (Alexandre III) ; cas typiques ; abus d'une rebaptisation systématique (lien 67 #ouverture-m).
11. Les anabaptistes : Zurich 1525, Grebel, Manz, Schleitheim 1527, Münster, Menno Simons, baptistes ; leurs raisons ; Trente can. 13 ; réponse catholique (lien #ouverture-b) ; dialogue aujourd'hui.
Bilan : 6 exercices croisés.
