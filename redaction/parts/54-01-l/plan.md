# Plan du cours 54-01-l : Le mot Église et le dessein de Dieu

Question centrale : que veut dire le mot « Église », et d'où vient l'Église ? Réponse : une convocation de Dieu, voulue par le Père, préfigurée, préparée, fondée par le Christ, née de la Croix, manifestée par l'Esprit, consommée dans la gloire ; germe du Royaume ; peuple rassemblé de l'unité trinitaire.
Obstacles du novice : Église = bâtiment ou clergé ; Église née seulement à la Pentecôte ; Jésus n'aurait pas voulu d'Église (Loisy) ; Église = Royaume purement et simplement ; « Ecclesia ab Abel » = tout le monde est dans l'Église.

Fichiers : 00-ouverture.html, 01.html … 11.html, 99-bilan.html.

1. « Ekklèsia », l'assemblée convoquée : ek-kalein ; l'ekklèsia civique d'Athènes et d'Éphèse (Actes 19) ; ce que les chrétiens ont gardé et changé (c'est Dieu qui convoque) ; définition d'Église. Mots : Ekklèsia, Convocation, Église.
2. Le qahal d'Israël et la Septante : qahal, ʿédah ; Septante ekklèsia / synagôgè ; « jour de l'assemblée » (Dt 4:10, 9:10) ; Actes 7:38 ; « Église de Dieu » (Ne 13:1, LG 9) ; pourquoi ekklèsia plutôt que synagogue. Mots : Qahal, Septante, Synagôgè, Église de Dieu.
3. Kirche, church et les trois sens : kuriakon / kuriakè (CEC 751) ; langues romanes vs germaniques et slaves ; église / Église ; trois sens CEC 752 (1 Co 11:18 ; 1 Co 1:2 ; Mt 16:18, Col 1:18) ; inséparables ; Église domestique Rm 16:5. Mots : Kuriakon, Assemblée liturgique, Église locale, Église universelle.
4. Un dessein né dans le cœur du Père : Éphésiens 1:3-10 ; mystère, récapitulation ; Éph 3:9-11 ; CEC 759-760 (Hermas, Clément d'Alexandrie) ; LG 2 et les cinq moments (annoncée en figure, préparée, établie, manifestée, consommée). Mots : Dessein bienveillant, Mystère, Récapitulation, Cinq moments de l'Église.
5. Préfigurée dès l'origine : CEC 761 (réponse au chaos du péché) ; Abel le juste (Gn 4, He 11:4, Mt 23:35) ; Ecclesia ab Abel : LG 2, Augustin Sermon 341, Grégoire Hom. 19 ; Augustin Cité de Dieu XV ; Thomas III q8 a3 ; ce que l'adage dit et ne dit pas. Mots : Ecclesia ab Abel, Préfiguration, Justes.
6. Préparée dans l'Ancienne Alliance : Abraham (Gn 12:1-3) ; élection (Dt 7:6-8) ; Sinaï (Ex 19:5-6) ; prophètes : nouvelle alliance (Jr 31:31-34), rassemblement (Éz 37), nations (Is 2:2-3 ; 49:6) ; CEC 762 ; Rm 11:29. Mots : Élection, Alliance, Peuple de Dieu, Nouvelle alliance.
7. Fondée par le Christ : annonce du Royaume (Mc 1:15, LG 5) ; petit troupeau (Lc 12:32) ; les Douze (Mc 3:13-15) ; promesse à Pierre (Mt 16:18) ; Cène (Lc 22:19-20) ; envoi (Mt 28:18-20) ; Loisy et Lamentabili 52. Mots : Fondation de l'Église, Les Douze, Petit troupeau.
8. Née du côté ouvert : Jn 19:33-37 ; Gn 2:21-23 ; pleura ; aperuit (Augustin) ; sang et eau = baptême et eucharistie (Chrysostome) ; Ambroise (CEC 766) ; SC 5 ; LG 3 ; concile de Vienne (1312) ; nouvelle Ève (lien Marie). Mots : Côté ouvert, Sang et eau, Église nouvelle Ève.
9. Manifestée à la Pentecôte : Actes 2:1-41 ; Joël ; Babel (Gn 11 ; AG 4) ; LG 4 ; née / manifestée ; Actes 2:42. Mots : Pentecôte, Manifestation de l'Église, Babel.
10. Consommée dans la gloire ; germe du Royaume : LG 48, CEC 769 ; Ap 19:7, 21:2-3 ; He 12:22-23 ; pèlerinage ; LG 5 germe et commencement ; ni identité ni séparation (DI 18-19) ; Mt 13:31-33. Mots : Consommation de l'Église, Église en pèlerinage, Germe et commencement du Royaume.
11. Peuple rassemblé de l'unité trinitaire : LG 2-4 (Père, Fils, Esprit) ; Cyprien De oratione dominica 23 ; LG 4 ; Jn 17:21 ; Éph 2:18 ; conséquences. Mots : Origine trinitaire de l'Église, Peuple de l'unité trinitaire.
