# 22-04-e — L’école d’Alexandrie (lettre e, fichier 22-la-patristique.html)

Question centrale : pourquoi une ville a-t-elle donné son nom à une manière chrétienne de lire l’Écriture et de penser le Christ, et que vaut cet héritage ?
Obstacles du novice : « école » pris au seul sens d’établissement ; allégorie = fantaisie ; Platon = paganisme à rejeter en bloc ou Évangile déguisé ; Logos-sarx = hérésie ; Alexandrie = monophysisme ; confondre Didascalée et Bibliothèque.

Éviter les redites : l’exégèse des Pères (12-…#ouverture-e) a déjà Philon (Abraham, De migratione, corps/âme) et Origène (puits d’Isaac, Exode 16:29, pierres d’achoppement) ; la Septante détaillée (11-…#ouverture-e, Aristée) ; l’apollinarisme et Eutychès (45-…#ouverture-l, Lettre 101, Luc 2:52, Mt 26:38, Jn 11:35, Tome de 362) ; affaire des deux Denys (28-…#ouverture-c). Ici : exemples neufs, angle de l’école.

Leçons (01.html à 11.html) :
1. Alexandrie, la ville du livre — fondation 331, Ptolémées, Musée et Bibliothèque, fin de la Bibliothèque ; Église d’Alexandrie (Marc, Eusèbe HE II,16 ; Apollos Actes 18:24-25 ; Nicée canon 6) ; « école » au double sens.
2. Les Juifs d’Alexandrie et la Septante — Philon In Flaccum 43, 55 ; Vie de Moïse II, 37, 40-41 (fête de Pharos) ; Siracide (prologue) ; Sagesse 7:25-26 et Hébreux 1:3 ; Aristobule ; ce que la Septante donne à l’école.
3. Philon d’Alexandrie — vie ; œuvres ; Quod Deus 53-54 (Nombres 23:19 / Deutéronome 8:5) ; Leg. All. I, 63-65 (Genèse 2:10) ; le Logos (Opif. 24-25 ; Conf. 146) ; Eusèbe HE II,17 ; Jérôme De viris 11.
4. Le Didascalée, de Pantène à Origène — Eusèbe HE V,10 ; Pantène (Stromates I,1,11 ; Inde) ; Clément (lien) ; Origène à 18 ans (HE VI,3), Héraclas (VI,15) ; le programme (Grégoire, lien) ; débat des historiens.
5. Le Didascalée après Origène — Héraclas (VI,26 ; VI,35 ; VII,7 « pape ») ; Denys (VI,29 ; VII,25) ; Théognoste, Piérius (De viris 76), Pierre ; Didyme l’Aveugle (De viris 109 ; Jérôme Lettre 68,2 ; Socrate HE IV,25 ; Tura 1941 ; condamnation tardive) ; fin de l’école.
6. L’allégorie — allêgoria ; Galates 4:24 ; conviction alexandrine ; Clément, Quel riche 29 (Samaritain) ; Origène (lien) ; règles et dérives ; critique antiochienne (lien) ; jugement de l’Église (CEC 115-117).
7. La philosophie, préparation à l’Évangile — Ammonius (HE VI,19) ; Stromates I,5,28 ; Fides et ratio 38 ; Lettre à Grégoire 1-2 et Exode 12:35-36 ; ce que Platon apporte ; limites (Colossiens 2:8 ; 1 Co 1:22-24) ; erreurs venues de là.
8. Le Logos au centre — Jean 1:1-3 ; Logos grec et philonien ; Clément, Pédagogue I,2 et I,7 ; Origène, Principes I,2,2 et I,2,4 ; Athanase, Décrets 27 ; le risque subordinatien, Arius ; Denys (lien) ; Nicée.
9. La christologie Logos-sarx — Jean 1:14 ; l’étiquette moderne (Grillmeier) ; le Verbe sujet unique ; Athanase, Contre les ariens III, 31-34 ; forces (idiomes, Theotokos, divinisation) ; la question de l’âme du Christ ; Cyrille, 2e lettre à Nestorius ; Logos-anthropos (lien).
10. Les héritiers : Athanase et Cyrille — le siège d’Alexandrie ; ce qu’ils gardent et changent ; Athanase (lien), Cyrille (lien), Théophile et l’origénisme ; « sceau des Pères ».
11. La pente de l’école : apollinarisme, puis monophysisme — Apollinaire ; Lettre 101 (bref) ; 377, 381 (canon 1) ; correction alexandrine (Tome 362, 7 ; Cyrille) ; Eutychès 448, Éphèse 449, Chalcédoine 451 ; miaphysisme copte ; déclaration de 1973 ; Jean 12:27, Hébreux 2:17.
Bilan : 6 exercices croisés.

État : livré (22-04-e.html), contrôlé, humanisé, essai d’assemblage réussi.
