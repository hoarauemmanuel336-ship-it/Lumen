# Plan 06-03-c : La connaissance sensible (lettre c)

Question centrale : comment un être de chair connaît-il le monde par ses sens, et que vaut cette connaissance ?
Obstacles du novice : croire que connaître = fabriquer une copie dans la tête ; confondre sens et organe ; croire que « les sens nous trompent » ; ignorer les sens internes ; lire l'adage « rien dans l'intelligence… » comme un empirisme.

Fichiers : 00-ouverture.html, 01.html … 11.html, 99-bilan.html.

1. Connaître, c'est devenir l'autre — connaissance = être l'autre en tant qu'autre ; ST I q.14 a.1 ; De anima III,8 431b21 ; intentionnalité, forme sans matière (cire et anneau, De anima II,12 424a17-21) ; être naturel / intentionnel ; immutatio spiritualis (ST I q.78 a.3). Foi : ouverture au réel, Dieu connaissant suprêmement immatériel.
2. Le sens, faculté du singulier matériel — définition sensus ; organe ; singulier ; puissance passive ; ni pur corps ni pur esprit ; les cinq sens comme ensemble : distinction par l'objet propre, unité (genre sensitif, toucher racine, sens commun). Foi : Proverbes 20:12 ; Psaumes 94:9.
3. La vue et l'ouïe — couleur, lumière ; sens le plus spirituel (q.78 a.3 « maxime spiritualis ») ; Métaphysique A,1 980a21-27 ; ouïe : son, parole, enseignement (De sensu 1, 437a) ; Romains 10:17 ; 1 Jean 1:1-3.
4. L'odorat, le goût et le toucher — odeur (faible chez l'homme, De anima II,9 421a9-10) ; saveur, goût forme de toucher (II,10 422a8) ; toucher fondamental, chez tout animal (II,2 413b4-5 ; III,12-13), finesse humaine (421a20-26) ; Luc 24:39 ; Psaumes 34:9.
5. Les trois sortes de sensibles — propre, commun (mouvement, repos, nombre, figure, grandeur), par accident (fils de Diarès / l'homme vu) ; De anima II,6.
6. La vérité des sens — le sens ne se trompe pas sur l'objet propre (III,3 428b18-19) ; erreurs sur communs et par accident ; soleil d'un pied (428b3-4) ; bâton dans l'eau ; l'erreur vient du jugement ; conditions. Foi : témoins (2 Pierre 1:16, Jean 20:27) ; Eucharistie ST III q.75 a.5 ad 2 ; Adoro te.
7. Les sens internes et le sens commun — pourquoi des sens internes (q.78 a.4 : nature ne manque pas du nécessaire ; présence/absence) ; quatre puissances ; Avicenne cinq ; sens commun racine (ad 1), discerne blanc/doux, voit qu'il voit.
8. L'imagination — trésor des formes ; phantasme (grec phantasma ; phantasia de phaos, III,3 429a2-4) ; recompose (montagne d'or) ; rêves ; rôle dans la pensée (lien 06-04-i) ; visions imaginatives (Augustin, Gen. ad litt. XII) ; images sacrées, paraboles.
9. L'estimative et la cogitative — brebis/loup, oiseau/paille ; intentions non senties ; cogitative = raison particulière, collation ; saisie de l'individu concret (sensible par accident) ; expérience, prudence (lien #sujet:vertus.prudence).
10. La mémoire sensible — trésor des intentions ; passé perçu comme passé ; réminiscence (« quasi syllogistice ») ; mémoire → expérience (Métaphysique A,1 980b28-981a1) ; distinction avec la mémoire intellectuelle ; Deutéronome 4:9.
11. Des sens à l'intelligence — adage (De veritate q.2 a.3 arg.19) ; De anima III,8 432a7-9 ; sens exact (origine, non borne) ; ST I q.84 a.6 (cause matérielle) ; Leibniz « nisi ipse intellectus » ; Dieu connu par les créatures (Sagesse 13:5, Romains 1:20, Dei Filius) ; sacrements sensibles (ST III q.60 a.4 ; CEC 1146) ; erreurs : ontologisme, angélisme.
Bilan : 6 exercices croisés.
