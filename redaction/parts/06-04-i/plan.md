# 06-04-i · L’intelligence et l’abstraction (lettre i) · plan

Question centrale : comment l’intelligence, qui ne reçoit des sens que du singulier matériel, forme-t-elle des idées universelles et immatérielles, et pourquoi cela compte-t-il pour la foi ?
Obstacles du novice : confondre l’image et le concept ; croire que l’abstraction appauvrit ou fabrique une « moyenne » ; prendre l’espèce intelligible pour ce que l’on connaît ; faire de l’intellect agent une puissance extérieure ou unique ; croire que la pensée pure se passe d’images ; confondre mathématique et métaphysique ; croire que l’universel est un simple nom ou une image floue.

Fichiers : 00-ouverture.html, 01..11.html, 99-bilan.html.

1. Connaître ce qu’est la chose : la connaissance intellectuelle (quiddité, universel, immatériel ; chien/maître, Helen Keller ; Genèse 2:19-20 ; foi : définitions du dogme).
2. L’image et le concept : différence de nature (chiliogone de Descartes, Méd. VI ; photographie composite de Galton ; tableau des différences ; foi : penser Dieu sans l’imaginer, la substance eucharistique).
3. L’abstraction : tirer l’universel du singulier (abstrahere ; considérer sans séparer, Physique II, 2 ; ST I q.85 a.1 ; matière individuelle ; nature considérée en elle-même ; foi : unité du genre humain, spiritualité de l’âme, lien 08-s).
4. L’intellect agent (De l’âme III, 5, 430a14-17 ; ST I q.79 a.3-5 ; lumière ; propre à chacun, lien 08-i ; foi : Psaumes 4:7 lu par saint Thomas, Jean 1:9, lumière naturelle de la raison de Dei Filius).
5. L’intellect possible et l’espèce intelligible (De l’âme III, 4, 429a24, 430a1 tablette ; ST I q.79 a.2 ; espèce = ce par quoi, ST I q.85 a.2 ; foi : vision de Dieu sans espèce créée, ST I q.12 a.2, 1 Corinthiens 13:12, lien 76#ouverture-l).
6. Le verbe mental (espèce impresse/expresse ; ST I q.27 a.1 ; verbe intérieur/extérieur ; foi : Jean 1:1, le Verbe en Dieu, analogie, liens 36#ouverture-g et 26#ouverture-t).
7. Le retour à l’image (conversio ad phantasmata ; ST I q.84 a.7 ; De la mémoire 449b31 ; connaissance du singulier par réflexion ST I q.86 a.1 ; foi : ST I q.1 a.9, paraboles Marc 4:33-34, sacrements, Romains 1:20).
8. Les trois degrés d’abstraction et la division des sciences (Comm. De Trinitate q.5 a.1 et a.3 ; physique, mathématique, séparation métaphysique ; schéma des trois degrés = formulation postérieure (Cajetan, Jean de saint Thomas, Maritain) ; sciences intermédiaires ; foi : métaphysique ouverte à Dieu, Sagesse 13:5).
9. Les idées innées (Platon, réminiscence ; Descartes, Méd. III ; Notae ; Leibniz ; réponse : ST I q.84 a.3, l’aveugle-né, l’oubli ; l’inné = la lumière et les premiers principes, pas les idées ; foi : lien 10#ouverture-d).
10. L’illumination directe (Augustin De Trin. XII, 15, 24 ; intellect agent séparé (Avicenne, augustinisme avicennisant) ; ontologisme : Malebranche, Gioberti, Rosmini ; Saint-Office 18 sept. 1861 ; Post obitum 1887 et Note 2001 ; réponse : ST I q.84 a.5 ; q.88 a.3 ; foi : 1 Corinthiens 13:12, Jean 1:18, lumière de gloire, Vienne ; Bonaventure lien 10#ouverture-b).
11. L’empirisme (Locke, papier blanc ; Berkeley, idées générales ; Hume, idées copies affaiblies, Traité I,1,1 et I,1,7 ; Condillac ; réponse : différence de nature, Leibniz « nisi ipse intellectus », universel nécessaire, premiers principes ; foi : sans abstraction, pas de métaphysique ni de théologie naturelle, lien 09#ouverture-g et 10#ouverture-i).
