# 26-02-a · Augustin, prêtre et évêque d'Hippone (lettre a)

Question centrale : comment le converti de Milan, qui ne rêvait que de prière et d'étude, est-il devenu pendant près de quarante ans le pasteur d'une Église d'Afrique, et que reste-t-il de ce ministère dans l'enseignement de l'Église ?
Obstacles du novice : croire qu'Augustin a voulu être évêque ; confondre la Règle (cours r) et la maison des clercs ; ignorer la charge matérielle d'un évêque antique (tribunal, pauvres) ; croire que les conciles africains agissaient sans Rome ou contre elle ; croire que les Révisions sont un reniement ; confondre « sacrement » chez Augustin et les sept sacrements définis plus tard ; croire qu'Augustin méprise le mariage.

Sources vérifiées : Possidius, Vie d'Augustin (texte latin Weiskotten 1919, lacabalesta.it) ch. III, IV, V, VIII, XI, XVIII, XIX, XXII-XXIV, XXVI-XXIX, XXXI ; lettres 10, 21, 22, 29, 126, 213, 228 (newadvent / augustinus.it) ; sermons 355-356 (augustinus.it discorso_518/519) ; Cité de Dieu XIX, 19 ; Révisions I, 1 ; I, 13, 7 ; I, 17 ; I, 23, 2 ; II, 22-23 ; épilogue ; Bien du mariage 1 ; 3 ; 6 ; 8 ; 24, 32 ; Sainte Virginité 2 ; 3 ; 11 ; 31 ; LG 32 ; GS 48 note, 49, 50 ; CEC 1601, 1620, 1643-1654 ; Casti connubii ; De opere monachorum 29, 37.

## Leçons

1. Le retour en Afrique et les serviteurs de Dieu de Thagaste (388-391) : Rome 387-388, Carthage, Thagaste ; vente du patrimoine (lettre 126, 7) ; servi Dei, otium, « deificari in otio » (lettre 10, 2) ; Alypius, Évodius, Adéodat (mort vers 389-390), Nébridius ; œuvres (Le Maître, La Vraie Religion) en une phrase avec lien p ; Possidius III « ferme triennio ».
2. L'ordination forcée à Hippone (391) : Hippone ; pourquoi il y va (sermon 355, 2) ; la scène (Possidius IV) ; larmes mal comprises ; lettre 21 à Valère (1 et 4) ; ordinations forcées (Pinien 411, lettre 126) ; monastère du jardin (Possidius V, sermon 355, 2) ; Valère grec, prédication du prêtre contre l'usage africain ; la Laetitia abolie (lettre 29, 395) et lettre 22 à Aurèle (392).
3. Évêque coadjuteur puis évêque d'Hippone (395-396) : crainte de Valère (Possidius VIII) ; Megalius primat de Numidie ; canon 8 de Nicée ignoré (lettre 213, 4) ; date 395 ou 396 ; mort de Valère ; « nomen operis, non honoris » (Cité de Dieu XIX, 19 ; 1 Timothée 3:1) ; sermon 340, 1 (LG 32) ; Église d'Hippone divisée (lien d).
4. La vie commune avec son clergé : monasterium clericorum (sermon 355, 2) ; Actes 4:32 ; pauvreté, affaire Januarius, sermons 355-356 (fin 425-début 426) ; Possidius XXII (table, cuillères, vers contre la médisance), XXVI (pas de femmes) ; pépinière d'évêques (Possidius XI) ; différence avec la Règle (lien r).
5. La charge quotidienne (I) : prédication (sermons, Valère, lien e) et tribunal épiscopal (audientia episcopalis ; Possidius XIX ; 1 Corinthiens 6:1-5 ; De opere monachorum 29, 37 ; lettre 213, 5).
6. La charge quotidienne (II) : les pauvres (Possidius XXIII, XXIV vases fondus ; sermon 356, 10 et 13 ; hospice), captifs (lettre 10* Divjak), refus d'héritages ; la correspondance (près de 300 lettres ; Jérôme, Paulin, Proba, Boniface ; lettres Divjak 1981 ; intercession Possidius XX).
7. Les conciles africains autour d'Aurèle : Aurèle évêque de Carthage 391/392-vers 430 ; lettre 22 ; Hippone 393, La Foi et le Symbole (Révisions I, 17) ; liste des livres saints (Hippone 393, Carthage 397) ; conciles contre donatistes (lien d) et Pélage (lien u) ; Apiarius 418-419, appels outre-mer, communion avec Rome ; rôle d'Augustin rédacteur.
8. Les Révisions (426-427) : prologue (iudiciaria severitate) ; méthode ; 93 ouvrages, 232 livres ; lettres et sermons non revus (épilogue) ; exemples : fortuna, Platon (I, 1), miracles (I, 13, 7), grâce (I, 23, 2) ; humilité et progrès ; Proverbes 10:19 ; désignation d'Héraclius (lettre 213, 26 septembre 426).
9. Le siège d'Hippone et la mort (430) : Vandales 429 (lien 29 l), Genséric, ariens ; Boniface ; Possidius XXVIII (trois Églises debout, larmes, Plotin) ; lettre 228 à Honorat (Jean 10:12) ; prière (XXIX) ; maladie 3e mois ; psaumes pénitentiels, dix jours (XXXI) ; pas de testament, bibliothèque ; 28 août 430 ; 76 ans ; fête.
10. La Vie d'Augustin par Possidius : Possidius (moine d'Hippone, évêque de Calama vers 397, émeute 408, Carthage 411, exil 437) ; date (entre 431 et 439) ; dessein (préface ; ne pas refaire les Confessions) ; plan en quatre parties ; Indiculum (XVIII) ; valeur et limites ; phrase finale (XXXI).
11. Le Bien du mariage (401) : Jovinien et Jérôme (Révisions II, 22) ; société naturelle (1 ; 3) ; amitié des vieux époux ; dette mutuelle (6 ; 1 Corinthiens 7:3-4) ; trois biens proles, fides, sacramentum (24, 32 ; La Genèse au sens littéral IX, 7, 12) ; sacramentum : Éphésiens 5:32, lien indissoluble (Matthieu 19:6) ; opinion propre sur l'acte non procréatif (faute vénielle) vs GS 49.
12. La Sainte Virginité et la postérité des trois biens : Révisions II, 23 ; Église vierge et mère (2) ; Marie (3 ; Luc 11:27-28) ; virginité consacrée (11), conseil (Matthieu 19:12 ; 1 Corinthiens 7:38) ; humilité (31 ; Siracide 3:18) ; réception : Pierre Lombard, Thomas, Florence 1439 (DS 1327), Casti connubii 1930, GS 48 note, CEC 1601, 1620, 1643-1654.
