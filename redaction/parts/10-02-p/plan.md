# 10-02-p Platon et le platonisme (lettre p) — plan

Question centrale : qu'a vu Platon (un monde intelligible, stable, qui fonde le monde sensible ; une âme faite pour lui) et que la foi a-t-elle reçu et corrigé ?
Obstacles : Idées = idées dans la tête ; « platonique » = sans corps ; Platon = chrétien avant l'heure ; démiurge = Créateur ; réminiscence = foi chrétienne ; immortalité de l'âme = résurrection.

1. Platon, l'Académie et les dialogues : vie (428/427-348/347), famille, Socrate, 399, Lettre VII ; Syracuse ; Académie (~387) ; inscription « géomètre » tardive ; pourquoi des dialogues (Phèdre 275d, Lettre VII 341c) ; classement : Thrasylle (9 tétralogies), chronologie stylométrique (trois groupes), authenticité, pagination d'Estienne (1578).
2. Les Idées : Héraclite/Parménide via Aristote Métaph. A 6 ; Euthyphron 6d-e ; Phédon 74 (l'égal), 78d ; Banquet 211a-b ; traits : intelligibles, éternelles, immuables, en soi, unes ; Timée 27d-28a ; contresens « idée = pensée ».
3. La participation : Phédon 100c-d ; modèle et copie ; Parménide 130-133 (cheveu/boue, voile, troisième homme) ; Aristote Métaph. A 9 991a20-22 ; reprise : participation de l'être (Thomas I q.6 a.4 ; I q.44 a.1) ; Idées dans l'intelligence divine (Augustin, q.46 via Thomas I q.84 a.5).
4. L'Idée du Bien : République VI 505a, soleil 507-509, 509b-c « au-delà de l'essence », ligne 509d-511e ; lecture chrétienne : Bien et Dieu ; Exode 3:14 et l'Être même ; Thomas I q.6 a.4.
5. La caverne : 514a-517a, 515a « semblables à nous », 517a mort de Socrate, 517b-c, 518c-d conversion (periagôgê), 520c « il faut redescendre » ; lecture chrétienne : conversion, Jean 1:9, la lumière qui descend (Augustin Conf. VII, 20, 26 ; FR 40).
6. La réminiscence et l'âme immortelle : Ménon 80d-86c (paradoxe, esclave, 81d, 86b-c) ; Phédon 72e-77a ; Phédon 64a, 67d-e, 62b, 82e ; sôma-sêma (Gorgias 493a, Cratyle 400c) ; quatre arguments ; 114d ; jugement : Augustin Trin. XII, 15, 24 ; Thomas I q.84 a.3 ; Vienne, Latran V, CEC 366 ; Sagesse 9:15 ; 1 Corinthiens 6:19.
7. L'amour qui élève : Banquet, Diotime, Poros et Penia 203b-e, erôs intermédiaire, enfanter dans la beauté 206b-e, échelle 210a-212a ; Phèdre (folie divine) ; reprise : Grégoire de Nysse, Denys (lien n), Deus caritas est 4, 7, 9-10 ; 1 Jean 4:8,10.
8. La justice dans l'âme et dans la cité : Gygès, Thrasymaque, cité en grandes lettres, trois classes, âme tripartite (436b), quatre vertus (427e, 433a), philosophe-roi 473c-d, 592b ; communisme des gardiens, beau mensonge ; jugement : vertus cardinales (Sagesse 8:7), Aristote, Thomas I-II q.21 a.4 ad 3.
9. Le démiurge du Timée : récit vraisemblable 29d ; 28a, 28c, 29a, 29e-30a ; khôra 48e-52d ; nécessité 48a ; âme du monde ; temps 37d ; débat sur le commencement ; Calcidius, Chartres (lien m) ; Justin Apol. I 59-60 ; Sagesse 11:17 ; création contre fabrication (prépare L12).
10. La première théologie philosophique : République II 379a theologia ; critique d'Homère et d'Hésiode ; typoi : Dieu bon, cause du bien seul 379b-c ; immuable et vrai 380d-383a ; Lois X : trois impiétés 885b ; matérialisme 889 ; l'âme antérieure, mouvement qui se meut lui-même 893b-896b ; meilleure âme 897b-c ; providence et incorruptibilité ; sanctions 907d-910d ; jugement : Sagesse 13:1-5, Romains 1:20, Dei Filius, DH.
11. Le moyen platonisme : nom moderne ; période (~ Ier s. av. – IIIe s.) ; Eudore, Plutarque (De E), Alcinoos (Didaskalikos 9-10), Apulée, Numénius, Atticus ; thèmes : transcendance, Idées pensées de Dieu, assimilation à Dieu (Théétète 176a-b), intermédiaires ; rencontre : Justin (lien j), Clément (lien m), Celse et Origène (Contre Celse VII, 42) ; Matthieu 11:27.
12. Reçu et corrigé : reçu (Dieu spirituel, immuable, bon ; monde intelligible ; âme ; ascension) Augustin CD VIII, 4-5, 11 ; Thomas I q.84 a.5 ; corrigé : création contre fabrication (Théophile, Ad Autolycum II, 4 ; 2 Maccabées 7:28 ; Latran IV) ; résurrection contre mépris du corps (Porphyre, CD X, 29 ; Actes 17:32 ; 1 Corinthiens 15:44) ; Incarnation (Conf. VII, 9 ; FR 39-41) ; Révisions I, 1, 4.
Bilan : 6 exercices croisés.
