# 62-02-c : Coopération au salut et médiation maternelle (lettre c, fichier 62)

Question centrale : comment Marie a-t-elle part à l'œuvre du salut, si le Christ est l'unique Rédempteur et l'unique Médiateur ?
Obstacles : croire que « coopérer » veut dire « ajouter » au Christ ; confondre médiation du Christ et médiation participée ; prendre les titres pour des définitions ; croire que la dispensation de toutes les grâces ou la Corédemption sont des dogmes ; croire à l'inverse que l'Église a « rabaissé » Marie en 2025.

Leçons (une par fichier, 01.html … 11.html, puis 99-bilan.html) :
1. Coopérer au salut : ce que le mot veut dire. Dieu associe ses créatures (1 Co 3:9) ; Christ seul Sauveur (Ac 4:12) ; LG 62 (médiation qui suscite une coopération) ; cause première / causes secondes ; double perspective (MPF 4 : rédemption objective, influence actuelle) ; carte des degrés d'autorité du cours.
2. Le consentement libre à l'Incarnation. LG 56 (non instrument passif, libre foi et obéissance ; Irénée « cause du salut ») ; Luc 1:38 ; Thomas III q30 a1 (au nom de toute la nature humaine) ; Léon XIII Octobri mense 4 ; MC 110 ; Bernard « Responde verbum » ; MPF 26 ; lien 60-a.
3. La compassion au pied de la croix. Jean 19:25 ; Luc 2:34-35 ; LG 58 (debout, consentement de son amour) ; Ambroise (Jésus n'avait pas besoin d'aide) ; MPF 12 (Bernard, Arnaud de Bonneval) ; Pie XII MC 110 ; Pie X Ad diem illum ; compassion ≠ co-sacrifice sacerdotal ; Col 1:24.
4. L'associée du Rédempteur (LG 61). Texte ; « titre absolument unique » ; obéissance, foi, espérance, charité ; ce que « associée » dit et ne dit pas ; débat rédemption objective (immédiate / médiate) : opinions ; Pie X de congruo / de condigno ; lien nouvelle Ève.
5. La maternité dans l'ordre de la grâce (LG 61-62). « devenue notre Mère » ; « se continue sans interruption » de l'Annonciation à la consommation des élus ; intercession multiple ; Jean 19:26-27 (lien 62-l) ; CEC 968-970 ; maternité spirituelle ≠ métaphore.
6. La médiation maternelle (LG 60). 1 Tm 2:5-6 ; sens de « médiateur » ; trois traits : participée, subordonnée, qui manifeste la vertu ; source gratuite, pas nécessité ; union immédiate favorisée ; Thomas III q26 a1 (dispositive vel ministerialiter) ; LG 62 analogie sacerdoce et bonté.
7. Avocate, Auxiliatrice, Secourable, Médiatrice (LG 62). Latin des quatre titres ; histoire de chacun (Irénée advocata, Salve Regina ; Auxilium christianorum, Pie VII 1815 ; Adiutrix, Léon XIII 1895, Perpétuel Secours ; Médiatrice, Orient VIe s., Occident XIIe s., Mercier 1921) ; clause « nulle dérogation, nulle addition » ; pourquoi une liste.
8. La troisième partie de Redemptoris Mater (1987). Plan (38-41, 42-47, 48-50) ; « médiation dans le Christ » ; caractère spécifiquement maternel ; coopération = médiation subordonnée (39) ; dimension universelle et intercession depuis Cana (40) ; Assomption (41) ; l'Église qui apprend sa maternité (43-44) ; dimension mariale de la vie du disciple, « l'accueillit chez lui » (45-46) ; Année mariale (48-50).
9. Marie dispensatrice de toutes les grâces. Bernard (aqueduc, totum per Mariam) ; Montfort (Traité) ; Alphonse ; Léon XIII Octobri mense, Adiutricem ; Pie X Ad diem illum ; Mercier, Benoît XV 1921 ; deux sens (part à l'acquisition / intercession pour chaque grâce) ; statut : non défini, Vatican II sans décision, Ratzinger 1996, MPF 45, 53, 67-68.
10. Le titre de Corédemptrice. Histoire (Rédemptrice Xe s., Corédemptrice XVe s. Salzbourg ; XXe s. ; papes ; JPII sept fois) ; sens chez ses défenseurs (co = avec, subordonné ; Benoît XV Inter sodalicia) ; mouvement pour un cinquième dogme ; difficultés : ambiguïté, Écriture et Pères, œcuménisme, explications constantes ; Vatican II l'évite ; Ratzinger 1996 et 2002 ; François.
11. La note Mater populi fidelis (2025). Date, signataires, approbation 7 octobre 2025 ; but et attitude envers la piété ; plan ; Co-rédemptrice toujours inopportune (22) ; Médiatrice : prudence, portée et limites (24) ; Médiatrice de toutes les grâces (67-68) ; Mère de la grâce (69) ; Mère des croyants, paratonnerre (37) ; Mère du Peuple fidèle ; autorité de la note (magistère ordinaire, pas une définition).
