# 65-11-u Les couleurs liturgiques (lettre u) — plan

Question centrale : pourquoi la chasuble change-t-elle de couleur, qui l'a décidé, et que dit chaque couleur ?
Obstacles : croire à une symbolique « naturelle » et éternelle ; ignorer l'histoire tardive (XIIe-XVIe s.) ; confondre violet et noir, rose et « rose bonbon », or et couleur ; croire que le rose est obligatoire, que le bleu est une couleur romaine ; croire l'Orient tenu par les mêmes règles.

Sources vérifiées : PGMR 345-346 (vatican.va, trad. fr. 2002) ; Redemptionis Sacramentum 127 (vatican.va) ; SC 81, 124 ; Cath. Encycl. « Liturgical colours » (Benoît XIV : blanc seul jusqu'au IVe s. ; Ruthènes depuis 1891 ; décrets 3145, 3646 or/argent) ; praytell (Innocent III I,65, attributions ; rose officiel au Cérémonial de 1600 ; curie : rouge aux funérailles papales) ; New Cath. Encycl. (canon des croisés de Jérusalem XIIe s.) ; Wikipedia (indult bleu 12 févr. 1864 ; usage byzantin clair/sombre, usage slave et russe ; copte blanc ; Rameaux rouge 1956 ; Vendredi saint noir jusqu'en 1969) ; Wikipedia Golden Rose (Léon IX 1051, sermon d'Innocent III).

Leçons :
1. Le langage des couleurs — PGMR 345 ; couleur du jour (messe et office) ; ce qui la porte ; carte des six couleurs + or ; messes rituelles, votives, pour diverses circonstances (346) ; adaptations des conférences.
2. Avant la règle — vêtements d'Aaron (Exode 28), blanc dans l'Écriture ; vêtement civil ; Benoît XIV (blanc seul jusqu'au IVe s.) ; époque carolingienne : prescriptions locales ; canon des croisés de Jérusalem (XIIe s.).
3. D'Innocent III au Missel de saint Pie V — Lothaire de Segni, De sacro altaris mysterio I,65 ; quatre couleurs principales, autres rattachées ; violet pour Laetare ; Durand de Mende ; diversités locales ; Ordo romanus XIVe s. : cinq ; Missel 1570 : cinq couleurs, première règle universelle ; rose (Cérémonial 1600) ; décrets ultérieurs ; réformes 1955-1970 ; PGMR 346.
4. Le blanc — lumière, résurrection, gloire, pureté ; Transfiguration, anges, Ap 7 ; liste PGMR 346a ; Jean l'Évangéliste, Chaire de Pierre, Conversion de Paul, Nativité de Jean-Baptiste ; sacrements (baptême, mariage), Jeudi saint, Vigile.
5. Le rouge — feu de l'Esprit (Ac 2:3), sang des martyrs ; double lecture ; liste PGMR 346b ; Rameaux, Vendredi saint (changements) ; apôtres, évangélistes ; Saints Innocents, Étienne ; Croix glorieuse ; messes du Saint-Esprit, confirmation ; funérailles papales.
6. Le vert — temps ordinaire ; Innocent III : jours ordinaires ; espérance, croissance ; deux périodes ; dimanches verts ; quand le vert cède.
7. Le violet — Avent et Carême (nuances : attente / pénitence) ; défunts ; sacrement de pénitence (étole) ; histoire : substitut du noir chez Innocent III ; teinte non définie ; bleu non admis.
8. Le rose — Gaudete (Ph 4:4-5) et Laetare (Is 66:10) ; facultatif « là où c'est l'usage » ; rose d'or (Léon IX 1051 ; sermon d'Innocent III) ; violet éclairci ; sens : joie au milieu de l'attente.
9. Le noir — messes des défunts là où c'est la coutume ; histoire (Avent/Carême chez Innocent III ; Vendredi saint jusqu'en 1969) ; SC 81 ; violet, noir, blanc aux funérailles ; deuil chrétien et espérance (1 Th 4:13).
10. L'or et les vêtements précieux — PGMR 346 (jours les plus solennels) ; RS 127 (or, argent sauf violet et noir ; abus) ; décrets de la Congrégation des rites ; États-Unis ; SC 124 noble beauté ; Écriture (Exode 28, Ap 21).
11. Les Églises orientales — pas de canon fixé ; livres byzantins : clair / sombre ; usage grec ; usage slave et russe ; copte blanc ; Ruthènes 1891 ; Églises orientales catholiques et leur tradition propre ; ce que l'Orient et l'Occident partagent.
