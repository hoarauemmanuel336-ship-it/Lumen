# 55-04-c La catholicité de l'Église (lettre c) : plan

Question centrale : que veut dire « catholique » quand le Credo le dit de l'Église, si ce n'est pas d'abord « grande » ou « répandue partout » ?
Obstacles du novice : croire que catholique = universel au sens géographique ; croire que le mot est un nom de confession parmi d'autres ; croire que l'Église est devenue catholique en s'étendant ; confondre catholicité et uniformité culturelle ; croire qu'une Église locale n'est qu'une part de l'Église.

Fichiers : 00-ouverture.html, 01.html ... 11.html, 99-bilan.html.

1. Le mot « catholique » : grec katholikos / kath'holou ; Aristote katholou ; katholou une fois dans le NT (Actes 4:18, « formellement ») ; Actes 9:31 ; deux directions (extension / intégralité, CEC 830) ; latin catholicus, slavon sobornaïa, Luther « christlich ».
2. Saint Ignace d'Antioche, Smyrniotes 8 : contexte (docètes, Eucharistie, évêque) ; la phrase ; le parallèle évêque/communauté :: Christ/Église catholique ; débat sur le sens ; Martyre de Polycarpe (4 emplois, dont « évêque de l'Église catholique qui est à Smyrne »).
3. Saint Cyrille de Jérusalem, Catéchèse XVIII, 23 : étendue, doctrine complète, tous les hommes, remède à tout péché et toute vertu ; comparaison avec saint Thomas (lieu, condition, temps).
4. Le nom propre : besoin d'un nom (Actes 11:26 ; hairesis Actes 24:5,14 ; 1 Corinthiens 1:12-13) ; Clément d'Alexandrie (Stromates VII, 17) ; Cyrille XVIII, 26 ; Pacien (lettre 1 à Sympronien) ; Augustin (Contre la lettre du fondement 4, 5) ; aujourd'hui (Anglicans, Orthodoxes, Luthériens ; Bellarmin, 1re note).
5. Saint Vincent de Lérins, Commonitorium (434) : la règle quod ubique, quod semper, quod ab omnibus ; universitas, antiquitas, consensio ; cas d'application (donatistes, ariens, conciles et Pères) ; progrès sans altération (ch. 23 ; Dei Filius 4) ; limites.
6. La catholicité de plénitude : CEC 830 ; plèrôma (Éphésiens 1:22-23 ; Colossiens 2:9-10) ; AG 6 ; trois éléments ; lien avec « subsiste dans » ; UR 4.
7. La catholicité de mission : CEC 831 ; promesses (Genèse 12:3 ; Isaïe 49:6 ; Malachie 1:11) ; Matthieu 28:18-20 (quatre « tout ») ; LG 13 ; Apocalypse 7:9.
8. Catholique dès la Pentecôte : Actes 1:15 ; Actes 2 ; Babel ; AG 4 ; CEC 830 ; Communionis notio 9 (rappel) ; graine de moutarde.
9. La catholicité de chaque Église particulière en communion avec Rome : CEC 832-834 ; LG 23, 26 ; Ignace aux Romains et Irénée ; EN 62 ; Communionis notio 17 (Orthodoxes).
10. La catholicité et les cultures : Actes 15 ; Actes 17 ; LG 13 ; AG 22 ; GS 58 ; SC 37 ; EN 20 ; Grégoire à Mellitus ; Cyrille et Méthode ; querelle des rites ; Apocalypse 21:24-26.
11. L'erreur du nombre et de l'étendue : ses formes ; réponse (Pentecôte, Luc 12:32, crise arienne, Jérôme) ; ce que l'étendue garde de vrai (Augustin contre Vincentius, lettre 93 ; securus iudicat orbis terrarum ; Dei Filius) ; tenir les deux.
