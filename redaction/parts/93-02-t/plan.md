# Plan du cours 93-02-t « Le travail » (lettre t)

Question centrale : pourquoi le travail humain a-t-il une dignité, et quels droits en découlent pour celui qui travaille ?
Obstacles du novice : croire que le travail est une punition (Genèse 3) ; mesurer la dignité au métier ; croire que le salaire convenu est forcément juste ; voir le syndicat comme lutte des classes ; voir le dimanche comme simple affaire privée ; opposer promotion de la femme et maternité.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. Le travail dans l'Écriture : la mission et la peine — Gn 2:15 (cultiver et garder, hébreu ‘abad / shamar), Gn 1:28, Gn 2:5 ; Gn 3:17-19 (peine, ‘itsabon) : le travail est antérieur à la chute ; la peine vient du péché ; Sagesse (Ps 104:23, Ps 128:2, Si 38:31-34, Qo 2:22-24), Exode 1:13-14 (travail servile). Mots : Travail ; Cultiver et garder ; Dominer la terre ; Peine du travail.
2. Jésus, homme du travail à Nazareth — Mc 6:3, Mt 13:55 (grec tektôn) ; vie cachée (Lc 2:51-52) ; LE 26 « évangile du travail », LS 98 ; paraboles ; Paul fabricant de tentes (Ac 18:3, 2 Th 3:8-12) ; rupture avec le mépris antique du travail manuel. Mots : Vie cachée ; Charpentier ; Évangile du travail ; Travail manuel.
3. La dignité du travail vient de la personne — LE 6 (« le premier fondement de la valeur du travail est l'homme lui-même », « pour l'homme »), CEC 2427-2428, LE 9 « devient plus homme » ; sens objectif / subjectif (rappel, lien 92 #ouverture-t) ; égale dignité de tous les métiers ; travail-marchandise. Mots : Dignité du travail ; Sujet du travail ; Sens objectif ; Sens subjectif ; Travail-marchandise.
4. Participation à l'œuvre du Créateur et à la Rédemption (LE 25-27) — GS 34 ; Jn 5:17 ; 1 Co 3:9 ; peine unie à la croix (LE 27, CEC 2427) ; résurrection, « cieux nouveaux » (2 P 3:13), GS 39 non cité ; erreurs : activisme / mépris du monde. Mots : Participation à l'œuvre du Créateur ; Rédemption ; Offrande du travail ; Spiritualité du travail.
5. Le droit au travail et le drame du chômage — Mt 20:6-7 ; CEC 2433, 2436 ; LE 18 (« toujours un mal… calamité sociale ») ; Compendium 287-289 ; plein emploi ; employeur indirect (rappel lien 92 #ouverture-t) ; allocations ; CiV 25 ; FT 162 / LS 128. Mots : Droit au travail ; Chômage ; Plein emploi ; Allocation de chômage.
6. Le juste salaire dans l'économie actuelle — Lv 19:13, Dt 24:14-15, Jr 22:13, Jc 5:4, Lc 10:7 ; RN (rappel lien 92 #ouverture-r) ; QA 3 critères ; GS 67 ; CEC 2434 (accord des parties) ; LE 19 (« vérification concrète ») ; salaire familial (rappel #ouverture-l) ; CiV 63 travail digne ; cas actuels (travailleurs pauvres, retard de paiement, écarts). Mots : Juste salaire ; Accord des parties ; Travailleur pauvre ; Travail digne.
7. Les syndicats et le droit de grève — LE 20, GS 68, CEC 2435, Compendium 304-308 ; syndicat (grec syndikos) ; RN (rappel) ; Solidarność ; pas de lutte des classes, pas de politique partisane ; grève : légitime sous conditions (recours ultime, bénéfice proportionné, pacifique, objectifs liés au travail, services essentiels) ; abus. Mots : Syndicat ; Grève ; Services essentiels ; Recours ultime.
8. Le repos et le droit au dimanche — Gn 2:2-3 ; Ex 20:8-11 ; Dt 5:12-15 ; Mc 2:27 ; Hé 4:9-10 ; CEC 2184-2188 ; Dies Domini (31 mai 1998) 64-67 ; Constantin 321 ; Abitène ; GS 67 repos ; Am 8:5. Mots : Sabbat ; Dimanche ; Repos dominical ; Jour férié.
9. Le travail des femmes et la protection de la maternité — Gn 1:27 ; Pr 31 ; FC 23 ; Lettre aux femmes 1995 n. 4 ; LE 19 (« vraie promotion de la femme ») ; Compendium 295 (génie féminin, discriminations) ; GS 67 mères de famille ; salaire familial (rappel #ouverture-l). Mots : Génie féminin ; Égalité de rémunération ; Protection de la maternité ; Discrimination.
10. Le travail des enfants, la sécurité et la santé au travail — Lm 5:13 ; Ne 5:5 ; Mc 10:14 ; Mt 18:6 ; RN (enfant), Compendium 296, CiV 63 ; OIT 2025 : 138 millions, 54 millions travaux dangereux ; sécurité et santé : LE 19, Compendium 301, 1 Co 6:19-20 ; OIT 2023 : près de 3 millions de morts/an. Mots : Travail des enfants ; Travaux dangereux ; Sécurité au travail ; Accident du travail ; Maladie professionnelle.
11. Les nouvelles formes de travail et la précarité — Compendium 311-314 (travail atypique, précarité) ; CiV 25 (mobilité, incertitude) ; plateformes ; intelligence artificielle : Antiqua et nova 67, 70 ; Léon XIV et la nouvelle révolution industrielle (lien 92 #ouverture-l) ; flexibilité vs précarité ; Compendium 310 « mondialisation des tutelles ». Mots : Précarité ; Travail atypique ; Travail de plateforme ; Flexibilité.
12. La spiritualité du travail : saint Joseph artisan — Mt 1:19,24 ; Mt 2:13-14 ; Mt 13:55 ; Redemptoris custos 22-24 (15 août 1989) ; Patris corde 6 (8 décembre 2020) ; fête du 1er mai 1955 (rappel lien 92 #ouverture-p) ; Col 3:23-24 ; 1 Co 10:31 ; conscience professionnelle, sanctification de la vie quotidienne, offrande, prière. Mots : Saint Joseph artisan ; Conscience professionnelle ; Sanctification du travail.
