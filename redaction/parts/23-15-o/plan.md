# Plan du cours 23-15-o : Les apologistes latins avant Nicée (lettre o)

Question centrale : comment, entre la fin du IIe siècle et l'époque de Constantin, des lettrés de langue latine (un avocat de Rome, un prêtre romain, deux rhéteurs d'Afrique) ont-ils défendu et exposé la foi devant un monde païen cultivé, et qu'ont-ils laissé à l'Église (doctrine, histoire, langue) ?
Obstacles du novice : croire que tous ces auteurs sont des saints ou des Pères (aucun n'est vénéré ; Novatien est schismatique) ; prendre le silence de l'Octavius sur le Christ pour une ignorance ; confondre Novatien (Rome) et Novatus (Carthage) ; croire que Novatien était hérétique sur la Trinité ; lire les formules d'avant Nicée avec la précision d'après ; prendre la Mort des persécuteurs pour une chronique neutre ; confondre « édit de Milan » et loi impériale ; croire que la liberté religieuse est une idée moderne.
Partage : Tertullien (cours t), Cyprien et le schisme vu de Carthage (cours y, leçon 5 : rappel + lien), apologistes grecs (cours g : apologie, accusations), Hippolyte (cours b : modalisme), persécutions et Constantin (27-...#ouverture-p / #ouverture-c), Eusèbe (24-...#ouverture-e).

1. Plaider en latin : naissance du christianisme latin (Afrique, Rome grecque jusqu'au milieu du IIIe s.), Scillitains 180, Vetus Latina ; l'Apologétique de Tertullien (rappel) ; nouvelle accusation : les chrétiens causes des malheurs (Tertullien Apol. 40, Arnobe I, 1) ; les quatre auteurs et leurs dates ; leur public ; la borne de Nicée.
2. L'Octavius (1) : auteur (Jérôme, Hommes illustres 58 ; Lactance, Inst. V, 1), date et rapport à l'Apologétique, manuscrit unique (8e livre d'Arnobe) ; cadre d'Ostie (ch. 2-4, Sérapis) ; réquisitoire de Caecilius (scepticisme, tradition des ancêtres, calomnies ch. 8-9, Fronton).
3. L'Octavius (2) : réponse d'Octavius (raison commune ch. 16 ; providence et Dieu unique ch. 17-18 ; philosophes ch. 19-20 ; dieux hommes divinisés ; démons ; calomnies retournées ch. 28-31 ; pas de temples ch. 32 ; résurrection ch. 34 ; martyrs ch. 37 ; « nous ne disons pas de grandes choses, nous les vivons » ch. 38) ; conversion ch. 40 ; silence sur le Christ et l'Écriture, pourquoi.
4. Novatien et le traité Sur la Trinité : prêtre romain (lettre de Corneille dans Eusèbe VI, 43 : baptême clinique) ; premier théologien romain de langue latine ; date (avant 250) ; plan selon la règle de vérité ; Père ; Fils vrai Dieu et vrai homme contre adoptianistes et modalistes (« si le Christ n'est qu'un homme… ») ; Jean 10:30 « unum » ; théophanies ; Esprit (ch. 29) ; ch. 31 et subordinatianisme ; transmission sous les noms de Tertullien et Cyprien (Jérôme 70).
5. Novatien antipape et l'Église des purs : Lettre 30 ; élection de Corneille (mars 251) ; ordination de Novatien ; principe rigoriste ; récit polémique de Corneille ; concile de 60 évêques ; rappel Cyprien (lien) ; novatiens « cathares », canon 8 de Nicée, Acésius ; autres œuvres (Les Viandes des Juifs ; Spectacles, Pudicité) ; mort (Socrate, inscription de 1932) ; jugement de l'Église.
6. Arnobe de Sicca et le Contre les nations : Sicca, rhéteur ; Chronique de Jérôme (songes, évêque) et critique ; date (I, 13 ; II, 71 ; persécution IV) ; sept livres ; Christ Dieu et seul sauveur (I, 42 ; II, 65) ; argument du pari (II, 4) ; procès des mythes et des cultes (III-VII) ; limites : Écriture ignorée, âme « de qualité moyenne » (II, 14), âmes non créées par Dieu ; réception.
7. Lactance, le « Cicéron chrétien » : vie (Afrique, Arnobe, Nicomédie, conversion, 303, pauvreté, Trèves) ; œuvres selon Jérôme 80 ; style, Jérôme Lettre 58, 10, surnom humaniste, Subiaco 1465 ; L'Ouvrage de Dieu ; La Colère de Dieu (ch. 5 ; dilemme d'Épicure ch. 13).
8. Les Institutions divines : plan des sept livres ; dessein (V, 1-4 : instruire, critique de Cyprien) ; sagesse et religion (IV, 3-4), religio/religare (IV, 28) ; Christ (IV) et Église catholique (IV, 30) ; justice, égalité (V, 15) ; liberté religieuse (V, 19) ; vrai culte (VI) ; vie bienheureuse et millénarisme (VII) ; Abrégé ; limites (Esprit, antipodes, passages dualistes) ; jugement.
9. La Mort des persécuteurs : manuscrit unique (Baluze 1679), attribution, date vers 314-315, Donat ; thèse et genre ; persécuteurs anciens (2-6) ; Dioclétien (7), 23 février 303 (12-13), incendie (14), abdication 305 ; mort de Galère (33) et édit de 311 (34) ; signe de Constantin (44) ; lettre de Licinius 313 (48) ; valeur et limites ; comparaison avec Eusèbe.
10. Lactance auprès de Constantin : Trèves, Crispus (Jérôme 80, Chronique) ; adresses à Constantin des Institutions ; un apologiste devant un empereur chrétien ; liberté religieuse et politique constantinienne ; mort de Crispus 326 ; fin de l'âge des apologies ; rappel Eusèbe (lien).
11. L'apport à la langue théologique latine : héritage de Tertullien ; Minucius (latin classique) ; Novatien (précision trinitaire à Rome) ; Arnobe (lexique des cultes) ; Lactance (élégance, religio, Église catholique) ; Jérôme 58, 10 ; Augustin, Doctrine chrétienne II, 40, 61 (or d'Égypte) ; limites d'avant Nicée.
Bilan : 6 exercices croisés.
État : plan fait.
