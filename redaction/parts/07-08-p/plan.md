# 07-08-p : Les premiers principes (fichier 07, lettre p)

Sous-titre : Les vérités évidentes sur lesquelles repose toute pensée, et ce qu'elles donnent à la foi.
Question centrale : sur quoi repose la certitude de tout raisonnement, si tout ne peut pas se démontrer ?
Obstacles du novice : croire qu'un principe non démontré est un postulat arbitraire ; confondre « tout a une cause » et le principe de causalité ; confondre finalité et intention consciente ; croire que le mystère chrétien est une contradiction ; croire que Hume a « réfuté » la causalité.

Leçons (11) :
1. Des vérités qu'on ne démontre pas : nécessité de points de départ (régression à l'infini, Aristote Méta Γ 4 1006a6-11), connu par soi (per se nota) : prédicat dans la notion du sujet ; connu par soi en soi / pour nous (Boèce, De hebdomadibus ; ST I q2 a1 ; I-II q94 a2) ; indémontrables et certains ; démonstration indirecte possible (réfutation, réduction). Tableau des principes de la leçon. Foi : Dieu n'est pas connu par soi pour nous (lien 09-01-l). FR 4.
2. L'intelligence des principes : habitus (lien 06-10-d), naturel en partie, formé à partir des sens (Sec. Anal. II 19) ; l'être premier connu, d'où les principes ; « semences des sciences » (De veritate q11 a1) ; contre les idées innées et contre l'empirisme ; certitude et infaillibilité de cet habitus. Foi : la lumière naturelle reflet de la lumière divine (ST I q84 a5 ; Psaume 4:7 « fais lever sur nous la lumière de ta face » à vérifier).
3. Le principe de non-contradiction : formulation Γ 3 1005b19-20 ; chaque clause (même chose, même temps, même rapport) ; formes ontologique, logique, psychologique ; le plus ferme (1005b11-17) ; Thomas : fondé sur être et non-être (I-II q94 a2) ; usage : résoudre les contradictions apparentes. Foi : le mystère au-dessus de la raison, non contre (Dei Filius ch. 4) ; Trinité, Christ : pas sous le même rapport.
4. Défendre le principe : réfutation (élenctique) Γ 4 ; « il suffit qu'il dise quelque chose » ; Mégare et le puits (1008b) ; l'agir trahit ; Avicenne (à signaler) ; Héraclite ; Hegel et les logiques paraconsistantes : présentation honnête et jugement. Foi : sans PNC, ni dogme ni hérésie (lien 06-08-j).
5. Le principe d'identité et le principe du tiers exclu : identité (ce qui est, est ; chaque être est ce qu'il est), pas une tautologie ; débat sur le premier principe (Thomas : PNC ; Garrigou-Lagrange : identité forme positive) ; tiers exclu Γ 7 1011b23 ; contradictoires et contraires ; intuitionnisme de Brouwer ; futurs contingents (De int. 9) mention. Foi : la définition dogmatique et l'anathème.
6. Le principe de raison suffisante : Leibniz (Monadologie 31-32, texte français original) ; forme thomiste : raison d'être en soi ou en un autre ; raison intrinsèque et extrinsèque ; liens avec PNC ; limites : la liberté (lien 09-04-v) ; Dieu a en lui sa raison d'être ; la volonté de Dieu raisonnable sans cause (ST I q19 a5).
7. Le principe de causalité : formulations (commencer d'être ; contingent ; par participation, ST I q44 a1 ; ce qui est mû est mû par un autre) ; pourquoi connu par soi ; « tout a une cause » faux ; exemples. Foi : création, voies (lien 09-02-c).
8. Hume et la causalité : Enquête IV, VII ; Traité I, 3, 3 ; habitude ; lettre à John Stewart 1754 ; réponse réaliste : imaginer / concevoir, perception de l'action, Hume se sert de la causalité, principe non inductif ; Kant d'une phrase (lien 10-13-k). Foi : preuves de Dieu, Vatican I (lien 09-09-g).
9. Le principe de finalité : omne agens agit propter finem (ST I-II q1 a2 ; SCG III 2) ; argument par la détermination ; agents sans connaissance (flèche) ; finalité n'est pas intention consciente ; mécanisme moderne (Bacon, Descartes, Spinoza) ; lien 07-07-q pour le hasard. Foi : providence, cinquième voie, fin de l'homme.
10. L'agir suit l'être : agere sequitur esse ; ST I q75 a2 ; connaître la nature par les opérations ; application à l'âme (lien 08-08-s), aux animaux ; foi : deux natures, deux opérations du Christ (Tome à Flavien, Constantinople III) ; la grâce avant les vertus infuses ; agir est le fait du suppôt (lien 07-10-n).
11. Le premier principe de l'ordre pratique : ST I-II q94 a2 ; bien = ce que tous désirent ; parallèle avec être / PNC ; syndérèse (ST I q79 a12) ; inclinations naturelles ; Hume et l'« is/ought » ; foi : loi naturelle, Romains 2:14-15 (lien #sujet:loi.naturelle).
