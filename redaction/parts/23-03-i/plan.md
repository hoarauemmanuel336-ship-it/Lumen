# 23-03-i · Ignace d’Antioche (fichier 23, lettre i)

Question centrale : qui était Ignace, que disent ses sept lettres écrites en route vers le martyre, et pourquoi l’Église les tient pour un témoin majeur de sa foi (évêque, eucharistie, Christ vrai Dieu et vraie chair, martyre) ?

Obstacles du novice : confondre les trois recensions ; croire la date de 107/110 certaine ; lire « épiscopat monarchique » au sens politique ; croire qu’Ignace « invente » l’évêque ; prendre le désir du martyre pour un goût du suicide ; prendre « Église catholique » au sens confessionnel moderne ; lire « préside à la charité » comme une définition juridique de la primauté ; confondre docétisme et arianisme.

## Leçons (12)
1. Ignace, évêque d’Antioche : Antioche (Actes 11, 13, Galates 2:11), la succession (Eusèbe HE III,22 ; III,36 ; Origène ; Chrysostome ; Théodoret), ce qu’on sait de lui, Théophore (grec *Theophoros*, « porteur de Dieu » ; légende tardive de l’enfant de Marc 9:36 ; dialogue du *Martyre* : « celui qui a le Christ dans le cœur »), Père apostolique.
2. De l’arrestation au martyre : Trajan (lien persécutions), dix léopards (Rom 5,1), route par l’Asie, Philadelphie, Smyrne (Polycarpe, délégations : Onésime, Burrhus, Crocus ; Damas, Bassus, Apollonius, Zotion ; Polybe) et quatre lettres ; Troas, paix d’Antioche, trois lettres, départ précipité vers Néapolis (Pol 8,1) ; Philippes (Polycarpe, Phil 1, 9, 13) ; martyre à Rome livré aux bêtes ; Irénée V,28,4 ; *Martyre d’Ignace* (Colbertinum : 20 décembre, Sura et Sénécion, amphithéâtre Flavien) ; reliques (Antioche, Jérôme, Tychaeum, Saint-Clément) ; date : vers 110, discussion (Chronique d’Eusèbe, 107 ; sous Trajan 98-117 ; datations tardives, Barnes ; thèse de faux, Hübner, Lechner).
3. Les sept lettres et leurs trois recensions : genre, liste et lieux, collection de Polycarpe, Eusèbe ; longue (13 lettres, IVe s., interpolée, compilateur des Constitutions apostoliques) ; moyenne (7 lettres ; latin publié par Ussher 1644 ; grec par Voss 1646, Romains par Ruinart 1689) ; courte syriaque (3 lettres, Cureton 1845) ; controverse (Calvin, Pearson 1672) ; Zahn 1873, Lightfoot 1885 ; état actuel (Joly, Rius-Camps, Hübner, Lechner minoritaires) ; lettres latines à Marie et à Jean (médiévales).
4. La Lettre aux Éphésiens : unité autour de l’évêque (cithare, chœur, Eph 4 ; évêque comme le Seigneur, Eph 6,1) ; eucharistie (se réunir souvent, Eph 13,1 ; autel, Eph 5,2 ; remède d’immortalité, Eph 20,2 ; CEC 1405) ; virginité de Marie cachée au prince de ce monde (Eph 19,1 ; l’étoile ; Origène ; CEC 498) ; foi et charité (Eph 14,1), silence (Eph 15,1).
5. Les lettres aux Magnésiens et aux Tralliens : Magnésie (Damas jeune évêque, Magn 3,1 ; Magn 6,1) ; judaïsants (Magn 8-10 ; vivre selon le dimanche, Magn 9,1 ; Magn 10,3 ; mot *christianismos*) ; Tralles (Polybe ; Trall 3,1, CEC 1554) ; docétisme (grec *dokein*), Trall 9-10, argument du martyre ; poison mêlé de vin (Trall 6,2).
6. La Lettre aux Romains : adresse (préside dans la région des Romains, préside à la charité, *prokathēmenē tēs agapēs* ; CEC 834 ; lectures) ; Pierre et Paul (Rom 4,3) ; supplique (ne pas intervenir) ; froment de Dieu (Rom 4,1) ; vrai chrétien (Rom 3,2) ; mieux vaut mourir (Rom 6,1) ; eau vive, pain de Dieu (Rom 7,2-3) ; Église de Syrie (Rom 9,1).
7. La Lettre aux Philadelphiens : visite, évêque silencieux (Phld 1) ; schisme (Phld 3) ; une seule eucharistie (Phld 4) ; Phld 6,1 ; le cri de l’Esprit (Phld 7) ; les archives (Phld 8,2) ; grand prêtre (Phld 9,1) ; diacre pour Antioche (Phld 10).
8. La Lettre aux Smyrniotes : confession (Smyrn 1) ; vraie passion, vraie résurrection (Smyrn 2-3, Luc 24:39) ; eucharistie chair du Sauveur (Smyrn 7,1) ; charité négligée (Smyrn 6,2) ; eucharistie valide sous l’évêque (Smyrn 8,1) ; Église catholique (Smyrn 8,2 ; CEC 830 ; sens de *katholikos*).
9. La Lettre à Polycarpe : adresse ; unité, porter tous (Pol 1,2) ; serpent et colombe ; athlète (Pol 2,3) ; enclume (Pol 3,1) ; Christ hors du temps (Pol 3,2) ; veuves, esclaves (Pol 4) ; mariage avec l’avis de l’évêque, chasteté sans orgueil (Pol 5,2) ; armure (Pol 6,2) ; messager pour la Syrie, « le chrétien n’est pas maître de lui-même » (Pol 7) ; départ (Pol 8,1).
10. L’évêque, le presbyterium et les diacres : vocabulaire ; trois degrés ; images (évêque/Père ou Christ, presbytres/apôtres, diacres/service du Christ) ; « monarchique » (un seul évêque par Église) ; débat historique (NT, Clément, Didachè, Rome sans évêque nommé) ; lecture catholique (succession apostolique ; développement) ; Ignace ne parle pas de succession ; CEC 1549, 1554 ; *presbyterium* aujourd’hui.
11. La christologie d’Ignace : Jésus appelé Dieu (Eph inscr., Eph 1,1 « sang de Dieu », Eph 18,2, Rom inscr., Rom 6,3, Smyrn 1,1, Pol 8,3) ; Eph 7,2 (le seul médecin) ; « engendré et inengendré », formule d’avant Nicée, défendue par Athanase (*De synodis* 47) ; vraie chair (alēthōs) ; Fils de Marie et Fils de Dieu ; Pol 3,2 ; communication des idiomes ; Eph 9,1 (Trinité).
12. Le martyre, imitation de la Passion, et la mémoire de l’Église : disciple (Eph 3,1 ; Rom 5,3) ; imitateur de la passion de mon Dieu (Rom 6,3) ; atteindre Dieu ; libation, autel, froment (eucharistie) ; naissance (Rom 6,1) ; lien avec l’antidocétisme (Trall 10 ; Smyrn 4,2) ; humilité ; ne pas provoquer le martyre (jugement de l’Église) ; mémoire : 17 octobre (depuis 1969 ; avant 1er février ; Orient 20 décembre) ; antiennes (Galates 2:19-20 ; « Je suis le froment du Christ ») ; Canon romain (*Nobis quoque peccatoribus*) ; Benoît XVI 2007, « docteur de l’unité ».
