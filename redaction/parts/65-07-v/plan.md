# 65-07-v · La Vigile pascale (fichier 65-le-temps-liturgique, lettre v)

Question centrale : que fait l'Église pendant la nuit de Pâques, et pourquoi cette nuit, avec ses quatre parties (lumière, Parole, baptême, eucharistie), est-elle le sommet de toute l'année ?
Obstacles du novice : prendre la Vigile pour une « messe anticipée du samedi soir » ; ne pas voir l'unité des quatre parties ; trouver les sept lectures trop longues sans voir leur logique ; ignorer que les baptêmes d'adultes en sont le cœur ; croire que la Vigile a toujours été célébrée ainsi (déplacement au samedi matin, restauration de 1951-1955).

Leçons (12) :
1. La mère de toutes les saintes vigiles — Augustin (Sermon 219), PS 77, 80 ; sommet de l'année (NUALC) ; Exode 12:42 ; quatre parties (PS 81) et leur logique ; Pâque = passage.
2. Une veille dans la nuit — PS 78 (après la tombée de la nuit, avant l'aube) ; Tertullien, Tradition apostolique ; Luc 12:35-37, Mt 25:6 ; attente du retour (Jérôme, Lactance, paraphrasés) ; déplacement au samedi matin, Pie V ; Pie XII 1951 et 1955 ; Messe de la Vigile = messe de Pâques.
3. Le feu nouveau — lucernaire ; le feu hors de l'église (PS 82) ; monition ; bénédiction (latin) ; symbolisme du feu ; origine gallo-germanique.
4. Le cierge pascal et ses inscriptions — croix, alpha, oméga, millésime ; formule ; cinq grains ; allumage ; cire, neuf, unique (PS 82) ; usage pendant cinquante jours, baptêmes, funérailles (PS 99).
5. La procession de la lumière — « Lumière du Christ » trois fois ; colonne de feu ; cierges des fidèles ; lumières de l'église ; ancien cierge triple.
6. L'Exsultet — annonce de la Pâque ; structure ; « Haec nox est » ; felix culpa ; nuit bienheureuse ; offrande du cierge ; Augustin, livres gallicans, rouleaux de l'Italie du Sud.
7. Les sept lectures de l'Ancien Testament — liste, psaumes et oraisons ; Exode 14 obligatoire ; au moins trois ; histoire (12 → 4 → 7) ; logique.
8. Gloria, épître, Alléluia, Évangile — cloches ; collecte ; Romains 6:3-11 ; Alléluia triple, Ps 118 ; Évangile selon l'année, sans cierges ; homélie.
9. La litanie des saints et la bénédiction de l'eau — litanie debout, noms ajoutés, quand elle est omise ; bénédiction de l'eau (CEC 1217-1222), cierge plongé, acclamation ; eau lustrale s'il n'y a pas de baptême.
10. Les baptêmes et les confirmations des adultes — RICA (1972), catéchuménat, élection, scrutins ; renonciation, profession, baptême, rites complémentaires ; confirmation par le prêtre (c. 866, 883) ; néophytes.
11. Le renouvellement des promesses du baptême — origine 1955/56 ; monition, renonciation, profession, cierges allumés ; aspersion ; prière universelle ; CEC 1254.
12. L'eucharistie de la nuit et le jour de Pâques — sommet (PS 90) ; textes propres ; communion des néophytes ; double alléluia ; messe du jour ; Ps 118:24 ; séquence Victimae paschali laudes (Wipo, PGMR 64).
