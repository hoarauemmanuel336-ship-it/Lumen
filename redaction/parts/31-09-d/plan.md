# 31-09-d · Les décrets doctrinaux de Trente (lettre d)

Question centrale : qu'a défini le concile de Trente sur la foi, contre quelles thèses protestantes, comment chaque décret est né (débats, acteurs, compromis) et ce qu'il a laissé ouvert.
Principe : cours d'histoire ; la doctrine elle-même renvoie d'un lien aux blocs doctrinaux (02, 11, 53, 67-74, 76). Liens dans le fichier 31 : seulement #ouverture-y.

Fichiers : 00-ouverture.html, 01.html … 12.html, 99-bilan.html.

1. Session IV (8 avril 1546) : l'Écriture, les traditions et le canon. Pourquoi commencer par là (sola scriptura, Worms) ; le décret (Évangile source, livres et traditions, égal respect ; partim/partim et Nacchianti rappelés + lien 02#ouverture-e) ; le canon : Florence 1442, Luther (préfaces 1522, Apocryphes 1534), Cajetan, débat sur deux classes (Seripando), anathème, « avec toutes leurs parties » ; réception (Chemnitz, Vatican I).
2. Session IV : la Vulgate authentique, la règle d'interprétation, l'imprimerie et l'usage profane ; question des traductions en langue courante laissée sans décision ; Pie XII 1943 (authenticité juridique) ; suites (Sixto-clémentine → #ouverture-e, Index 1564 → #ouverture-e, Luis de León).
3. Session V (17 juin 1546) : le péché originel. Charles Quint et la méthode (→ #ouverture-t) ; thèses de Luther, Zwingli, anabaptistes, Érasme et Romains 5:12 ; les cinq canons ; concupiscence (canon 5) ; la déclaration sur Marie et le débat sur l'Immaculée Conception (défini en 1854).
4. Session VI (13 janvier 1547) : la justification. Ratisbonne 1541 ; sept mois de débats ; Seripando et la double justice ; certitude de la grâce ; seize chapitres, trente-trois canons (plan, formules clés) ; réception (Calvin 1547, Chemnitz, 1999) ; lien 53#ouverture-l.
5. Session VII (3 mars 1547) : les sacrements en général, le baptême, la confirmation. Thèses des réformateurs (Captivité babylonienne, Zwingli, Calvin, anabaptistes) ; histoire du septénaire (Pierre Lombard, Lyon II, Florence 1439) ; 13 + 14 + 3 canons sans chapitres ; ex opere operato, caractère, intention ; transfert à Bologne (→ #ouverture-t).
6. Session XIII (11 octobre 1551) : l'eucharistie. Divisions protestantes (Marbourg 1529, Zwingli, Luther, Calvin, Consensus de Zurich 1549) ; Bérenger, Latran IV ; 8 chapitres, 11 canons ; transsubstantiation « très convenablement » ; culte, Fête-Dieu, réserve ; quatre articles ajournés pour les protestants.
7. Session XIV (25 novembre 1551) : la pénitence et l'extrême-onction. 9 ch. 15 can. ; 3 ch. 4 can. ; Luther et la pénitence ; Jean 20:22-23 ; contrition, attrition, confession intégrale de droit divin, absolution acte judiciaire, satisfaction ; Jacques 5:14-15 ; le nom d'extrême-onction et Vatican II.
8. Session XXI (16 juillet 1562) : la communion sous les deux espèces. Histoire (Constance 1415, utraquistes, Compacts, Pie II) ; Luther ; demandes de Ferdinand Ier et de la Bavière ; 4 ch. 4 can. ; « sauve la substance » ; enfants ; la coupe renvoyée au pape (session XXII), concession de 1564 ; Vatican II.
9. Session XXII (17 septembre 1562) : le sacrifice de la messe. Luther (1520, 1521), Zwingli 1525, Calvin, articles anglicans ; débats sur la Cène ; 9 ch. 9 can. ; même victime ; messes « privées », canon de la messe, langue (discipline / doctrine) ; décret sur les abus.
10. Session XXIII (15 juillet 1563) : l'ordre. Sacerdoce universel selon Luther ; crise de 1562-1563 (résidence, droit divin, juridiction ; Guerrero, Lorraine ; morts de Gonzague et Seripando ; Morone) ; 4 ch. 8 can. ; « par disposition divine » ; ce qui reste ouvert (Vatican II) ; séminaires (→ #ouverture-e).
11. Session XXIV (11 novembre 1563) : le mariage. Luther (« chose de ce monde »), divorce chez les réformateurs, bigamie de Philippe de Hesse ; préambule et 12 canons ; Éphésiens 5:32 « laisse entendre » ; canon 7 et les Grecs de Venise ; virginité ; Tametsi (→ #ouverture-e).
12. Session XXV (3-4 décembre 1563) : purgatoire, saints, reliques, images, indulgences. Clôture pressée ; iconoclasme ; décrets sans canons sauf indulgences ; Nicée II ; abus ; quêteurs (session XXI) ; suites (Pie V, Paul VI 1967).
