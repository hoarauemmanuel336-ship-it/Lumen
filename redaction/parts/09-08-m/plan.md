# Plan du cours 09-08-m : L'athéisme et ses maîtres (lettre m)

Question centrale : pourquoi des esprits puissants ont-ils nié Dieu, que valent leurs raisons, et que répondent la raison et l'Église ?
Obstacles du novice : croire que l'athéisme est un seul bloc ; confondre athée, agnostique, indifférent ; croire qu'expliquer l'origine d'une croyance la réfute ; croire que la science a prouvé l'inexistence de Dieu ; caricaturer les athées ; oublier la part des croyants.

Leçons (12) :
1. Le mot « athéisme » et ses deux formes : atheos (Platon Lois X, Socrate Apologie 26c, chrétiens accusés : Martyre de Polycarpe 9, Justin 1 Apol. 6 ; Éph 2:12 ; Ps 14:1) ; français XVIe s., d'Holbach 1770 ; athéisme théorique (négation par raisons ; négatif/positif) ; athéisme pratique (vivre comme si Dieu n'était pas ; Ps 10:4, Luc 12:19-20 ; Grotius etsi Deus non daretur) ; Maritain (classification, doute). Distinction avec agnosticisme (lien #ouverture-g) et indifférence.
2. Gaudium et spes 19 à 21 : vocation à la communion ; « faits les plus graves » ; formes (19.2) ; faute et causes en bref ; athéisme systématique (20 : autonomie, libération économique) ; attitude de l'Église (21 : réprouve, cherche les causes cachées, dignité, espérance eschatologique, remèdes, dialogue, Augustin). CEC 2123-2126 ; Dei Filius canon.
3. Le mal, objection première : Épicure via Lactance (De ira Dei 13), Boèce (Consolation I, pr. 4), saint Thomas (I, q. 2, a. 3, obj. 1 et ad 1 ; SCG III, 71 « si malum est, Deus est »), Hume (Dialogues X), Dostoïevski/Camus, problème logique et évidentiel (Mackie 1955), réponses philosophiques (privation, permission, bien tiré du mal, limites) ; lien 42.
4. Feuerbach : L'Essence du christianisme (1841) ; projection ; textes allemands (Introduction ch. 2) ; homo homini deus ; réponse (projection ne prouve pas inexistence ; Dieu « tout autre » ; analogie ; sophisme génétique ; Lubac).
5. Marx : critique de la religion (Introduction 1844 : opium, soupir de la créature) ; aliénation économique ; Thèse 11 ; matérialisme historique ; réponse : Divini Redemptoris (1937 : athée, pseudo-idéal, intrinsèquement pervers, rouage), Centesimus annus 13 ; ce qu'il a vu de juste.
6. Nietzsche : Gai Savoir 1882, §125 l'insensé, §108, §343 (1887) ; critique de la morale chrétienne : Généalogie (1887), ressentiment, morale d'esclaves, Antéchrist ; surhomme ; réponse : Deus caritas est 3 ; Scheler ? (non) ; la charité n'est pas ressentiment ; nihilisme (Fides et ratio 90).
7. Freud : L'Avenir d'une illusion (1927), ch. VI : illusion = croyance motivée par désir ; détresse infantile, père ; Totem et tabou (1913) ; névrose ; réponse : illusion pas erreur (Freud lui-même) ; sophisme génétique ; argument retournable ; Ricœur, maîtres du soupçon (1965).
8. Comte : Cours de philosophie positive (1830-1842), loi des trois états (1re leçon), positivisme, religion de l'Humanité (Catéchisme positiviste 1852) ; réponse : la loi n'est pas une loi scientifique ; théologie et métaphysique répondent à d'autres questions ; le culte de l'Humanité ; lien Foi et sciences.
9. Sartre : L'existentialisme est un humanisme (1945/1946), L'Être et le néant (1943) ; l'existence précède l'essence ; pas de nature humaine ; condamné à être libre ; Dieu rival de la liberté ; désir d'être Dieu ; Les Mots ; réponse : liberté créée, cause première et causes secondes, Dieu donne la liberté (Thomas I, q. 83, a. 1, ad 3), GS 21 ; Dostoïevski phrase non littérale.
10. Le nouvel athéisme et le scientisme : Wolf 2006, Harris, Dawkins (Pour en finir avec Dieu / The God Delusion 2006), Dennett, Hitchens ; hypothèse Dieu ; Boeing 747 ; réponse : Dieu n'est pas un être complexe parmi d'autres (simplicité) ; scientisme autoréfutant ; Fides et ratio 88 ; violence des religions.
11. Henri de Lubac, Le Drame de l'humanisme athée (1944) : trois parties ; Feuerbach et Nietzsche ; Comte ; Dostoïevski ; humanisme exclusif = inhumain (Populorum progressio 42) ; Prométhée ; Dieu rival.
12. Les causes de l'athéisme et la part des croyants : GS 19.3, 21.5 ; causes intellectuelles, morales, sociales ; responsabilité (négligence, présentations trompeuses, défaillances) ; remèdes : doctrine, pureté de vie, foi vivante et adulte, charité ; Mt 5:16 ; Rm 2:24 ; jugement de la faute (CEC 2125).
Bilan : 6 exercices croisés.
