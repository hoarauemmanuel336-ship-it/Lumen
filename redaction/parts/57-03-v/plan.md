# Plan du cours 57-03-v : La vocation des laïcs (lettre v)

Question centrale : qu'est-ce qu'un laïc dans l'Église, quelle est sa mission propre, et par quels textes et quelles structures l'Église la reconnaît-elle ?
Obstacles du novice : « laïc » = « non religieux » (laïcité) ; laïc = chrétien de second rang ou simple auxiliaire du prêtre ; apostolat = activité paroissiale ; autonomie du temporel = indépendance à l'égard de Dieu ; ministères institués = petit sacerdoce ; mouvements = Église parallèle.

Fichiers : 00-ouverture.html, 01.html … 11.html, 99-bilan.html.

1. Le mot « laïc » et la définition de Lumen gentium 31 : laos/laikos ; Clément de Rome 40 ; définition négative et positive ; LG 31 cité ; sens civil (laïcité) à ne pas confondre ; membres des instituts séculiers.
2. Le caractère séculier et le ferment : LG 31 « caractère séculier propre et particulier » ; vocation propre « gérance des choses temporelles » ; levain (Matthieu 13:33), sel et lumière (Matthieu 5:13-16), Jean 17:15-18, Diognète (LG 38) ; CL 15 : dimension séculière de toute l'Église, « de façons diverses », caractère théologique ; GS 43 divorce foi/vie ; CL 59 deux vies parallèles ; débat théologique (Congar).
3. L'office prophétique : rappel tria munera (lien 56 #ouverture-t) ; LG 35 témoins, sens de la foi, grâce de la parole ; témoignage de la vie et parole (CEC 905, AA 6) ; 1 Pierre 3:15-16 ; Priscille et Aquila (Actes 18:26) ; famille ; limites (enseignement authentique aux pasteurs).
4. L'office sacerdotal : LG 34 consécration et onction ; toutes leurs activités deviennent offrandes spirituelles (1 Pierre 2:5) ; unies à l'eucharistie ; « consacrent à Dieu le monde lui-même » ; Romains 12:1-2 ; lien au cours sur le sacerdoce commun (#ouverture-s) ; parents, travail, souffrance.
5. L'office royal : LG 36 ; Philippiens 2:8-9 ; liberté royale, vaincre le péché en soi ; servir le Christ dans les autres (Marc 10:42-45) ; ordonner le temporel : création, valeur, finalité gloire de Dieu ; 1 Corinthiens 3:21-23 ; compétence profane ; assainir les institutions ; distinguer droits de membre de l'Église et de citoyen ; Genèse 1:28, 2:15.
6. La juste autonomie des réalités terrestres (GS 36) : deux sens ; texte du concile ; science et foi, note Galilée (Paschini) ; « la créature sans Créateur s'évanouit » ; Matthieu 22:21 ; GS 43 compétence et liberté des laïcs, pluralité d'options ; ni cléricalisme ni sécularisme.
7. Le décret Apostolicam actuositatem (1965) : contexte (Action catholique, Pie XI) ; date ; six chapitres ; vocation chrétienne = vocation à l'apostolat ; droit et devoir ; deux ordres ; champs ; apostolat individuel et organisé ; Action catholique (AA 20) ; mandat (AA 24) ; conseils (AA 26) ; secrétariat → Conseil pontifical pour les laïcs (1967), Dicastère (2016) ; formation.
8. Christifideles laici (1988) : synode 1987 ; vigne (Matthieu 20:1-7) ; cinq chapitres mystère-communion-mission ; description positive ; caractère séculier théologique ; ministères, offices et fonctions, suppléance, deux tentations ; associations « nouvelle saison », critères d'ecclésialité (renvoi l.11) ; unité de vie ; formation.
9. Les ministères institués : lecteur et acolyte (Ministeria quaedam, 15 août 1972) : ordres mineurs (Corneille 251) ; suppression tonsure, ordres mineurs, sous-diaconat ; « institution » et non « ordination » ; état clérical au diaconat ; lecteur (Néhémie 8, Luc 4) ; acolyte ; ministre extraordinaire de la communion, can. 230 §§ 2-3 ; candidats à l'ordre.
10. Femmes lectrices et acolytes, ministère de catéchiste : Spiritus Domini (10 janvier 2021), can. 230 §1 ; lettre à Ladaria, Ordinatio sacerdotalis ; Antiquum ministerium (10 mai 2021) ; catéchiste dans l'Écriture (Galates 6:6, Luc 1:4, 1 Corinthiens 12:28) ; grec katêchein ; qualités (n. 8) ; rite (3 décembre 2021) ; qui l'on institue.
11. Associations de fidèles, mouvements et communautés nouvelles : droit d'association (CL 29 : du baptême) ; can. 298-329 ; publiques/privées ; tiers ordres ; vigilance ; critères d'ecclésialité (CL 30) ; mouvements XXe s. (exemples) ; Pentecôte 1998, coessentiels ; Iuvenescit Ecclesia (2016) ; 1 Thessaloniciens 5:19-21 ; abus et décret du 11 juin 2021.
