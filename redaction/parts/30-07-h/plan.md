# Plan du cours 30-07-h : Les hérésies médiévales

Lettre h. 12 leçons. Fichiers : 00-ouverture.html, 01.html à 12.html, 99-bilan.html.

Question centrale : pourquoi, aux XIIe et XIIIe siècles, des chrétiens sincères ont-ils quitté la foi de l'Église (cathares, vaudois, joachimites, Libre-Esprit), et comment l'Église a-t-elle répondu, par la parole, par la vie évangélique, par le droit et par la force ?
Obstacles du novice : croire que tous les « hérétiques » se ressemblent (cathares et vaudois confondus) ; voir dans les cathares de simples chrétiens « purs » persécutés, ou à l'inverse une secte imaginaire ; croire que Dominique était inquisiteur ou chef de croisade ; prendre « Tuez-les tous » pour un fait établi ; ignorer que les vaudois existent encore ; confondre joachimisme et hérésie formelle de Joachim ; croire à une « secte » organisée du Libre-Esprit.

1. L'hérésie au Moyen Âge : le mot, le contexte, les sources. Grec hairesis ; CEC 2089 ; foi et ordre social, Vergentis in senium (1199) ; Orléans 1022 ; Pierre de Bruys, Henri de Lausanne, Arnaud de Brescia ; vie apostolique ; sources (adversaires, registres, rares textes cathares) ; faits / historiens / jugement de l'Église.
2. Les bogomiles des Balkans. Bulgarie du tsar Pierre, Théophylacte, Cosmas le Prêtre ; Satanaël, dualisme mitigé, rejet des sacrements ; Basile brûlé à Constantinople (Alexiade) ; Euthyme Zigabène ; Bosnie (débat) ; Cologne 1143 (Évervin) ; Interrogatio Iohannis (Nazaire).
3. Le catharisme et sa doctrine dualiste. katharos, Eckbert de Schönau (1163) ; noms ; dualisme absolu / mitigé ; Livre des deux principes ; doctrine ; réponse catholique (Firmiter, Genèse 1:31, 1 Timothée 4:1-4, Jean 1:14) ; débat historiographique.
4. L'Église cathare : parfaits, croyants, consolamentum. Hiérarchie, Saint-Félix (1167, discuté), maisons ; consolamentum (Rituel de Lyon), melioramentum, convenenza, endura (discutée) ; Rainier Sacconi ; implantation et raisons du succès.
5. La mission de Dominique et des légats, et l'assassinat de Pierre de Castelnau (1145-1208). Missions antérieures (Bernard 1145, Henri de Marcy 1178-1181, Lombers 1165) ; légats d'Innocent III ; Montpellier 1206, Diègue et Dominique ; débats (Servian, Montréal, Pamiers), Fanjeaux, Prouille ; Raymond VI excommunié (1207) ; meurtre (14 janvier 1208) ; lettre d'Innocent III (10 mars 1208).
6. La croisade contre les Albigeois (1209-1229) et Simon de Montfort. Saint-Gilles (18 juin 1209) ; Béziers et « Tuez-les tous » ; Carcassonne ; Simon ; Minerve, Lavaur ; Muret (1213) ; Latran IV ; mort de Simon (1218) ; Louis VIII ; Meaux-Paris (1229) ; concile de Toulouse ; jugement.
7. La chute de Montségur (1244) et la fin du catharisme. Avignonet (1242), siège, bûcher du 16 mars 1244 ; Quéribus ; Pierre Autier, Montaillou, Bélibaste (1321) ; Italie ; légendes.
8. Pierre Valdès et les vaudois (vers 1170). Conversion, traduction, pauvreté, prédication ; Latran III ; profession de foi (1180) ; expulsion ; Actes 5:29.
9. La condamnation des vaudois (1184) et leur rattachement à la Réforme (1532). Ad abolendam ; Pauvres lombards, Bergame (1218) ; Pauvres catholiques (1208), Bernard Prim ; barbes ; persécutions ; Chanforan ; Olivétan ; Mérindol, Pâques piémontaises ; 1848 ; aujourd'hui ; François à Turin (2015).
10. Joachim de Flore et le joachimisme. Vie ; trois états, concordance ; Latran IV ; Évangile éternel (1254), Anagni (1255) ; spirituels ; Bonaventure ; Dante ; postérité (de Lubac) ; CEC 676.
11. Le mouvement du Libre-Esprit. Amalriciens (1210), Latran IV ; béguines et bégards ; Marguerite Porete (1310) ; Ad nostrum (Vienne) ; Lerner ; Ruusbroec ; 1 Jean 1:8.
12. La réponse de l'Église : la prédication, les ordres mendiants, l'enquête judiciaire. Prédication et réconciliation (Innocent III, Latran IV can. 10) ; ordres mendiants (Toulouse 1215, université de Toulouse 1229) ; enquête (1184, 1199, 1215 can. 3, Toulouse 1229, 1231-1233) ; bilan ; jugement de l'Église (Dignitatis humanae 12, 12 mars 2000).
Bilan : 6 exercices croisés.
