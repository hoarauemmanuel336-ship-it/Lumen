# 71-08-i Les indulgences : plan (12 leçons, 5 exercices chacune, bilan 6)

Question centrale : qu'est-ce qu'une indulgence, sur quoi l'Église fonde-t-elle le pouvoir de l'accorder, et comment la gagne-t-on aujourd'hui ? Obstacles : croire qu'elle pardonne le péché, qu'elle s'achète, que les « jours » étaient des jours de purgatoire, qu'elle agit toute seule, que c'est une invention médiévale abolie depuis Luther ; confondre le trésor avec de l'argent.
