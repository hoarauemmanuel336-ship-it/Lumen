# Lumen

Le site personnel et privé d'Emmanuel, en ligne sur lumenveritatis.net : la Bible dans ses deux traductions (Chérubin et Séraphin), Mémoriser, Articles, Ressources et l'atelier des commentaires bibliques.

- **Pour l'IA** : tout est expliqué dans `CLAUDE.md`, à lire en premier.
- **Les données** : `documentation/donnees.md`.
- **L'IA dans le site** : `documentation/ia.md`.
- **La sécurité de la base** : `documentation/regles-firestore.txt`.

Fabriquer le site : `node fabrication/build-bi.js` (le résultat sort dans `site/`). Netlify le refait à chaque dépôt sur la branche `main`.
